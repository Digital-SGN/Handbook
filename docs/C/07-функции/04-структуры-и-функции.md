# Структуры и функции

Структуру можно передавать в функцию как **параметр** и возвращать как **результат**. Но есть нюансы: по умолчанию структура передаётся **по значению**, то есть копируется целиком.

## Структура как параметр

Структура передаётся **по значению** — функция получает **копию**.

```cpp
#include <stdio.h>

struct person
{
    char *name;
    int age;
};

void print_person(struct person user)
{
    printf("Name: %s\n", user.name);
    printf("Age: %d\n", user.age);
}

int main(void)
{
    struct person tom = { .name = "Tom", .age = 38 };
    print_person(tom);
    return 0;
}
```

Функция `print_person` принимает `struct person` и печатает поля. Изменить оригинал она не может — работает с копией.

### Через typedef — короче

```cpp
#include <stdio.h>

typedef struct
{
    char *name;
    int age;
} person;

void print_person(person user)
{
    printf("Name: %s\n", user.name);
    printf("Age: %d\n", user.age);
}

int main(void)
{
    person tom = { .name = "Tom", .age = 38 };
    print_person(tom);
    return 0;
}
```

Писать `person user` вместо `struct person user` — удобнее.

### Цена передачи по значению

Когда структура передаётся по значению:

- создаётся **полная копия** всех полей — на стеке;
- для больших структур это **медленно** и **затратно по памяти**;
- изменения внутри функции **не видны** снаружи.

Если структура большая (десятки-сотни байт) или её нужно **изменить**, передавайте указатель.

## Указатель на структуру как параметр

Передача указателя решает обе проблемы: не копирует данные и позволяет изменить оригинал.

```cpp
#include <stdio.h>

struct person
{
    char *name;
    int age;
};

void change_person(struct person *user)
{
    user->age = user->age + 1;
}

int main(void)
{
    struct person bob = { "Bob", 22 };

    printf("Before: %s : %d\n", bob.name, bob.age);
    change_person(&bob);
    printf("After:  %s : %d\n", bob.name, bob.age);

    return 0;
}
```

Вывод:

```text
Before: Bob : 22
After:  Bob : 23
```

Функция принимает `struct person *` и меняет поле через `->`. Изменения видны в `main`, потому что функция работала с **тем же объектом**, а не с копией.

### `const` для входных параметров

Если функция **только читает** структуру, но принимает её через указатель (чтобы избежать копирования), стоит поставить `const`:

```cpp
void print_person(const struct person *user)
{
    printf("Name: %s\n", user->name);
    printf("Age: %d\n", user->age);
    // user->age = 0;   // ошибка: изменение запрещено
}
```

Вызов:

```cpp
struct person tom = { "Tom", 38 };
print_person(&tom);   // передаём адрес
```

**Преимущества:**

- нет копирования структуры;
- компилятор **гарантирует**, что функция её не изменит;
- код самодокументируется: видно, что параметр — входной.

> **Соглашение:** для структур, которые функция только читает, — `const struct T *`. Для тех, что функция изменяет, — `struct T *`. Для маленьких структур (2–3 `int`) можно и по значению.

## Структура как результат

Функция может **вернуть структуру**:

```cpp
#include <stdio.h>

struct person
{
    char *name;
    int age;
};

struct person create_person(char *name, int age)
{
    struct person user;
    user.name = name;
    user.age = age;
    return user;
}

int main(void)
{
    struct person bob = create_person("Bob", 22);

    printf("Name: %s\n", bob.name);
    printf("Age: %d\n", bob.age);

    return 0;
}
```

Функция `create_person` собирает структуру и **возвращает её по значению**. Компилятор копирует её в переменную `bob` (или оптимизирует копирование — RVO, return value optimization).

### Не возвращайте адрес локальной структуры

```cpp
struct person *bad_create(void)
{
    struct person p = { "Tom", 22 };
    return &p;   // ОШИБКА: p уничтожится при выходе
}
```

`p` — локальная переменная. После выхода из функции она перестаёт существовать, а указатель на неё становится **висячим**. Обращение к нему — неопределённое поведение.

Если нужно вернуть структуру по указателю — используйте `malloc`:

```cpp
struct person *create(void)
{
    struct person *p = malloc(sizeof(struct person));
    if (p != NULL) {
        p->name = "Tom";
        p->age = 22;
    }
    return p;   // вызывающий должен будет освободить
}
```

## Что выбрать

| Ситуация | Решение |
| :--- | :--- |
| Функция только читает, структура большая | `const struct T *` |
| Функция изменяет структуру | `struct T *` |
| Структура маленькая (2–3 поля) и только читается | По значению |
| Структура создаётся в функции и возвращается | По значению |
| Структура создаётся и живёт дольше функции | `malloc` + указатель |

> **Общее правило.** По значению — только для **маленьких** структур. Всё остальное — через **указатель**. Если функция не меняет данные — `const`.

---

## Итог

- Структура как параметр передаётся **по значению** — копируется целиком.
- Для больших структур это **медленно** и не позволяет изменить оригинал.
- **Указатель на структуру** — без копирования, с возможностью изменить.
- **`const struct T *`** — функция читает, но не меняет. Рекомендуется для входных данных.
- Функция может **вернуть структуру по значению** — это безопасно.
- **Возвращать адрес локальной структуры нельзя** — она уничтожается при выходе.
- Если структура должна жить дольше функции — выделяйте её через `malloc`.
