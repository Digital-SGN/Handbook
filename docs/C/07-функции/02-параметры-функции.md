## Определение параметров

Формальная запись:

```cpp
тип имя_функции(тип параметр1, тип параметр2, ..., тип параметрN)
```

Для каждого параметра — **тип**, затем **имя**. Через запятую — следующий.

Пример — функция, принимающая строку:

```cpp
#include <stdio.h>

void print_message(char message[])
{
    printf("%s\n", message);
}

int main(void)
{
    print_message("Hello, world!");
    print_message("Hello work...");
    return 0;
}
```

Разберём терминологию:

- **`message`** — **формальный параметр** (или просто параметр). Он объявлен в определении функции;
- **`"Hello, world!"`** — **аргумент**. Это конкретное значение, передаваемое при вызове.

Одно и то же имя параметра может получать разные значения при разных вызовах.

### Прототип

```cpp
void print_message(char[]);
```

Имена в прототипе можно не указывать — компилятору достаточно типов.

## Несколько параметров

Перечисляются через запятую:

```cpp
#include <stdio.h>

void sum(int x, int y)
{
    printf("%d + %d = %d\n", x, y, x + y);
}

int main(void)
{
    sum(1, 2);
    sum(4, 5);
    sum(6, 2);
    return 0;
}
```

Вывод:

```text
1 + 2 = 3
4 + 5 = 9
6 + 2 = 8
```

**Соответствие аргументов параметрам — по позиции.** Первый аргумент идёт в первый параметр, второй — во второй, и т.д.

Прототип:

```cpp
void sum(int, int);
```

## Соответствие типов

Типы аргументов и параметров должны **соответствовать**. Если типы не совпадают, компилятор **попробует преобразовать** их к типу параметра.

Например, для `void sum(int, int)`:

```cpp
sum(1.4, 2.5);    // double → int
sum(1.4f, 2.5f);  // float  → int
```

В обоих случаях функция получит числа `1` и `2` — дробные части будут **отброшены**.

> **Осторожно:** такие неявные преобразования могут приводить к потере данных. Компилятор с `-Wconversion` предупредит. Не полагайтесь на «авось» — передавайте аргументы правильного типа.

## Передача по значению

Ключевая особенность C: аргументы передаются **по значению**. Функция получает **копию** значения, а не саму переменную.

```cpp
#include <stdio.h>

void increase(int x)
{
    x = 2 * x;
    printf("Inside increase: x = %d\n", x);
}

int main(void)
{
    int a = 25;
    increase(a);
    printf("In main: a = %d\n", a);
    return 0;
}
```

Вывод:

```text
Inside increase: x = 50
In main: a = 25
```

Почему `a` не изменилось?

1. При вызове `increase(a)` значение переменной `a` **копируется** в параметр `x`.
2. Внутри функции `x = 50` меняет **копию**, не `a`.
3. После возврата из функции копия уничтожается, `a` остаётся `25`.

### Что происходит с памятью

При вызове функции:

- для параметров выделяются **отдельные участки памяти**;
- туда **копируются** значения аргументов;
- `float` при этом превращается в `double`, а `char`/`short` — в `int`;
- после завершения функции эта память **освобождается**.

Именно поэтому изменения параметров внутри функции никак не влияют на оригинальные переменные.

> **Как изменить переменную снаружи?** Передавать не саму переменную, а **указатель на неё**. Тогда функция сможет писать по адресу. Подробнее — в главах про указатели.

## Константные параметры

Иногда нужно гарантировать, что параметр **не изменится** внутри функции. Для этого его объявляют `const`:

```cpp
void change(const int n)
{
    // n = n * 2;   // ошибка: n — константа
    int m = n * 2;
    printf("n = %d\n", n);
    printf("m = %d\n", m);
}
```

Если попытаться изменить `const`-параметр, компилятор выдаст ошибку. Если нужно вычислить что-то на основе параметра — используйте **отдельную переменную**.

> **Польза `const`.** Это не просто формальность. `const` в параметре:
> - защищает от случайного изменения;
> - документирует намерение («это входные данные, менять не буду»);
> - позволяет компилятору оптимизировать код.

Особенно полезно `const` для **указателей на большие структуры** — об этом в следующих главах.

## Итог

- **Параметры** — часть заголовка функции, описывают, какие данные она принимает.
- При вызове передаются **аргументы** — конкретные значения.
- Соответствие аргументов и параметров — **по позиции**.
- Типы должны совпадать. Несовпадение → компилятор **преобразует**, возможна потеря данных.
- Аргументы передаются **по значению** — функция работает с копиями.
- Изменения параметров внутри функции **не влияют** на оригинальные переменные.
- **`const`** в параметре защищает его от изменения.
