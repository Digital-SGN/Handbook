# Функции

**Функция** — именованный блок кода, который можно вызывать многократно из разных мест программы. Если переменные и константы хранят **состояние** программы, то функции определяют её **действия**.

## Определение функции

Общая форма:

```cpp
тип имя_функции(параметры)
{
    выполняемые_инструкции
}
```

Первая строка — **заголовок** (или **сигнатура**). Разберём по частям:

- **возвращаемый тип** — что функция отдаёт наружу. Если ничего — `void`;
- **имя функции** — идентификатор по тем же правилам, что и переменные;
- **параметры** — список в круглых скобках. Если параметров нет, скобки пустые;
- **тело** — блок кода в фигурных скобках.

Простейшая функция:

```cpp
#include <stdio.h>

void hello()
{
    printf("Hello!\n");
}

int main(void)
{
    return 0;
}
```

Функция `hello`:

- тип `void` — ничего не возвращает;
- без параметров — пустые скобки;
- тело — одна строка `printf`.

Если **запустить эту программу**, на консоль ничего не выведется. `hello` определена, но **не вызывается**.

> **Важно:** определение функции не значит её выполнение. Функция сработает только при **вызове**.

## Вызов функции

Синтаксис вызова:

```cpp
имя_функции(аргументы);
```

В любой программе должна быть функция с фиксированным именем `main` — точка входа. Чтобы `hello` выполнилась, её нужно вызвать **из `main`**:

```cpp
#include <stdio.h>

void hello()
{
    printf("Hello!\n");
}

int main(void)
{
    hello();   // вызов
    hello();   // вызов
    return 0;
}
```

`hello` вызывается дважды, и дважды выводится `Hello!`.

В этом и смысл функций: **вынести повторяющееся действие** в одно место и вызывать многократно.

Поскольку `hello` не имеет параметров, при вызове передаются просто пустые скобки:

```cpp
hello();
```

## Прототип функции

Компилятор должен **знать** о функции **до** её вызова. Если вызов идёт раньше определения — компилятор этого не поймёт:

```cpp
#include <stdio.h>

int main(void)
{
    hello();   // ошибка: компилятор не знает о hello
    return 0;
}

void hello()
{
    printf("Hello!\n");
}
```

Некоторые компиляторы соберут это с предупреждением, некоторые — с ошибкой. В любом случае так писать не стоит.

### Что такое прототип

**Прототип** (или **описание**) — это заголовок функции **без тела**, который сообщает компилятору о её существовании:

```cpp
тип имя_функции(параметры);
```

Для `hello`:

```cpp
void hello(void);
```

Точка с запятой в конце **обязательна**.

### Полный пример с прототипом

```cpp
#include <stdio.h>

// прототип — сообщаем компилятору о функции
void hello(void);

int main(void)
{
    hello();   // вызов разрешён: компилятор знает прототип
    hello();
    return 0;
}

// определение функции — может быть ниже
void hello()
{
    printf("Hello!\n");
}
```

Теперь порядок не важен: главное — **прототип до первого вызова**.

### Пустые скобки vs `void`

Для функции **без параметров** в прототипе указывается `void`:

```cpp
void hello(void);   // правильно
```

Это не то же самое, что пустые скобки:

- `void hello(void)` — параметров нет;
- `void hello()` — в старом C означало «параметры неизвестны» (устаревшая форма).

В современном C **всегда пишите `void`**, если параметров нет.

## Итог

- **Функция** — именованный блок кода, вызываемый по имени.
- Синтаксис: `тип имя(параметры) { тело }`.
- **`void`** вместо типа — функция ничего не возвращает.
- **Вызов:** `имя(аргументы);`.
- Функция выполняется **только при вызове**.
- **Прототип** сообщает компилятору о функции до её определения.
- Прототип: `тип имя(параметры);`.
- Для функции без параметров используйте `void`, а не пустые скобки.
