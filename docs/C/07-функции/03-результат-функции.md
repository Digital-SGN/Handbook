# Результат функции

Функция может **возвращать результат** — значение, которое она отдаёт наружу. Для этого используется оператор **`return`**.

## Формы return

Оператор `return` имеет две формы:

```cpp
return;              // без значения — только для void
return выражение;    // со значением — для всех остальных типов
```

- **`return;`** — используется в функциях с типом `void`.
- **`return выражение;`** — для всех остальных типов.

## Функция без результата

Рассмотрим функцию с типом `void`:

```cpp
void sum(int x, int y)
{
    printf("%d + %d = %d\n", x, y, x + y);
}
```

Явного `return` нет, но компилятор **добавит его автоматически** в конец функции. То есть эта функция **эквивалентна** такой:

```cpp
void sum(int x, int y)
{
    printf("%d + %d = %d\n", x, y, x + y);
    return;
}
```

Обе формы равнозначны.

### Досрочный выход

`return;` можно использовать, чтобы **выйти из функции раньше**:

```cpp
void print_positive(int n)
{
    if (n <= 0) {
        return;   // выходим, если число не положительное
    }
    printf("Positive: %d\n", n);
}
```

Это удобнее, чем городить `else`.

## Функция с результатом

Если тип функции **отличается от `void`**, она должна **вернуть значение** этого типа.

```cpp
#include <stdio.h>

int sum(int x, int y)
{
    return x + y;
}

int main(void)
{
    int x = 25;
    int y = 15;
    int result = sum(x, y);

    printf("%d + %d = %d\n", x, y, result);
    return 0;
}
```

Функция `sum`:

- тип — `int`;
- возвращает `x + y`;
- результат присваивается переменной `result`.

Вывод:

```text
25 + 15 = 40
```

### Использование результата

Возвращённое значение можно:

- **присвоить** переменной:
  ```cpp
  int result = sum(x, y);
  ```
- **передать** в другую функцию:
  ```cpp
  printf("%d\n", sum(x, y));
  ```
- **использовать** в выражении:
  ```cpp
  int total = sum(x, y) + 100;
  ```

### Прототип

```cpp
int sum(int, int);
```

Возвращаемый тип в прототипе **обязателен** — без него компилятор предположит `int` (устаревшее поведение).

> **Что если забыть `return`?** Для функции с типом, отличным от `void`, отсутствие `return` — **неопределённое поведение**. Программа может вернуть «мусор». Всегда проверяйте, что во всех ветках выполнения есть `return`.

## Сложная логика возврата

`return` может стоять **в разных ветках** — тогда функция вернёт разные значения в зависимости от условий:

```cpp
#include <stdio.h>

int calculate(int x, int y, char operation)
{
    if (operation == '+')
    {
        return x + y;
    }
    else if (operation == '-')
    {
        return x - y;
    }
    else
    {
        return 0;
    }
}

int main(void)
{
    int x = 30;
    int y = 10;

    int result1 = calculate(x, y, '+');
    int result2 = calculate(x, y, '-');
    int result3 = calculate(x, y, 'g');

    printf("%d + %d = %d\n", x, y, result1);
    printf("%d - %d = %d\n", x, y, result2);
    printf("%d\n", result3);

    return 0;
}
```

Вывод:

```text
30 + 10 = 40
30 - 10 = 20
0
```

Здесь функция `calculate` принимает три параметра:

- два числа;
- знак операции.

Возвращает:

- сумму для `'+'`;
- разность для `'-'`;
- `0` для всего остального.

### Ранний возврат

`return` прерывает выполнение функции **немедленно**. Это позволяет избавиться от вложенных `else`:

```cpp
int calculate(int x, int y, char operation)
{
    if (operation == '+') return x + y;
    if (operation == '-') return x - y;
    return 0;   // ветка по умолчанию
}
```

Тот же результат, но читается проще.

> **Совет:** если функция большая и содержит много условий — предпочитайте **ранние возвраты**. Так код становится линейным, а не «лестницей» из вложенных блоков.

---

## Итог

- **`return;`** — для функций типа `void`; завершает функцию досрочно.
- **`return выражение;`** — для функций, возвращающих значение.
- Для `void`-функций `return` в конце добавляется компилятором автоматически.
- Если тип функции не `void`, она **обязана** вернуть значение.
- Отсутствие `return` в такой функции — **неопределённое поведение**.
- Возвращённое значение можно присвоить, передать дальше или использовать в выражении.
- **Ранний возврат** упрощает логику — избегайте длинных `else if`-цепочек.
