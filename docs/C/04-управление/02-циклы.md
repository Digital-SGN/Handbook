# Циклы

**Цикл** позволяет выполнить один и тот же блок кода много раз, пока выполняется условие. В C три вида циклов:

- **`for`** — когда известно количество повторений или есть счётчик;
- **`while`** — когда условие проверяется до тела цикла;
- **`do..while`** — когда тело должно выполниться хотя бы один раз.

## Цикл for

Формальная запись:

```cpp
for (инициализация; условие; приращение)
{
    // тело цикла
}
```

Заголовок состоит из **трёх частей**, разделённых `;`:

1. **Инициализация** — выполняется один раз перед началом цикла. Обычно здесь создают счётчик.
2. **Условие** — проверяется перед каждой итерацией. Если истинно — тело выполняется, если нет — цикл завершается.
3. **Приращение** — выполняется после каждой итерации. Обычно увеличивает счётчик.

Пример — вывод чисел от 0 до 5:

```cpp
#include <stdio.h>

int main(void)
{
    for (int i = 0; i < 6; i++)
    {
        printf("%d", i);
    }
    return 0;
}
```

Вывод:

```text
012345
```

Разбор:

- `int i = 0` — счётчик `i` создаётся и инициализируется нулём;
- `i < 6` — цикл выполняется, пока `i` меньше 6;
- `i++` — после каждой итерации `i` увеличивается на 1.

Один проход цикла называется **итерацией**. Здесь было 6 итераций.

### Счётчик не обязан быть `int`

Тип счётчика может быть любым числовым, например `float`. Но на практике почти всегда используют `int` или `size_t` — целочисленные типы работают быстрее и предсказуемее.

### Изменение шага

Приращение не обязано быть `i++`. Можно:

- уменьшать: `i--`;
- увеличивать с шагом: `i += 2`;
- умножать: `i *= 2`.

```cpp
for (int i = 0; i < 10; i += 2)
{
    printf("%d ", i);   // 0 2 4 6 8
}
```

### Пример с квадратами чисел

```cpp
#include <stdio.h>

int main(void)
{
    for (int i = 0; i < 9; i++)
    {
        printf("%d * %d = %d\n", i, i, i * i);
    }
    return 0;
}
```

Вывод:

```text
0 * 0 = 0
1 * 1 = 1
2 * 2 = 4
3 * 3 = 9
4 * 4 = 16
5 * 5 = 25
6 * 6 = 36
7 * 7 = 49
8 * 8 = 64
```

## Пропуск частей заголовка

Любую из трёх частей (или все сразу) можно опустить. Главное — сохранить обе `;`.

```cpp
int i = 1;
for ( ; i < 9 ; )
{
    printf("%d * %d = %d\n", i, i, i * i);
    i++;
}
```

Здесь:

- инициализация вынесена **до** цикла;
- приращение происходит **внутри** тела.

Этот приём иногда полезен, но в большинстве случаев лучше держать все три части в заголовке — так виднее, что происходит.

> **Бесконечный цикл:** если опустить условие, оно трактуется как истина. `for (;;)` — бесконечный цикл. Выход из него — только через `break`, `return` или `goto`.

## Вложенные циклы

Цикл можно поместить внутрь другого цикла. Классический пример — таблица умножения:

```cpp
#include <stdio.h>

int main(void)
{
    for (int i = 1; i < 10; i++)
    {
        for (int j = 1; j < 10; j++)
        {
            printf("%d\t", i * j);
        }
        printf("\n");
    }
    return 0;
}
```

Внешний цикл перебирает строки, внутренний — столбцы. На каждой итерации внешнего цикла внутренний проходит **все свои итерации заново**.

> **Осторожно со сложностью.** Вложенные циклы быстро растут: два цикла по `n` — это `n²` итераций, три — `n³`. Для больших данных это может стать проблемой производительности.

## Цикл while

`while` проверяет условие **до** каждой итерации. Если условие ложно изначально — тело не выполнится ни разу.

```cpp
while (условие)
{
    // тело цикла
}
```

Пример — вывод чисел от 6 до 1:

```cpp
#include <stdio.h>

int main(void)
{
    int i = 6;

    while (i > 0)
    {
        printf("%d\n", i);
        i--;
    }
    return 0;
}
```

Здесь:

- `i > 0` — условие;
- пока оно истинно, выполняются `printf` и `i--`;
- когда `i` станет `0`, цикл завершится.

### Когда использовать while

- когда **количество итераций заранее неизвестно**;
- когда условие зависит от внешних данных (чтение файла, ввод пользователя);
- когда счётчик уже существует по другим причинам.

```cpp
int sum = 0;
int x = 1;

while (x != 0)
{
    scanf("%d", &x);
    sum += x;
}
```

Здесь цикл работает до тех пор, пока пользователь не введёт `0`. Заранее неизвестно, сколько будет итераций.

## Цикл do..while

`do..while` сначала выполняет тело, **потом** проверяет условие. Поэтому тело выполнится **хотя бы один раз**, даже если условие изначально ложно.

```cpp
do
{
    // тело цикла
}
while (условие);
```

Обратите внимание: после `while (условие)` стоит `;` — в отличие от обычного `while`, у которого точки с запятой нет.

Пример:

```cpp
#include <stdio.h>

int main(void)
{
    int i = 6;

    do
    {
        printf("%d", i);
        i--;
    }
    while (i > 0);

    return 0;
}
```

Здесь тело выполнится 6 раз, пока `i` не станет `0`.

Теперь пример, где условие ложно **сразу**:

```cpp
int i = -1;

do
{
    printf("%d", i);
    i--;
}
while (i > 0);
```

Вывод:

```text
-1
```

Несмотря на то, что `i < 0` с самого начала, тело выполнилось **один раз**. Именно этим `do..while` отличается от `while`.

### Когда использовать do..while

- когда действие **должно** выполниться хотя бы один раз;
- меню, где пользователю нужно показать опции и потом спросить выбор;
- валидация ввода — запрашиваем значение, потом проверяем, пока не станет корректным.

## Сравнение трёх циклов

| Цикл | Проверка условия | Минимум итераций |
| :--- | :--- | :--- |
| `for` | до тела | 0 |
| `while` | до тела | 0 |
| `do..while` | после тела | 1 |

### Что выбрать

- **`for`** — если есть счётчик и известно условие завершения (пройти по массиву, вывести диапазон).
- **`while`** — если количество итераций неизвестно заранее.
- **`do..while`** — если тело нужно выполнить хотя бы раз, а потом уже проверять условие.

Любой цикл `for` можно переписать как `while` и наоборот — это вопрос удобства.

## Оператор break

`break` **прерывает** цикл и выходит из него немедленно. Управление переходит к инструкции **после** цикла.

```cpp
int i = 1;

for ( ; ; )
{
    printf("%d * %d = %d\n", i, i, i * i);
    i++;
    if (i > 5) break;
}
```

Здесь цикл формально бесконечный, но выходит по `break`, когда `i` превышает `5`.

Применения `break`:

- выход из «бесконечного» цикла по условию;
- прерывание поиска, когда элемент найден;
- выход из `switch` (см. главу про условные конструкции).

> **Важно:** `break` внутри вложенного цикла прерывает **только внутренний** цикл. Чтобы выйти из внешнего, нужен отдельный механизм (флаг, `goto` или `return`).

## Оператор continue

`continue` **пропускает** остаток тела текущей итерации и переходит к следующей. Цикл при этом не завершается.

Пример — сумма только нечётных чисел от 0 до 9:

```cpp
#include <stdio.h>

int main(void)
{
    int result = 0;

    for (int i = 0; i < 10; i++)
    {
        if (i % 2 == 0) continue;   // пропустить чётные
        result += i;
    }

    printf("result = %d\n", result);   // 25
    return 0;
}
```

Разбор:

- `i % 2 == 0` — проверка на чётность;
- если число чётное, `continue` пропускает сложение;
- если нечётное, `result += i` выполняется.

Сумма нечётных чисел `1 + 3 + 5 + 7 + 9 = 25`.

### Разница между break и continue

| Оператор | Что делает |
| :--- | :--- |
| `break` | **выходит** из цикла полностью |
| `continue` | **пропускает** текущую итерацию и идёт к следующей |

### Замена continue на if

`continue` не обязателен — то же самое можно записать через `if`:

```cpp
for (int i = 0; i < 10; i++)
{
    if (i % 2 != 0)
    {
        result += i;
    }
}
```

Этот вариант иногда читается лучше. Выбирайте по ситуации: `continue` удобен, когда проверок много и они «отсеивают» случаи одна за другой.

## Бесконечные циклы

Цикл, из которого нет выхода, называется **бесконечным**. Способы его создать:

```cpp
for ( ; ; ) { /* ... */ }

while (1) { /* ... */ }

do { /* ... */ } while (1);
```

Бесконечный цикл — не всегда ошибка. Так работают серверы, игровые движки, операционные системы. Главное — чтобы **внутри** был выход по условию (`break`, `return`, `exit`).

> **Осторожно:** случайный бесконечный цикл — одна из самых частых ошибок новичков. Проверьте, что счётчик или условие действительно меняются внутри тела. Если условие всегда истинно — цикл не завершится.

## Итог

- В C три цикла: **`for`**, **`while`**, **`do..while`**.
- **`for`** удобен, когда есть счётчик. Заголовок: `инициализация; условие; приращение`.
- Части заголовка `for` можно опускать, но `;` остаются.
- **Вложенные циклы** работают как таблица: внешний — строки, внутренний — столбцы.
- **`while`** проверяет условие **до** тела — может не выполниться ни разу.
- **`do..while`** проверяет условие **после** тела — выполняется **минимум один раз**.
- **`break`** полностью выходит из цикла, **`continue`** пропускает текущую итерацию.
- `break` во вложенном цикле прерывает только **внутренний**.
- Бесконечный цикл (`for(;;)`, `while(1)`) — нормальный инструмент, если внутри есть выход.
