# Условные конструкции

**Условные конструкции** направляют ход программы по одному из путей в зависимости от условия. В C есть четыре инструмента для этого:

- `if` — выполнить, если условие истинно;
- `if..else` — выбрать одну из двух веток;
- `switch.case` — выбрать одну из многих веток по значению;
- тернарный оператор `?:` — короткая замена `if..else` в выражении.

## Оператор if

Сокращённая форма:

```cpp
if (условие) инструкция;
```

В качестве условия — любое выражение, возвращающее число. Если результат **не равен нулю**, инструкция выполняется. Если равен нулю — пропускается.

```cpp
#include <stdio.h>

int main(void)
{
    if (1) printf("Hello C\n");         // выполнится

    if (0) printf("Hello World\n");     // не выполнится

    return 0;
}
```

Здесь условия — просто числа. `1` — истина, `0` — ложь. Любое ненулевое число трактуется как истина.

На практике условие почти всегда — результат **сравнения** или **логической операции**:

```cpp
#include <stdio.h>

int main(void)
{
    int n = 10;

    if (n == 20) printf("n = 20\n");   // не выполнится
    if (n == 10) printf("n = 10\n");   // выполнится

    return 0;
}
```

`n == 20` возвращает `0` (ложь), `n == 10` — `1` (истина).

> **Частая ошибка:** перепутать `=` и `==`.
> ```cpp
> if (n = 20)    // ошибка: присваивание, условие всегда истинно
> if (n == 20)   // правильно: сравнение
> ```
> Компилятор с `-Wall` предупредит. Не игнорируйте.

## Блок инструкций

Если нужно выполнить **несколько инструкций**, они объединяются фигурными скобками:

```cpp
#include <stdio.h>

int main(void)
{
    int x = 60;

    if (x > 50)
    {
        printf("if statement\n");
        printf("x is greater than 50\n");
    }

    return 0;
}
```

> **Совет:** ставьте фигурные скобки **всегда**, даже если внутри одна инструкция. Это защищает от ошибок при добавлении строк позже и делает код однородным.

## Сложные условия

Условия можно объединять логическими операциями:

```cpp
#include <stdio.h>

int main(void)
{
    int x = 50;
    int y = 60;

    if (x > 20 && y < 100)
    {
        printf("the condition is true\n");
    }

    return 0;
}
```

Здесь `&&` означает: истина, только если **оба** условия верны. Для «хотя бы одного» используют `||`, для отрицания — `!`.

## Оператор else

Если нужно выполнить одни действия при истинном условии, а другие — при ложном, используется форма `if..else`:

```cpp
if (условие)
    инструкция_1
else
    инструкция_2
```

- если условие истинно — выполняется `инструкция_1`;
- если ложно — `инструкция_2`.

```cpp
int x = 60;

if (x > 60)
    printf("x is greater than 60\n");
else
    printf("x is less or equal 60\n");
```

Здесь `x` не больше `60`, поэтому выполнится ветка `else`.

## Конструкция else if

Бывает нужно проверить несколько условий по очереди. Тогда используют `else if`:

```cpp
int x = 60;

if (x > 60)
    printf("x is greater than 60\n");
else if (x < 60)
    printf("x is less than 60\n");
else
    printf("x is equal 60\n");
```

Порядок работы:

1. Проверяется первое условие `x > 60`. Ложь → идём дальше.
2. Проверяется `x < 60`. Ложь → идём дальше.
3. Всё остальное — это `else`: значит, `x == 60`.

Важно: проверяются условия **сверху вниз**, и как только одно истинно — остальные пропускаются.

### Несколько инструкций в каждой ветке

```cpp
#include <stdio.h>

int main(void)
{
    int x = 60;

    if (x > 60)
    {
        printf("if statement\n");
        printf("x is greater than 60\n");
    }
    else if (x < 60)
    {
        printf("else if statement\n");
        printf("x is less than 60\n");
    }
    else
    {
        printf("else statement\n");
        printf("x is equal 60\n");
    }

    return 0;
}
```

Здесь сработает ветка `else`, потому что `x` равно `60`.

## Конструкция switch

`switch..case` — это выбор одной из многих веток по значению. Форма записи:

```cpp
switch (выражение)
{
    case константа_1:
        инструкции_1;
        break;
    case константа_2:
        инструкции_2;
        break;
    default:
        инструкции;
}
```

Как это работает:

1. Вычисляется выражение в скобках.
2. Его значение **последовательно сравнивается** с константами в `case`.
3. При совпадении выполняется соответствующий блок.
4. Если совпадений нет — выполняется `default` (если он есть).

Константы в `case` могут быть типа `char`, `int` или `unsigned`. Пример:

```cpp
#include <stdio.h>

int main(void)
{
    int x = 2;

    switch (x)
    {
        case 1:
            printf("x = 1\n");
            break;
        case 2:
            printf("x = 2\n");
            break;
        case 3:
            printf("x = 3\n");
            break;
    }

    return 0;
}
```

Вывод:

```text
x = 2
```

> **Отличие от `if..else if`.** `switch` сравнивает **на равенство** с конкретными значениями. Нельзя написать `case x > 5:`. Для диапазонов и сложных условий используйте `if..else if`.

## Оператор break

`break` **прерывает** выполнение `switch` и выходит из него. Если его не поставить, выполнение «провалится» в следующий блок — это называется **fall-through**.

Пример **без** `break`:

```cpp
#include <stdio.h>

int main(void)
{
    int x = 2;

    switch (x)
    {
        case 1:
            printf("x = 1\n");
        case 2:
            printf("x = 2\n");
        case 3:
            printf("x = 3\n");
    }

    return 0;
}
```

Вывод:

```text
x = 2
x = 3
```

Так как `x = 2`, начинается с блока `case 2`. Но `break` там нет, поэтому выполнение «проваливается» в `case 3` — и печатается ещё и `x = 3`.

> **Правило:** в конце каждого `case` ставьте `break`, если только fall-through не является намеренным. Намеренный случай комментируйте — иначе это выглядит как баг.

## Блок default

`default` выполняется, если **ни одно** из значений `case` не совпало. Он необязателен, но полезен — обрабатывает «непредвиденные» значения:

```cpp
#include <stdio.h>

int main(void)
{
    int x = 5;

    switch (x)
    {
        case 1:
            printf("x = 1\n");
            break;
        case 2:
            printf("x = 2\n");
            break;
        case 3:
            printf("x = 3\n");
            break;
        default:
            printf("x is undefined\n");
            break;
    }

    return 0;
}
```

Вывод:

```text
x is undefined
```

`default` можно ставить в любом месте `switch`, но по соглашению — в конце. `break` в `default` не обязателен (дальше всё равно ничего нет), но его часто пишут для единообразия.

## Тернарный оператор

**Тернарный оператор** `?:` — короткая замена `if..else`, когда нужно **получить значение**, а не выполнить действие. Форма:

```text
условие ? значение_если_истина : значение_если_ложь
```

Он использует **три** операнда:

- условие;
- что вернуть, если условие истинно;
- что вернуть, если ложно.

```cpp
#include <stdio.h>

int main(void)
{
    int x = 5;
    int y = 2;

    int z = x > y ? x - y : x + y;

    printf("z = %d\n", z);   // z = 3
    return 0;
}
```

Разбор:

- условие — `x > y` (истина, `5 > 2`);
- если истина — вернуть `x - y` = `3`;
- если ложь — вернуть `x + y`.

Результат — `3`, он присваивается переменной `z`.

### Когда использовать

Тернарный оператор удобен для коротких выражений:

```cpp
int max = a > b ? a : b;
const char *result = flag ? "yes" : "no";
```

Но если выражение становится длинным или вложенным — лучше `if..else`. Читаемость важнее краткости.

> **Не путайте:** тернарный оператор возвращает **значение**, а `if` — это **инструкция**. Поэтому `if` нельзя использовать внутри выражения: `int x = if (...) ...` не скомпилируется.

## Итог

- **`if`** выполняет инструкцию, если условие ненулевое.
- Несколько инструкций в ветке объединяются в **блок** `{ }`.
- **`else`** выполняет альтернативную ветку, если условие ложно.
- **`else if`** позволяет проверить несколько условий по очереди.
- **`switch..case`** — выбор по значению. Сравнивает только на равенство с константами.
- **`break`** завершает `switch`. Без него выполнение «проваливается» в следующий `case`.
- **`default`** срабатывает, если ни один `case` не подошёл.
- **Тернарный оператор** `?:` — короткая замена `if..else` в выражениях.
- Ставьте фигурные скобки всегда и не путайте `=` с `==`.
