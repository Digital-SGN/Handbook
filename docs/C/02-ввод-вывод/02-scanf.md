# Ввод в консоли. Функция scanf

**`scanf`** — основная функция ввода в C. Она определена в том же заголовочном файле `stdio.h`, что и `printf`, и работает как бы «зеркально» ей: `printf` выводит данные, `scanf` их читает.

## Форма записи

```cpp
scanf(форматная_строка, аргументы);
```

- **Форматная строка** — в двойных кавычках, содержит спецификации преобразования (`%d`, `%f`, `%s` и т.д.).
- **Аргументы** — **адреса** переменных, в которые нужно записать введённые значения.

Оба параметра обязательны.

Общий вид спецификации:

```text
% * ширина_поля модификатор спецификатор
```

Из всего этого **обязательны** только знак `%` и спецификатор. Остальное опционально.

## Оператор взятия адреса `&`

Ключевое отличие `scanf` от `printf`: ей нужны **адреса** переменных, а не их значения. Функции нужно знать, **куда** записать введённые данные.

Адрес переменной получают с помощью **оператора `&`**:

```cpp
int age = 10;
&age;   // адрес переменной age в памяти
```

Пример ввода числа:

```cpp
#include <stdio.h>

int main(void)
{
    int age;

    printf("Input your age: ");
    scanf("%d", &age);

    printf("age = %d\n", age);
    return 0;
}
```

Диалог с программой:

```text
Input your age: 44
age = 44
```

Разбор: `%d` — спецификатор для `int`, `&age` — адрес переменной.

> **Частая ошибка:** забыть `&`. `scanf("%d", age)` без амперсанда — **неопределённое поведение**: программа попытается записать число по случайному адресу. Компилятор с `-Wall` обычно предупредит.

### Исключение: `%s` и массивы

Для **массивов** `&` не нужен, потому что имя массива уже является адресом первого элемента:

```cpp
char name[10];
scanf("%10s", name);   // без &
```

Это единственное частое исключение. Во всех остальных случаях ставьте `&`.

## Спецификаторы

| Спецификатор | Что читает |
| :--- | :--- |
| `%c` | один символ |
| `%d` | десятичное целое |
| `%i` | целое в любой системе (десятичной, шестнадцатеричной, восьмеричной) |
| `%u` | целое без знака |
| `%f`, `%F` | число с плавающей точкой |
| `%e`, `%E` | то же, но в экспоненциальной записи |
| `%g`, `%G` | то же, в короткой форме |
| `%o` | восьмеричное число |
| `%x`, `%X` | шестнадцатеричное число |
| `%s` | строку |
| `%%` | символ процента |

Пример ввода разных типов:

```cpp
#include <stdio.h>

int main(void)
{
    double price;
    long code;

    printf("Enter the product code: ");
    scanf("%ld", &code);

    printf("Enter the price: ");
    scanf("%lf", &price);

    printf("Product code: %ld\tprice: %.2lf\n", code, price);
    return 0;
}
```

```text
Enter the product code: 1234
Enter the price: 234.567
Product code: 1234      price: 234.57
```

> **Обратите внимание:** для `double` в `scanf` используется `%lf` (с `l`), а в `printf` — просто `%f`. Это редкое расхождение между двумя функциями, о нём легко забыть.

## Ширина поля и модификаторы

### Ширина поля

Число между `%` и спецификатором задаёт **максимум символов**, которые будут прочитаны:

```cpp
scanf("%5d", &num);   // прочитает не больше 5 цифр
```

Полезно, когда ввод ограничен по длине.

### Модификаторы

| Модификатор | Тип |
| :--- | :--- |
| `h` | `short int` (`%hd`) |
| `l` | `long int` (`%ld`) или `double` (`%lf`, `%le`) |
| `L` | `long double` (`%Lf`, `%Le`) |

### Звёздочка `*`

Символ `*` в спецификации **пропускает** вводимое значение — оно читается, но никуда не сохраняется:

```cpp
int day, year;
scanf("%d%*d%d", &day, &year);   // среднее значение пропускается
```

Например, при вводе `15 06 2025` в `day` попадёт `15`, а в `year` — `2025`. Месяц `06` будет прочитан, но проигнорирован.

## Несколько значений за один вызов

За один вызов `scanf` можно прочитать сразу несколько значений. По умолчанию **разделитель — пробел** (а также табуляция и перевод строки).

```cpp
#include <stdio.h>

int main(void)
{
    int count;
    double price;
    long code;

    printf("Enter product data: ");
    scanf("%ld %d %lf", &code, &count, &price);

    printf("Product code: %ld\tcount: %d\tprice: %.2lf\n", code, count, price);
    return 0;
}
```

```text
Enter product data: 1234 3 234.56
Product code: 1234      count: 3        price: 234.56
```

Количество аргументов должно **точно совпадать** с количеством спецификаторов, а их типы — соответствовать. Иначе поведение непредсказуемо.

## Ввод строк

```cpp
#include <stdio.h>

int main(void)
{
    char name[10];

    printf("Enter your name: ");
    scanf("%10s", name);

    printf("Name: %s\n", name);
    return 0;
}
```

Что здесь важно:

- `%10s` — читает **не больше 10 символов**, чтобы не переполнить буфер `name[10]`;
- `name` передан **без `&`**, потому что имя массива — уже адрес.

```text
Enter your name: Tom
Name: Tom
```

### Проблема с пробелами

`%s` читает строку **до первого пробела**. Поэтому составное имя обрежется:

```text
Enter your name: Tom Smith
Name: Tom
```

Всё, что после пробела, останется во входном буфере и попадёт в следующий вызов `scanf`.

## Чтение строки с пробелами

Чтобы прочитать строку **вместе с пробелами**, используют **набор символов** в квадратных скобках:

```cpp
#include <stdio.h>

int main(void)
{
    char name[10];

    printf("Enter your name: ");
    scanf("%10[^\n]", name);

    printf("Name: %s\n", name);
    return 0;
}
```

`%10[^\n]` означает:

- `10` — максимум 10 символов;
- `[^\n]` — читать **до символа перевода строки** (`\n`), то есть до Enter.

Символ `^` внутри `[...]` означает «всё, кроме перечисленного».

```text
Enter your name: Tom Smith
Name: Tom Smith
```

> **Важно:** ширина поля (`10`) здесь **обязательна**. Без неё `%[^\n]` прочитает всю строку целиком, сколько бы её ни было, и переполнит буфер `name`. Переполнение буфера — одна из самых серьёзных уязвимостей в C.

## Подводные камни scanf

`scanf` — мощная, но **опасная** функция. Основные проблемы:

1. **Переполнение буфера.** `%s` без указания ширины читает строку любой длины. Если она длиннее массива — данные запишутся в чужую память. **Всегда указывайте ширину:** `%10s`, `%20[^\n]` и т.п.

2. **Несоответствие типов.** Если спецификатор не соответствует типу аргумента (`%d` для `double` и т.д.) — неопределённое поведение.

3. **Проверка результата.** `scanf` возвращает **число успешно прочитанных значений**. Если пользователь ввёл букву вместо числа, `scanf` вернёт `0` и оставит ввод в буфере. Проверяйте результат:

   ```cpp
   if (scanf("%d", &n) != 1) {
       printf("Ошибка ввода\n");
       return 1;
   }
   ```

4. **Оставшиеся данные в буфере.** Если после `%d` ввести `42abc`, число прочитается, а `abc` останется в буфере и попадёт в следующий `scanf`. Это причина странных «пропущенных» вводов.

5. **`%c` читает любой символ**, включая `\n` от предыдущего ввода. Чтобы прочитать именно символ от пользователя, часто нужно «съесть» перевод строки:

   ```cpp
   scanf(" %c", &c);   // пробел перед %c игнорирует пробельные символы
   ```

> **Рекомендация.** Для учебных примеров `scanf` подходит. В реальных приложениях часто используют `fgets` для строк и `strtol`/`strtod` для чисел — они безопаснее и дают больше контроля над ошибками.

## Итог

- **`scanf`** — основная функция ввода в C; определена в `stdio.h`.
- Ей передают **адреса** переменных через `&`. Исключение — массивы (`%s`, `%[...]`).
- Спецификаторы те же, что у `printf`, но для `double` используется `%lf`.
- Ширина поля (`%5d`, `%10s`) ограничивает количество читаемых символов.
- `%*d` — прочитать и пропустить значение.
- Несколько значений читаются за один вызов, разделитель — пробел.
- `%s` читает до пробела; `%[^\n]` — до конца строки.
- **Всегда указывайте ширину для `%s` и `%[...]`** — иначе переполнение буфера.
- **Проверяйте возвращаемое значение** `scanf` — это количество успешно прочитанных значений.
- Для серьёзных задач используйте `fgets` и `strtol`/`strtod` вместо `scanf`.
