# Консольный вывод. Функция printf

Основной инструмент вывода в C — функция `printf` из заголовочного файла `stdio.h`. Для простых строк всё тривиально, но при выводе чисел, символов и форматировании появляются свои нюансы.

## Форма записи

Общий вид вызова:

```cpp
printf(строка_форматирования, список_аргументов);
```

Первый параметр — строка в двойных кавычках, которая может содержать:

- обычный текст;
- **управляющие последовательности** (начинаются с `\`);
- **спецификации преобразования** (начинаются с `%`).

Простейший случай:

```cpp
#include <stdio.h>

int main(void)
{
    printf("Hello, world!");
    return 0;
}
```

## Управляющие последовательности

Это специальные комбинации символов, начинающиеся с обратного слеша `\`. Они позволяют вставить в строку символы, которые сложно набрать напрямую.

| Последовательность | Значение |
| :--- | :--- |
| `\n` | перевод на новую строку |
| `\t` | табуляция |
| `\r` | возврат каретки в начало строки |
| `\\` | обратный слеш |
| `\'` | одинарная кавычка |
| `\"` | двойная кавычка |

Пример:

```cpp
#include <stdio.h>

int main(void)
{
    printf("The book \"The C Programming Language\"\nBrian Kernighan, Dennis Ritchie");
    return 0;
}
```

Вывод:

```text
The book "The C Programming Language"
Brian Kernighan, Dennis Ritchie
```

## Спецификаторы преобразования

Спецификации преобразования задают формат вывода для конкретного типа данных. Общая форма:

```text
% флаги ширина_поля.точность модификатор спецификатор
```

Из всех компонентов **обязательны только два**: знак `%` и спецификатор. Остальное опционально.

### Основные спецификаторы

| Спецификатор | Для чего |
| :--- | :--- |
| `%c` | один символ (`char`) |
| `%s` | строка |
| `%d`, `%i` | целое со знаком (`int`) |
| `%u` | целое без знака (`unsigned`) |
| `%f`, `%F` | число с плавающей точкой (`float`, `double`) |
| `%e`, `%E` | то же, но в экспоненциальной записи |
| `%g`, `%G` | более короткий из `%e`/`%f` (или `%E`/`%F`) |
| `%o` | восьмеричное число без знака |
| `%x`, `%X` | шестнадцатеричное число (нижний / верхний регистр) |
| `%%` | сам знак процента |

Пример:

```cpp
#include <stdio.h>

int main(void)
{
    float r = 71.8986;
    printf("x = %f\n", r);
    printf("x = %e\n", r);

    char symbol = 'r';
    printf("symbol = %c\n", symbol);

    unsigned int number = 23;
    printf("number = %u\n", number);

    printf("%s\n", "Hello, world");
    return 0;
}
```

Вывод:

```text
x = 71.898598
x = 7.189860e+001
symbol = r
number = 23
Hello, world
```

Значения для спецификаторов передаются вторым и последующими аргументами `printf` — в том же порядке, в каком идут спецификаторы в строке.

> **Важно:** несоответствие спецификатора и типа аргумента — частая ошибка. Компилятор может не предупредить, а программа выведет мусор. Включайте флаги предупреждений (`-Wall -Wextra` в GCC/Clang).

## Ширина поля и точность

Для чисел с плавающей точкой (и не только) можно задать **ширину поля** и **точность**:

```text
%<ширина>.<точность><спецификатор>
```

- **Ширина поля** — минимальное количество символов для вывода.
- **Точность** — количество цифр в дробной части.

```cpp
float r = 71.8986;
printf("x = %4.2f\n", r);   // x = 71.90
```

Здесь `%4.2f` означает:

- `4` — ширина поля (минимум 4 символа);
- `2` — точность (2 цифры после точки);
- `f` — тип `float`/`double`.

Число `71.8986` округляется до `71.90`. Обратите внимание: ширина — **минимум**, а не максимум. Если число не влезает, поле расширится, чтобы вместить его целиком.

## Модификаторы

Модификаторы уточняют **размер** типа аргумента — это нужно, чтобы `printf` правильно прочитал значение из памяти.

| Модификатор | Тип |
| :--- | :--- |
| `h` | `short int` |
| `l` | `long int`, `unsigned long int` |
| `ll` | `long long int`, `unsigned long long int` |
| `L` | `long double` |

Пример:

```cpp
short r = 7100;
printf("x = %hd\n", r);
```

Здесь `%hd` означает «вывести `short`». Без `h` компилятор ожидал бы `int` — на практике это обычно сработало бы за счёт приведения, но формально это неверно.

Для `size_t` используйте `%zu`, для `ptrdiff_t` — `%td`. В главе про типы данных эти спецификаторы уже упоминались.

## Несколько аргументов

За один вызов `printf` можно вывести сразу несколько значений:

```cpp
printf("Name=%s\tAge=%d\tWeight=%3.2f", "Tom", 23, 63.3456);
```

Порядок сопоставления аргументов:

1. первый спецификатор `%s` → первый аргумент `"Tom"`;
2. второй `%d` → второй аргумент `23`;
3. третий `%3.2f` → третий аргумент `63.3456`.

Проще говоря: сколько спецификаторов — столько и аргументов, и они идут строго по порядку.

## Флаги форматирования

Флаги дополнительно управляют выводом. Они ставятся между `%` и шириной поля.

| Флаг | Что делает |
| :--- | :--- |
| `-` | выравнивание по левому краю (по умолчанию — по правому) |
| `+` | всегда выводить знак: `+` или `-` |
| ` ` (пробел) | пробел на месте знака для положительных чисел |
| `#` | для `%o`, `%x`, `%X` — добавляет префикс `0`, `0x`, `0X`; для `%f`, `%g`, `%G` — оставляет точку даже без дробной части |
| `0` | дополняет число нулями слева до нужной ширины |

Пример:

```cpp
#include <stdio.h>

int main(void)
{
    printf("%d\n", 8);
    printf("% d\n", 8);
    printf("%+d\n", +8);
    printf("%#o\n", 8);
    printf("%#f\n", 8.);

    printf("%9s %d\n", "Tom", 38);
    printf("%-9s %d\n", "Tom", 38);

    return 0;
}
```

Вывод:

```text
8
 8
+8
010
8.000000
      Tom 38
Tom       38
```

Что произошло:

- `% d` — добавился пробел перед `8`;
- `%+d` — добавился знак `+`;
- `%#o` — восьмеричное число получило префикс `0`;
- `%#f` — точка осталась, даже без дробной части;
- `%9s` — строка выровнена вправо в поле из 9 символов;
- `%-9s` — то же самое, но по левому краю.

## Итог

- `printf(строка_форматирования, аргументы)` — основная функция вывода в C.
- **Управляющие последовательности** (`\n`, `\t`, `\"` и др.) вставляют специальные символы.
- **Спецификаторы** (`%d`, `%f`, `%s`, ...) задают формат вывода для каждого аргумента.
- **Ширина поля** и **точность** задаются в виде `%<ширина>.<точность><спецификатор>`.
- **Модификаторы** (`h`, `l`, `ll`, `L`) указывают размер типа.
- Можно выводить сразу **несколько значений** — они сопоставляются спецификаторам по порядку.
- **Флаги** (`-`, `+`, `#`, `0`, пробел) управляют выравниванием и знаками.
- Следите за соответствием спецификатора и типа — иначе получите мусор в выводе.
