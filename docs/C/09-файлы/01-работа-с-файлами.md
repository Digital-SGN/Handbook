# Работа с файлами

**Файл** в C — неструктурированная последовательность байтов. С этой точки зрения файлом может быть не только документ на диске, но и принтер, терминал, сетевое соединение. Единый интерфейс для всего этого даёт **`<stdio.h>`**.

## Как работает ввод-вывод

Обмен между программой и диском идёт **блоками** (обычно 256, 512 или 4096 байт — степень двойки).

- **При чтении:** ОС загружает блок в **буфер**, программа берёт из буфера побайтно.
- **При записи:** данные накапливаются в буфере и сбрасываются на диск при заполнении.

Буфер — это область в памяти, поэтому обмен с ним быстрый. Прямое обращение к диску — медленное, и его стараются минимизировать.

**Файл вместе с буфером и позицией чтения/записи называется потоком** (stream).

## Тип `FILE`

Для работы с потоками используется тип **`FILE`** — структура, определённая в `<stdio.h>`. Программа обычно не заглядывает внутрь, а работает с указателем:

```cpp
FILE *fp;
```

Указатель `fp` идентифицирует поток.

## Открытие файла: `fopen`

Прототип:

```cpp
FILE *fopen(const char *filename, const char *mode);
```

- `filename` — путь к файлу (относительный или абсолютный);
- `mode` — режим открытия;
- при неудаче возвращает **`NULL`**.

```cpp
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("data.txt", "w");
    if (fp == NULL) {
        return 1;
    }

    fclose(fp);
    return 0;
}
```

### Пути

- `"data.txt"` — файл в текущей папке;
- `"subdir/data.txt"` — относительный путь;
- `"C:\\data.txt"` — абсолютный (Windows, двойной `\`, потому что `\` — escape-символ);
- `"/home/user/data.txt"` — абсолютный (Linux/macOS).

## Режимы открытия

| Режим | Что делает |
| :--- | :--- |
| `"r"` | Чтение. Файл должен существовать |
| `"w"` | Запись. Если файл есть — **перезаписывается**, если нет — создаётся |
| `"a"` | Дозапись в конец. Файл создаётся, если не существует |
| `"r+"` | Чтение и запись. Файл должен существовать |
| `"w+"` | Чтение и запись. Файл перезаписывается |
| `"a+"` | Чтение и дозапись. Файл создаётся, если не существует |
| `"rb"`, `"wb"`, `"ab"` | То же, но в **бинарном** режиме |
| `"r+b"`, `"w+b"`, `"a+b"` | То же с чтением-записью в бинарном режиме |

### Текстовый vs бинарный режим

- **Текстовый** (`"r"`, `"w"`) — при чтении/записи выполняется преобразование переводов строк: на Windows `\r\n` ↔ `\n`. На Linux/macOS различий почти нет.
- **Бинарный** (`"rb"`, `"wb"`) — байты пишутся и читаются **как есть**, без преобразований.

Для бинарных данных (числа, структуры) **всегда** используйте `"b"`. На Windows без него `\n` превратится в `\r\n`, и файл будет испорчен.

> **Важно:** `"w"` **уничтожает** содержимое файла при открытии. Если не хотите потерять данные — используйте `"a"`.

## Закрытие: `fclose`

```cpp
int fclose(FILE *stream);
```

- возвращает `0` при успехе;
- возвращает **`EOF`** при ошибке.

**Всегда закрывайте файл.** Если не закрыть:

- буфер может не сброситься на диск — данные потеряются;
- дескриптор останется занятым — их число ограничено;
- в долгоживущей программе это приведёт к утечке ресурсов.

При нормальном завершении программы ОС закрывает все открытые файлы, но полагаться на это — плохая практика.

## Обработка ошибок

`fopen` возвращает `NULL` по многим причинам: файла нет, нет прав, кончилось место и т.д. Проверять **обязательно**:

```cpp
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("data.txt", "r");
    if (fp == NULL)
    {
        perror("Error opening data.txt");
        return 1;
    }

    fclose(fp);
    return 0;
}
```

Функция **`perror`** выводит ваше сообщение + системную ошибку:

```text
Error opening data.txt: No such file or directory
```

`perror` берёт текст ошибки из глобальной переменной `errno`, которую выставляют системные вызовы.

### Возврат кода ошибки

Возвращать из `main` **ненулевое** число — стандартный способ сообщить ОС об ошибке:

```cpp
if (fp == NULL) {
    perror("fopen");
    return 1;   // код ошибки
}
```

Соглашение: `0` — успех, ненулевое — ошибка.

## Итог

- Файл — последовательность байтов. С буфером образует **поток**.
- Для работы с потоками — тип **`FILE *`** из `<stdio.h>`.
- **`fopen`** открывает файл, возвращает `NULL` при ошибке.
- Режимы: `"r"`, `"w"`, `"a"`, `"r+"`, `"w+"`, `"a+"` и их бинарные версии (`"rb"` и т.д.).
- `"w"` **уничтожает** содержимое файла. `"a"` — дописывает в конец.
- Для бинарных данных — всегда `"b"`.
- **`fclose`** закрывает файл. Всегда закрывайте.
- **`perror`** выводит описание ошибки. Возвращайте ненулевой код при сбое.
