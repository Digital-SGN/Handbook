# Чтение и запись структур в файл

Структуру можно записать в файл как **набор байтов** — просто скопировав её представление в памяти. Это работает, потому что структура в памяти лежит непрерывным блоком. Но у этого подхода есть **подводные камни**, которые нужно знать.

## Запись структуры

Идея: относиться к структуре как к массиву `char` и записать все её байты.

```cpp
#include <stdio.h>
#include <stdlib.h>

struct person
{
    char name[16];
    int age;
};

int save(const char *filename, const struct person *p)
{
    FILE *fp = fopen(filename, "wb");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    const char *c = (const char *)p;
    size_t size = sizeof(struct person);

    for (size_t i = 0; i < size; i++) {
        putc(c[i], fp);
    }

    fclose(fp);
    return 0;
}

int main(void)
{
    struct person tom = { "Tom Smith", 21 };
    return save("person.dat", &tom);
}
```

Здесь `(const char *)p` — приведение указателя на структуру к указателю на байт. Так мы получаем доступ к отдельным байтам структуры и пишем их по одному.

## Чтение структуры

Обратная операция — прочитать `sizeof(struct person)` байт и положить их в структуру.

```cpp
#include <stdio.h>
#include <stdlib.h>

struct person
{
    char name[16];
    int age;
};

int load(const char *filename)
{
    struct person p;

    FILE *fp = fopen(filename, "rb");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    char *c = (char *)&p;
    size_t size = sizeof(struct person);

    for (size_t i = 0; i < size; i++) {
        int ch = getc(fp);
        if (ch == EOF) {
            fclose(fp);
            fprintf(stderr, "Unexpected end of file\n");
            return 1;
        }
        c[i] = (char)ch;
    }

    fclose(fp);

    printf("%-20s %5d\n", p.name, p.age);
    return 0;
}
```

> **Правильный шаблон чтения:** читайте **в `int`**, проверяйте на `EOF` **до** записи в буфер. Иначе последний байт может оказаться «мусором» от `EOF`, приведённого к `char`.

## Правильный подход: `fread`/`fwrite`

Ручной цикл по байтам — учебный пример. В реальном коде используйте **`fread`/`fwrite`**:

```cpp
#include <stdio.h>

struct person
{
    char name[16];
    int age;
};

int save(const char *filename, const struct person *p)
{
    FILE *fp = fopen(filename, "wb");
    if (fp == NULL) { perror("fopen"); return 1; }

    if (fwrite(p, sizeof(struct person), 1, fp) != 1) {
        perror("fwrite");
        fclose(fp);
        return 1;
    }

    fclose(fp);
    return 0;
}

int load(const char *filename)
{
    struct person p;
    FILE *fp = fopen(filename, "rb");
    if (fp == NULL) { perror("fopen"); return 1; }

    if (fread(&p, sizeof(struct person), 1, fp) != 1) {
        perror("fread");
        fclose(fp);
        return 1;
    }

    fclose(fp);
    printf("%-20s %5d\n", p.name, p.age);
    return 0;
}

int main(void)
{
    struct person tom = { "Tom Smith", 21 };
    save("person.dat", &tom);
    load("person.dat");
    return 0;
}
```

Коротко, безопасно и быстро.

## Подводные камни

Запись структуры как «сырых байтов» **не переносима** между платформами и компиляторами. Причины:

### 1. Выравнивание (padding)

Компилятор может вставить **невидимые байты** между полями для выравнивания. Их значения — мусор, но они попадут в файл.

```cpp
struct example
{
    char c;     // 1 байт
                // 3 байта padding
    int i;      // 4 байта
};
// sizeof(struct example) == 8, а не 5
```

### 2. Порядок байтов (endianness)

На x86 числа хранятся **little-endian**, на некоторых ARM и старых RISC — **big-endian**. Файл, записанный на одной платформе, будет прочитан как мусор на другой.

### 3. Типы фиксированной ширины

`int` может быть 2 или 4 байта. `long` — 4 или 8. Для переносимых форматов используйте типы из **`<stdint.h>`**:

```cpp
#include <stdint.h>

struct person
{
    char name[16];
    int32_t age;   // гарантированно 4 байта
};
```

### 4. Указатели в структуре

Если в структуре есть указатель (`char *name`), в файл уйдёт **адрес**, а не данные. При чтении этот адрес будет указывать в никуда.

**Правило:** для записи в файл в структуре используйте **только** простые типы, массивы фиксированного размера и другие такие же структуры. Никаких `char *`.

### Как сохранять переносимо

- Поля простых типов фиксированной ширины (`int32_t`, `uint16_t`).
- Строки — **массивы `char` фиксированной длины**.
- Если очень нужна переносимость — писать по полям через `fprintf`/`fscanf` в текстовом виде.

## Массив структур

Сохранять несколько структур проще всего через `fwrite` с `nmemb > 1`:

```cpp
#include <stdio.h>

struct person
{
    char name[20];
    int age;
};

int save(const char *filename, const struct person *people, size_t n)
{
    FILE *fp = fopen(filename, "wb");
    if (fp == NULL) { perror("fopen"); return 1; }

    if (fwrite(people, sizeof(struct person), n, fp) != n) {
        perror("fwrite");
        fclose(fp);
        return 1;
    }

    fclose(fp);
    return 0;
}

int main(void)
{
    struct person people[] = {
        { "Tom",   23 },
        { "Alice", 27 },
        { "Bob",   31 },
        { "Kate",  29 }
    };
    size_t n = sizeof(people) / sizeof(people[0]);

    return save("people.dat", people, n);
}
```

Одна строка `fwrite` вместо ручного цикла по байтам.

### Сколько структур в файле

Заранее не известно. Есть **два подхода**:

**1. Хранить количество в начале файла.**

```cpp
// при записи
uint32_t count = (uint32_t)n;
fwrite(&count, sizeof(count), 1, fp);
fwrite(people, sizeof(struct person), n, fp);

// при чтении
uint32_t count;
fread(&count, sizeof(count), 1, fp);
struct person *people = malloc(count * sizeof(struct person));
fread(people, sizeof(struct person), count, fp);
```

**2. Вычислить из размера файла.**

```cpp
fseek(fp, 0, SEEK_END);
long size = ftell(fp);
fseek(fp, 0, SEEK_SET);
size_t n = size / sizeof(struct person);
```

Второй способ проще, но требует, чтобы в файле были **только** структуры, без заголовков.

> **Что не так у Метанита.** В исходном примере структуры читаются **побайтно** в цикле `while ((*c = getc(fp)) != EOF) c++;`. Это:
> - медленно (побайтовые операции);
> - **опасно**: если файл окажется больше выделенного буфера, произойдёт **переполнение памяти**;
> - неверно обрабатывает `EOF` для `char` (см. выше).
>
> Используйте `fread` и заранее знайте, сколько читать.

## Итог

- Структуру можно писать в файл как набор байтов.
- Учебный способ — побайтно через `putc`/`getc`. **Реальный** — через **`fread`/`fwrite`**.
- Читать **в `int`** и проверять `EOF` **до** записи в буфер.
- «Сырая» запись структуры **не переносима**: padding, endianness, размеры типов.
- Для переносимости — типы из **`<stdint.h>`** и массивы фиксированной длины.
- Указатели в структуре **нельзя** писать в файл — уйдёт адрес, а не данные.
- Массив структур пишется одним вызовом `fwrite` с `nmemb = n`.
- Количество элементов в файле — храните **в начале** или вычисляйте из размера файла.
