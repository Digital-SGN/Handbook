# Текстовые файлы

С текстовыми файлами удобнее работать **построчно**, а не по байтам. Для этого в `<stdio.h>` есть `fgets` и `fputs`.

## Запись строки: `fputs`

Прототип:

```cpp
int fputs(const char *s, FILE *stream);
```

Записывает строку **без завершающего `\0`**. Возвращает неотрицательное число при успехе или `EOF` при ошибке.

```cpp
#include <stdio.h>

int main(void)
{
    const char *message = "Hello, world!\nAn apple a day keeps the doctor away";

    FILE *fp = fopen("data.txt", "w");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    fputs(message, fp);
    fclose(fp);

    printf("File has been written\n");
    return 0;
}
```

Если нужен перевод строки — добавьте `\n` явно. `fputs` сама его **не добавляет** (в отличие от `puts`, которая пишет на консоль и добавляет `\n`).

## Чтение строки: `fgets`

Прототип:

```cpp
char *fgets(char *s, int n, FILE *stream);
```

Читает **не более `n - 1` символов** в буфер `s` или до первого `\n`.

- символ `\n`, если встретился, **остаётся** в буфере;
- в конце всегда добавляется `\0`;
- при успехе возвращает `s`, при ошибке или конце файла — **`NULL`**.

```cpp
#include <stdio.h>

int main(void)
{
    char buffer[256];

    FILE *fp = fopen("data.txt", "r");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    while (fgets(buffer, sizeof(buffer), fp) != NULL)
    {
        printf("%s", buffer);
    }

    fclose(fp);
    return 0;
}
```

### Что важно

- `sizeof(buffer)` — это размер массива, а не «сколько хотим прочитать». `fgets` сам отнимет один байт под `\0`;
- если строка длиннее буфера, `fgets` вернёт **первую часть** без `\n`, а следующая итерация прочитает остаток;
- в отличие от `gets` (которую **нельзя** использовать — она не проверяет размер), `fgets` безопасна.

> **Никогда не используйте `gets`.** Эта функция читает строку **любой длины** без контроля буфера — переполнение почти гарантировано. Её **удалили** из стандарта C11. Только `fgets`.

## Форматированный ввод-вывод: `fprintf` / `fscanf`

Работают как `printf`/`scanf`, но с файлом:

```cpp
int fprintf(FILE *stream, const char *format, ...);
int fscanf(FILE *stream, const char *format, ...);
```

### Пример: сохранение структуры в текстовом виде

```cpp
#include <stdio.h>

struct person
{
    char name[32];
    int age;
};

int main(void)
{
    struct person people[] = {
        { "Tom",   23 },
        { "Alice", 27 },
        { "Bob",   31 }
    };
    size_t n = sizeof(people) / sizeof(people[0]);

    // запись
    FILE *fp = fopen("people.txt", "w");
    if (fp == NULL) { perror("fopen"); return 1; }

    for (size_t i = 0; i < n; i++) {
        fprintf(fp, "%s %d\n", people[i].name, people[i].age);
    }
    fclose(fp);

    // чтение
    fp = fopen("people.txt", "r");
    if (fp == NULL) { perror("fopen"); return 1; }

    struct person p;
    while (fscanf(fp, "%31s %d", p.name, &p.age) == 2) {
        printf("%s, %d\n", p.name, p.age);
    }
    fclose(fp);

    return 0;
}
```

### `%31s` — ограничение ширины

В `fscanf` **всегда указывайте ширину для строк**:

```cpp
fscanf(fp, "%31s", p.name);   // прочитает максимум 31 символ + \0
```

Без этого `fscanf("%s", ...)` переполнит буфер, если в файле длинное слово.

### Проверяйте возврат `fscanf`

`fscanf` возвращает **число успешно прочитанных значений**. Если оно не совпадает с ожидаемым — была ошибка. Это стандартный способ писать цикл:

```cpp
while (fscanf(fp, "%31s %d", p.name, &p.age) == 2) {
    // обработать p
}
```

## Копирование файлов

Классический пример — побайтовое или построчное копирование:

```cpp
#include <stdio.h>

int main(void)
{
    const char *src = "data1.txt";
    const char *dst = "data2.txt";
    char buffer[256];

    FILE *f1 = fopen(src, "r");
    if (f1 == NULL) { perror("fopen src"); return 1; }

    FILE *f2 = fopen(dst, "w");
    if (f2 == NULL) {
        perror("fopen dst");
        fclose(f1);
        return 1;
    }

    while (fgets(buffer, sizeof(buffer), f1) != NULL)
    {
        fputs(buffer, f2);
    }

    fclose(f1);
    fclose(f2);
    return 0;
}
```

### Что важно при копировании

- **Закрывайте оба файла**, даже если второй `fopen` не удался — не забудьте `fclose(f1)` в обработке ошибки;
- Если файл открыт в `"w"`, его содержимое **уже уничтожено** при открытии. Если потом окажется, что `f1` не открылся — данные потеряны безвозвратно. В серьёзных утилитах сначала читают, потом пишут во временный файл, затем переименовывают.

### Более короткий вариант: `fread`/`fwrite`

```cpp
char buffer[4096];
size_t n;
while ((n = fread(buffer, 1, sizeof(buffer), f1)) > 0) {
    fwrite(buffer, 1, n, f2);
}
```

Этот вариант **работает и для текстовых, и для бинарных** файлов, и быстрее построчного чтения.

## Итог

- **`fputs`** — записывает строку без `\0`. `\n` добавляйте вручную.
- **`fgets`** — читает не более `n-1` символов, включая `\n`; безопасная замена `gets`.
- **`gets` использовать нельзя** — удалена из стандарта.
- **`fprintf` / `fscanf`** — как `printf`/`scanf`, но для файлов.
- В `fscanf` для строк **всегда указывайте ширину**: `%31s`, не `%s`.
- Проверяйте **возврат `fscanf`** — он говорит, сколько значений прочитано.
- Копирование: построчно через `fgets`/`fputs` или блоками через `fread`/`fwrite`.
- В обработке ошибок не забывайте закрывать **уже открытые** файлы.
