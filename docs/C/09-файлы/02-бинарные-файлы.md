# Бинарные файлы

С бинарными файлами работают **побайтово**. Один `char` = один байт, поэтому функции `putc`/`getc` естественным образом пишут и читают отдельные байты.

Для удобства в `<stdio.h>` есть и блочные функции — **`fread`** и **`fwrite`**. Они позволяют читать/писать сразу кусками памяти.

## Побайтовая запись: `putc`

Прототип:

```cpp
int putc(int c, FILE *stream);
```

Записывает один байт (значение `int` приводится к `unsigned char`). Возвращает записанный байт или `EOF` при ошибке.

```cpp
#include <stdio.h>

int main(void)
{
    const char *message = "Hello, world!";
    FILE *fp = fopen("data.bin", "wb");

    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    for (const char *p = message; *p != '\0'; p++)
    {
        putc(*p, fp);
    }

    fclose(fp);
    return 0;
}
```

## Побайтовое чтение: `getc`

Прототип:

```cpp
int getc(FILE *stream);
```

Возвращает следующий байт или **`EOF`** в конце файла или при ошибке.

```cpp
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("data.bin", "rb");

    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    int c;
    while ((c = getc(fp)) != EOF)
    {
        putchar(c);   // выводим символ на консоль
    }

    fclose(fp);
    return 0;
}
```

> **Почему `int`, а не `char`?** Потому что `EOF` — отрицательное значение (обычно `-1`), которое не помещается в `unsigned char`. Если объявить `char cpp`, можно спутать «настоящий» байт `0xFF` с `EOF`. Функции `getc` возвращают `int` именно по этой причине.

## Конец файла: `EOF`

`EOF` — константа, определённая в `<stdio.h>`. Обычно равна `-1`. Функции ввода возвращают её, когда достигнут конец файла или произошла ошибка.

Проверять нужно через сравнение с `EOF` **в переменной `int`**:

```cpp
int c;
while ((c = getc(fp)) != EOF) { ... }
```

## Блочный ввод-вывод: `fread` и `fwrite`

Для больших объёмов данных побайтовые операции **медленные**. Лучше использовать блочные:

```cpp
size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);
```

- `ptr` — адрес буфера в памяти;
- `size` — размер одного элемента в байтах;
- `nmemb` — количество элементов;
- возвращают **число успешно прочитанных/записанных элементов**.

### Пример: запись массива `int`

```cpp
#include <stdio.h>

int main(void)
{
    int data[] = { 1, 2, 3, 4, 5 };
    size_t count = sizeof(data) / sizeof(data[0]);

    FILE *fp = fopen("numbers.bin", "wb");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    size_t written = fwrite(data, sizeof(int), count, fp);
    if (written != count) {
        perror("fwrite");
    }

    fclose(fp);
    return 0;
}
```

### Пример: чтение массива `int`

```cpp
#include <stdio.h>

int main(void)
{
    int data[5];
    size_t count = sizeof(data) / sizeof(data[0]);

    FILE *fp = fopen("numbers.bin", "rb");
    if (fp == NULL) {
        perror("fopen");
        return 1;
    }

    size_t read = fread(data, sizeof(int), count, fp);
    printf("Read %zu items\n", read);

    for (size_t i = 0; i < read; i++) {
        printf("%d ", data[i]);
    }

    fclose(fp);
    return 0;
}
```

### Как читать файл неизвестного размера

Если заранее неизвестно, сколько в файле элементов, читают **поблочно** до `fread == 0`:

```cpp
int buffer[100];
size_t n;

while ((n = fread(buffer, sizeof(int), 100, fp)) > 0)
{
    for (size_t i = 0; i < n; i++) {
        printf("%d ", buffer[i]);
    }
}
```

`fread` возвращает **`0`** в конце файла — тогда выходим из цикла.

### Определение конца: `feof`

```cpp
if (feof(fp)) {
    printf("Достигнут конец файла\n");
}
```

> **Не пишите так:**
> ```cpp
> while (!feof(fp)) {
>     fread(...);
>     // обработка
> }
> ```
> `feof` устанавливается **после** неудачного чтения. В такой конструкции последняя итерация обработает **невалидные** данные. Проверяйте результат `fread`/`fgets`.

## Что выбрать

| Ситуация | Инструмент |
| :--- | :--- |
| Побайтовая обработка, потоковая фильтрация | `getc` / `putc` |
| Массивы, структуры, большие блоки | `fread` / `fwrite` |
| Текстовые строки | `fgets` / `fputs` (см. главу про текстовые файлы) |

> **Правило:** если данные — это **массив однотипных элементов**, используйте `fread`/`fwrite`. Побайтовые операции оставьте для потоковых задач (например, hex-дампер или кодировщик).

## Итог

- **`putc`** — записать один байт, **`getc`** — прочитать один байт.
- Обе работают с `int`, а не с `char` — из-за `EOF`.
- **`EOF`** — константа `-1`, признак конца файла или ошибки.
- **`fread`** и **`fwrite`** — блочные операции: быстрее для массивов и структур.
- `fread` возвращает **число прочитанных элементов**, `0` — конец файла.
- **`feof`** проверяет флаг конца файла — но **после** неудачного чтения. Не полагайтесь на неё в условии цикла.
- Для бинарных файлов всегда используйте режим с **`b`**.
