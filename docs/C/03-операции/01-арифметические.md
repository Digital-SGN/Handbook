# Арифметические операции

C поддерживает все основные арифметические операции. Числа, участвующие в операции, называются **операндами**.

| Операция | Знак | Пример |
| :--- | :---: | :--- |
| Сложение | `+` | `a + b` |
| Вычитание | `-` | `a - b` |
| Умножение | `*` | `a * b` |
| Деление | `/` | `a / b` |
| Остаток от деления | `%` | `a % b` |
| Инкремент | `++` | `++a`, `a++` |
| Декремент | `--` | `--a`, `a--` |

## Сложение, вычитание, умножение

```cpp
#include <stdio.h>

int main(void)
{
    int a = 67;
    int b = 33;

    int sum = a + b + 7;      // 107
    int diff = a - b;         // 34
    int mul = 15 * 3;         // 45

    printf("a + b + 7 = %d\n", sum);
    printf("a - b = %d\n", diff);
    printf("15 * 3 = %d\n", mul);
    return 0;
}
```

Операции можно комбинировать и использовать константы прямо в выражениях.

## Деление

```cpp
#include <stdio.h>

int main(void)
{
    int a = 15 / 3;         // 5
    float d = 34.0 / 3.0;   // 11.333333

    printf("a = %d\n", a);
    printf("d = %f\n", d);
    return 0;
}
```

### Целочисленное деление

Главная ловушка: если **оба операнда целые**, результат тоже будет целым — дробная часть **отбрасывается** (не округляется, а именно отбрасывается).

```cpp
float f = 10 / 4;
printf("f = %f\n", f);   // 2.0, а не 2.5
```

Здесь `10 / 4` сначала вычисляется как целое число (`2`), и только потом результат превращается в `float`. Именно поэтому получается `2.0`, а не `2.5`.

Чтобы получить вещественный результат, **хотя бы один операнд** должен быть вещественным:

```cpp
float f = 10.0 / 4;
printf("f = %f\n", f);   // 2.5
```

> **Совет:** если хотите вещественный результат, пишите `10.0 / 4` или `10 / 4.0` — но не `(float)(10 / 4)`. Приведение сработает уже после целочисленного деления и не поможет.

### Деление на ноль

Деление целого числа на ноль — **неопределённое поведение**. Программа может упасть, а может выдать мусор — зависит от платформы. Всегда проверяйте делитель, если он может быть нулём.

## Остаток от деления

Операция `%` возвращает **остаток** от деления одного числа на другое.

```cpp
int a = 35 % 3;   // 2  (35 = 3 * 11 + 2)
```

Операция работает **только с целыми числами**. Применять `%` к `float` или `double` нельзя — компилятор выдаст ошибку.

Типичные применения `%`:

- проверка чётности: `if (x % 2 == 0)`;
- циклический доступ к элементам массива;
- разбиение числа на цифры.

> **Особенность:** остаток от деления отрицательных чисел зависит от компилятора. По стандарту C99 знак результата совпадает со знаком делимого, но полагаться на это без необходимости не стоит.

## Приоритет операций

Операции `*`, `/` и `%` имеют **более высокий приоритет**, чем `+` и `-`. Это значит, что они выполняются раньше.

```cpp
int a = 8;
int b = 7;
int c = a + 5 * b;   // 43
```

Порядок вычисления:

1. `5 * b = 35`;
2. `a + 35 = 43`.

### Скобки

Скобки **переопределяют** порядок операций: то, что внутри скобок, вычисляется раньше.

```cpp
int c = (a + 5) * b;   // 91
```

Порядок:

1. `a + 5 = 13`;
2. `13 * b = 91`.

> **Совет:** не полагайтесь на память при сложных выражениях — расставляйте скобки. Это делает код однозначным и не мешает читать.

## Инкремент и декремент

**Инкремент** `++` увеличивает значение переменной на 1. **Декремент** `--` — уменьшает на 1. Это унарные операции, то есть работают с одним операндом.

У каждой операции две формы: **префиксная** (знак перед переменной) и **постфиксная** (знак после переменной). Разница — в том, **какое значение получает выражение**.

### Префиксный инкремент: `++x`

Сначала значение увеличивается, потом используется как значение выражения.

```cpp
int a = 8;
int b = ++a;
printf("a = %d\n", a);   // 9
printf("b = %d\n", b);   // 9
```

### Постфиксный инкремент: `x++`

Значение выражения — **старое**, а переменная увеличивается уже после.

```cpp
int a = 8;
int b = a++;
printf("a = %d\n", a);   // 9
printf("b = %d\n", b);   // 8
```

### Префиксный декремент: `--x`

```cpp
int a = 8;
int b = --a;
printf("a = %d\n", a);   // 7
printf("b = %d\n", b);   // 7
```

### Постфиксный декремент: `x--`

```cpp
int a = 8;
int b = a--;
printf("a = %d\n", a);   // 7
printf("b = %d\n", b);   // 8
```

### Сводная таблица

| Форма | Что делает | Значение выражения |
| :--- | :--- | :--- |
| `++a` | `a = a + 1` | новое значение `a` |
| `a++` | `a = a + 1` | старое значение `a` |
| `--a` | `a = a - 1` | новое значение `a` |
| `a--` | `a = a - 1` | старое значение `a` |

### Комбинированные выражения

Инкремент можно использовать внутри более сложных выражений:

```cpp
int a = 8;
int b = 7;
int c = a+++b;

printf("a = %d\n", a);   // 9
printf("b = %d\n", b);   // 7
printf("c = %d\n", c);   // 15
```

Как это разбирается? Компилятор читает `a+++b` по правилу **максимального сцепления** (maximal munch): он набирает как можно более длинный корректный токен. Сначала получается `a++`, потом `+b`. То есть фактически:

```cpp
int c = (a++) + b;
```

Аналогично `a---b` разбирается как `(a--) - b`.

> **Не пишите так.** Выражение `a+++b` работает, но читать его крайне тяжело. Расставьте пробелы: `(a++) + b` — гораздо понятнее и не зависит от тонкостей лексического анализа.

### Побочные эффекты и точки следования

Выражение `i = i++ + ++i;` — **неопределённое поведение** в C. Результат зависит от компилятора. Избегайте изменять одну и ту же переменную несколько раз внутри одного выражения.

## Итог

- В C есть пять базовых арифметических операций: `+`, `-`, `*`, `/`, `%`.
- **Деление целых** отбрасывает дробную часть. Чтобы получить вещественный результат, один из операндов должен быть вещественным.
- `%` работает **только с целыми** и возвращает остаток от деления.
- Операции `*`, `/`, `%` имеют **более высокий приоритет**, чем `+` и `-`.
- **Скобки** меняют порядок вычисления — используйте их для читаемости.
- `++` и `--` бывают **префиксные** (сначала меняют, потом отдают значение) и **постфиксные** (сначала отдают значение, потом меняют).
- Старайтесь **не изменять одну переменную несколько раз** в одном выражении — это неопределённое поведение.
