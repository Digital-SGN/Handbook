# Операции присваивания

**Присваивание** — одна из базовых групп операций в C. У неё два операнда, причём **левый должен быть изменяемым** — обычно это переменная. Выражение `5 = x` не скомпилируется: нельзя присвоить значение числу или результату вычисления.

## Базовая операция `=`

Операция `=` присваивает значение **правого** операнда **левому**:

```cpp
int x = 2 + 5;
```

Здесь `2 + 5` — правый операнд, его значение (`7`) присваивается переменной `x`.

### Преобразование типов

Типы правого и левого операнда не обязаны совпадать. Если они различаются, компилятор **попытается преобразовать** значение правого операнда к типу левого:

```cpp
int a = 3.99;    // a = 3 — дробная часть отбрасывается
double b = 5;    // b = 5.0 — целое превращается в дробное
```

Такие преобразования иногда приводят к потере данных — компилятор может предупредить об этом флагом `-Wconversion`.

## Множественное присваивание

Присваивание — это **выражение**, а не только инструкция. Оно возвращает присвоенное значение, поэтому цепочки работают:

```cpp
int a, b, c;
a = b = c = 34 + 7;
```

Порядок вычисления — **справа налево**:

1. `c = 34 + 7` → `c` получает `41`, выражение возвращает `41`;
2. `b = 41` → `b` получает `41`;
3. `a = 41` → `a` получает `41`.

В итоге все три переменные равны `41`.

> **Совет:** не увлекайтесь длинными цепочками. В отладке неудобно, а читаемость падает. Если значения логически разные — пишите отдельные присваивания.

## Составные операции присваивания

Все остальные операции присваивания — это **сокращённая запись** операции `=` вместе с другой операцией. Общий вид:

```text
A <оп>= B   эквивалентно   A = A <оп> B
```

| Операция | Что делает | Эквивалент |
| :--- | :--- | :--- |
| `+=` | присваивание после сложения | `A = A + B` |
| `-=` | присваивание после вычитания | `A = A - B` |
| `*=` | присваивание после умножения | `A = A * B` |
| `/=` | присваивание после деления | `A = A / B` |
| `%=` | присваивание после остатка от деления | `A = A % B` |
| `<<=` | присваивание после сдвига влево | `A = A << B` |
| `>>=` | присваивание после сдвига вправо | `A = A >> B` |
| `&=` | присваивание после поразрядного И | `A = A & B` |
| `\|=` | присваивание после поразрядного ИЛИ | `A = A \| B` |
| `^=` | присваивание после исключающего ИЛИ | `A = A ^ B` |

> **Про битовые операции.** Операции `<<`, `>>`, `&`, `|`, `^` — это **битовые операции**. Они работают с отдельными разрядами числа. Подробно они разбираются в отдельной главе — здесь достаточно знать, что есть сокращённая запись и для них.

### Зачем это нужно

- **Короче** — `a += 10` вместо `a = a + 10`.
- **Меньше шансов ошибиться** — не нужно дважды писать имя переменной.
- **Понятнее** — сразу видно, что переменная **обновляется**, а не перезаписывается новым значением.

## Примеры

```cpp
int a = 5;

a += 10;    // 15
a -= 3;     // 12
a *= 2;     // 24
a /= 6;     // 4
a <<= 4;    // 64
a >>= 2;    // 16
```

Разберём по шагам:

| Шаг | Выражение | Значение `a` |
| :--- | :--- | :--- |
| 0 | `int a = 5` | 5 |
| 1 | `a += 10` | 15 |
| 2 | `a -= 3` | 12 |
| 3 | `a *= 2` | 24 |
| 4 | `a /= 6` | 4 |
| 5 | `a <<= 4` | 64 |
| 6 | `a >>= 2` | 16 |

### Полный пример

```cpp
#include <stdio.h>

int main(void)
{
    int a = 5;

    a += 10;
    printf("a += 10 → %d\n", a);   // 15

    a -= 3;
    printf("a -= 3  → %d\n", a);   // 12

    a *= 2;
    printf("a *= 2  → %d\n", a);   // 24

    a /= 6;
    printf("a /= 6  → %d\n", a);   // 4

    return 0;
}
```

## Итог

- Операция `=` присваивает значение **правого** операнда **левому**.
- Левый операнд должен быть **изменяемым** — обычно это переменная.
- Если типы не совпадают, компилятор **преобразует** значение правого операнда к типу левого.
- Присваивание возвращает значение — поэтому возможны **цепочки** `a = b = cpp = 41`.
- **Составные операции** (`+=`, `-=`, `*=`, `/=`, `%=` и др.) — сокращённая запись `A = A <оп> B`.
- Составные операции короче, безопаснее и лучше показывают **намерение обновить** переменную.
- Битовые составные операции (`<<=`, `>>=`, `&=`, `|=`, `^=`) разбираются в отдельной главе.
