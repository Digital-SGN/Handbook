# Логические операции и операции отношения

**Операции отношения** (их ещё называют операциями сравнения) и **логические операции** работают с понятиями «истина» и «ложь». В C нет отдельного логического типа:

- **истина** — любое ненулевое значение, обычно `1`;
- **ложь** — `0`.

Результатом операции отношения или логической операции всегда является `0` или `1` типа `int`.

## Операции отношения

Операции отношения сравнивают два значения и возвращают `1`, если условие истинно, и `0`, если ложно.

| Операция | Знак | Значение |
| :--- | :---: | :--- |
| Равно | `==` | `1`, если операнды равны |
| Не равно | `!=` | `1`, если операнды не равны |
| Больше | `>` | `1`, если левый больше правого |
| Меньше | `<` | `1`, если левый меньше правого |
| Больше или равно | `>=` | `1`, если левый больше или равен правому |
| Меньше или равно | `<=` | `1`, если левый меньше или равен правому |

Пример:

```cpp
#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 4;

    int c = a == b;              // 0 — числа не равны
    printf("c = %d\n", c);

    int num = 5;
    int result = num == 2 + 3;   // 1 — 5 == 5
    printf("result = %d\n", result);

    printf("10 != 4 → %d\n", 10 != 4);   // 1
    printf("4  != 4 → %d\n", 4  != 4);   // 0
    printf("10 >  4 → %d\n", 10 >  4);   // 1
    printf("10 <  4 → %d\n", 10 <  4);   // 0
    printf("10 <= 4 → %d\n", 10 <= 4);   // 0
    printf("10 >= 4 → %d\n", 10 >= 4);   // 1

    return 0;
}
```

Обратите внимание на второй пример: `num == 2 + 3` — сначала вычисляется `2 + 3`, потом выполняется сравнение. Сложение имеет более высокий приоритет, чем `==`.

> **Частая ошибка:** путать `=` (присваивание) и `==` (сравнение).
> ```cpp
> if (a = 5)   // ошибка: присваивание, а не сравнение — условие всегда истинно
> if (a == 5)  // правильно: сравнение
> ```
> Компилятор с флагом `-Wall` обычно предупреждает об этом. Не игнорируйте такие предупреждения.

## Логические операции

Логические операции объединяют несколько условий. Операндами могут быть как результаты сравнений, так и любые числа.

| Операция | Знак | Возвращает `1`, когда... | Возвращает `0`, когда... |
| :--- | :---: | :--- | :--- |
| Отрицание (НЕ) | `!` | операнд равен `0` | операнд не равен `0` |
| Конъюнкция (И) | `&&` | оба операнда не равны `0` | хотя бы один равен `0` |
| Дизъюнкция (ИЛИ) | `\|\|` | хотя бы один операнд не равен `0` | оба равны `0` |

### Отрицание `!`

```cpp
int c = !2;   // 0
int d = !0;   // 1
```

`!2` даёт `0`, потому что `2` — это «истина». `!0` даёт `1`, потому что `0` — это «ложь».

### Конъюнкция `&&`

```cpp
int c = -2 && 5;   // 1 — оба не нули
int d = 0 && 7;    // 0 — один из операндов нулевой
```

### Дизъюнкция `||`

```cpp
int c = -2 || 5;   // 1
int d = 0 || 7;    // 1
int e = 0 || 0;    // 0
```

> **Важно:** в C **любое ненулевое** значение трактуется как «истина». Поэтому `-2 && 5` — это `1`, а не что-то другое. Отрицательные числа тоже «истинны».

### Сокращённое вычисление

`&&` и `||` используют **сокращённое вычисление** (short-circuit evaluation):

- в `a && b` правый операнд не вычисляется, если левый равен `0` — результат уже ясен;
- в `a || b` правый операнд не вычисляется, если левый не равен `0`.

Это не просто оптимизация — на этом строится целый приём:

```cpp
if (ptr != NULL && *ptr == 5) {
    // *ptr безопасно разыменовать, только если ptr не NULL
}
```

Если бы `&&` всегда вычислял оба операнда, разыменование `NULL` привело бы к падению.

## Приоритет операций

Операции отношения имеют **более высокий приоритет**, чем логические. Поэтому можно писать без скобок:

```cpp
int d = -2 > 5 && 0 < 7 || 0 == 0;   // 1
```

Порядок вычисления:

1. `-2 > 5` → `0`;
2. `0 < 7` → `1`;
3. `0 == 0` → `1`;
4. `0 && 1` → `0`;
5. `0 || 1` → `1`.

То же самое, но с явными скобками:

```cpp
int d = ((-2 > 5) && (0 < 7)) || (0 == 0);   // 1
```

### Порядок приоритетов (от высокого к низкому)

1. `!`
2. `>`, `<`, `>=`, `<=`
3. `==`, `!=`
4. `&&`
5. `||`

> **Совет:** даже если помните приоритеты — расставляйте скобки. Скобки делают намерение явным и избавляют читателя от необходимости держать таблицу приоритетов в голове.

## Сочетание условий

Полный пример с несколькими условиями:

```cpp
#include <stdio.h>

int main(void)
{
    int a = -2 > 5;          // 0
    int b = 0 < 7;           // 1
    int c = 0 == 0;          // 1
    int d = a && b || c;     // 1

    printf("a = %d\n", a);
    printf("b = %d\n", b);
    printf("c = %d\n", c);
    printf("d = %d\n", d);
    return 0;
}
```

Вывод:

```text
a = 0
b = 1
c = 1
d = 1
```

Разбор `d = a && b || c`:

1. `a && b` → `0 && 1` → `0`;
2. `0 || c` → `0 || 1` → `1`.

### Как избежать путаницы

`&&` и `||` — это не то же самое, что «и» и «или» в обычной речи. Если выражение становится длинным, лучше:

- разбить его на несколько переменных с говорящими именами;
- расставить скобки;
- вынести часть в отдельную функцию.

Код, который легко читается, обычно и работает правильно.

## Итог

- В C нет отдельного логического типа: **истина** — любое ненулевое значение, **ложь** — `0`.
- Результат операции отношения или логической операции — `int` со значением `0` или `1`.
- Операции отношения: `==`, `!=`, `>`, `<`, `>=`, `<=`.
- Логические операции: `!`, `&&`, `||`.
- `&&` и `||` используют **сокращённое вычисление** — правый операнд может не вычисляться.
- Операции отношения имеют **более высокий приоритет**, чем логические.
- Не путайте `=` (присваивание) и `==` (сравнение).
- **Расставляйте скобки** — это делает код однозначным.
