# Переменные

Для хранения данных в программе используются **переменные**. У переменной есть три характеристики:

- **тип** — какие данные она хранит;
- **имя** — как к ней обращаться в коде;
- **значение** — что в ней сейчас лежит.

## Определение переменной

Перед использованием любую переменную нужно **определить**. Синтаксис:

```c
тип_переменной имя_переменной;
```

Например:

```c
int number;
```

Здесь определена переменная `number` типа `int`. Определение — это отдельное выражение, поэтому после него ставится `;`.

## Правила именования

Имя переменной может содержать:

- буквы латинского алфавита (`a–z`, `A–Z`);
- цифры (`0–9`);
- знак подчёркивания `_`.

При этом имя **должно начинаться** с буквы или `_`, но не с цифры. Например, так можно:

```c
int _number33;
```

А так — нельзя:

```c
int 33number;   // ошибка
```

### Ограничение на длину

Многие компиляторы ограничивают длину имени. Для одних это 31 символ, для других ограничение жёстче. На практике имена обычно короткие и осмысленные, поэтому до лимита дело доходит редко.

### Регистрозависимость

c — **регистрозависимый** язык. `number` и `Number` — это **две разные** переменные:

```c
int number;
int Number;
```

Поэтому будьте внимательны: `count`, `Count` и `COUNT` — три разных имени.

## Зарезервированные слова

В языке есть набор **зарезервированных слов** (ключевых слов). Их нельзя использовать как имена переменных. Список небольшой:

```text
auto      break     case      char      const
continue  default   do        double    else
enum      extern    float     for       goto
if        int       long      register  return
short     signed    sizeof    static    struct
switch    typedef   union     unsigned  void
volatile  while
```

Также нельзя объявить две переменные с одним и тем же именем в одной области видимости:

```c
int number;
int number;   // ошибка на этапе компиляции
```

## Несколько переменных сразу

Можно определить несколько переменных одного типа одной строкой:

```c
int number1, number2, number3;
```

Здесь определены три переменные типа `int`.

## Присвоение значения

При определении переменной её значение **не определено**. В ней может лежать «мусор» — то, что осталось в памяти от других программ. Поэтому перед первым использованием переменной нужно присвоить ей конкретное значение:

```c
int number;
number = 2;
```

Полный пример:

```c
#include <stdio.h>

int main(void)
{
    int number;
    number = 2;
    printf("number = %d\n", number);
    return 0;
}
```

Вывод:

```text
number = 2
```

Здесь `%d` — **спецификатор формата** для целых чисел. Вместо него `printf` подставляет значение переменной `number`.

> **Важно:** использовать переменную без инициализации — частая причина багов. Если значение неизвестно, лучше сразу присвоить `0`.

## Инициализация

Можно задать значение **сразу при определении** — это называется **инициализацией**:

```c
#include <stdio.h>

int main(void)
{
    int number = 2;
    printf("number = %d\n", number);
    return 0;
}
```

Инициализировать можно и несколько переменных сразу:

```c
#include <stdio.h>

int main(void)
{
    int number1 = 1, number2 = 2, number3 = 3;

    printf("number1 = %d\n", number1);
    printf("number2 = %d\n", number2);
    printf("number3 = %d\n", number3);

    return 0;
}
```

Вывод:

```text
number1 = 1
number2 = 2
number3 = 3
```

### Присвоение vs инициализация

Это два разных понятия:

- **инициализация** — задание значения в момент определения переменной;
- **присвоение** — задание значения уже существующей переменной.

```c
int a = 5;   // инициализация
a = 10;      // присвоение
```

## Итог

- Переменная имеет **тип**, **имя** и **значение**.
- Перед использованием переменную нужно **определить**: `тип имя;`.
- Имя может содержать буквы, цифры и `_`, но не может начинаться с цифры.
- c **регистрозависим**: `number` и `Number` — разные переменные.
- Нельзя использовать **зарезервированные слова** и повторять имена.
- Можно определять **несколько переменных** одной строкой.
- **Инициализация** — задание значения при определении, **присвоение** — после.
- Для вывода целых чисел используется спецификатор `%d`.
- Неинициализированную переменную использовать нельзя — там может быть «мусор».
