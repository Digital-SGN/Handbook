# Константы

Главное отличие переменной от константы — **возможность менять значение**.

Переменную можно переприсваивать сколько угодно раз:

```cpp
#include <stdio.h>

int main(void)
{
    int number = 2;
    printf("number = %d\n", number);

    number = 55;
    printf("number = %d\n", number);

    number = -23;
    printf("number = %d\n", number);

    return 0;
}
```

Вывод:

```text
number = 2
number = 55
number = -23
```

## Ключевое слово const

Значение **константы** устанавливается один раз — при объявлении — и больше не меняется. Для определения константы используется ключевое слово `const`:

```cpp
#include <stdio.h>

int main(void)
{
    const int number = 2;
    printf("number = %d\n", number);

    // number = 55;   // ошибка: number — константа, изменить нельзя

    return 0;
}
```

Если попытаться изменить константу, компилятор не соберёт программу:

```text
error: assignment of read-only variable 'number'
```

## Зачем нужны константы

Константы определяют значения, которые **должны оставаться неизменными** на протяжении всей работы программы. Это не только защита от случайной правки, но и самодокументируемый код: по имени сразу видно, что значение менять не предполагается.

Классический пример — число **π**:

```cpp
#include <stdio.h>

int main(void)
{
    const double PI = 3.14159;

    double radius = 5.0;
    double area = PI * radius * radius;

    printf("Площадь круга: %.2f\n", area);
    return 0;
}
```

Число π не меняется никогда — значит, ему место в константе, а не в переменной.

### Соглашение об именовании

Константы принято писать **заглавными буквами**, часто с подчёркиваниями между словами:

```cpp
const int MAX_USERS = 100;
const double PI = 3.14159;
const int BUFFER_SIZE = 1024;
```

Это не требование языка, а соглашение — так сразу видно, что перед вами константа, а не переменная.

## Константы и переменные: что выбрать

| Признак | Переменная | Константа |
| :--- | :--- | :--- |
| Значение меняется | да | нет |
| Ключевое слово | — | `const` |
| Именование | `number`, `count` | `MAX_SIZE`, `PI` |
| Когда использовать | для данных, которые будут меняться | для неизменных значений |

**Правило:** если значение по смыслу неизменно — делайте его константой. Это избавит от случайных правок и сделает код понятнее.

## Итог

- **Переменная** может менять значение многократно.
- **Константа** задаётся один раз через `const` и больше не меняется.
- Попытка изменить константу — **ошибка компиляции**.
- Константы используют для **неизменных значений** (π, лимиты, размеры буферов).
- По соглашению имена констант пишут **заглавными буквами**.
