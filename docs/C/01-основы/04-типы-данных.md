# Типы данных

У каждой переменной есть **тип**. Тип определяет:

- какие значения может хранить переменная;
- сколько байт в памяти она занимает.

В C базовые типы делятся на несколько групп: целочисленные, вещественные, символьные и `void`.

## Целочисленные типы

В C есть несколько целочисленных типов — от самого маленького `char` до `unsigned long long`. Типы бывают **знаковые** (`signed`) и **беззнаковые** (`unsigned`): первые могут хранить отрицательные числа, вторые — только неотрицательные (зато диапазон положительных значений больше).

| Тип | Размер | Диапазон | Псевдонимы |
| :--- | :--- | :--- | :--- |
| `char` | 1 байт | зависит от компилятора | — |
| `signed char` | 1 байт | −128 … 127 | — |
| `unsigned char` | 1 байт | 0 … 255 | — |
| `short` | 2 байта | −32 768 … 32 767 | `short int`, `signed short`, `signed short int` |
| `unsigned short` | 2 байта | 0 … 65 535 | `unsigned short int` |
| `int` | обычно 4 байта | −2 147 483 648 … 2 147 483 647 | `signed int`, `signed` |
| `unsigned int` | обычно 4 байта | 0 … 4 294 967 295 | `unsigned` |
| `long` | 4 или 8 байт | зависит от платформы | `long int`, `signed long`, `signed long int` |
| `unsigned long` | 4 или 8 байт | зависит от платформы | `unsigned long int` |
| `long long` | 8 байт | −9 223 372 036 854 775 808 … 9 223 372 036 854 775 807 | `long long int`, `signed long long`, `signed long long int` |
| `unsigned long long` | 8 байт | 0 … 18 446 744 073 709 551 615 | `unsigned long long int` |

Самый распространённый целочисленный тип — `int`. У него есть псевдонимы `signed int` и `signed`:

```cpp
int age = 38;
signed int number = 2;
signed temps = -3;
```

Все три переменные здесь имеют один и тот же тип `int` — просто записаны через разные псевдонимы.

### О размерах типов

Размеры в таблице — **типичные, но не гарантированные**. Стандарт C задаёт только минимальные требования:

- `short` — минимум 16 бит;
- `int` — минимум 16 бит;
- `long` — минимум 32 бита;
- при этом `sizeof(short) <= sizeof(int) <= sizeof(long)`.

На практике на 64-разрядных Windows, Linux и macOS `int` занимает 4 байта. А вот `long` ведёт себя по-разному: на Windows — 4 байта, на Linux и macOS — 8 байт. Поэтому если важна точная ширина, стоит использовать `sizeof` или типы из `<stdint.h>` (например, `int32_t`, `uint64_t`).

### Выход за диапазон

Значение не должно выходить за пределы своего типа. Например, такая строка вызовет ошибку компиляции:

```cpp
unsigned short int number = -65535;   // ошибка: отрицательное значение для unsigned
```

Компилятор GCC прямо скажет, что значение не входит в диапазон `unsigned short int`.

## Суффиксы целочисленных литералов

По умолчанию любое десятичное число трактуется как `int`, `long` или `long long` — в зависимости от размера. Если число присваивается переменной другого типа, выполняется **преобразование**.

Чтобы явно указать тип литерала, к числу добавляют **суффикс**:

| Суффикс | Тип литерала |
| :--- | :--- |
| `u` или `U` | `unsigned int`, `unsigned long`, `unsigned long long` |
| `ul` или `UL` | `unsigned long`, `unsigned long long` |
| `ll` или `LL` | `long long` |
| `ull` или `ULL` | `unsigned long long` |

Пример:

```cpp
#include <stdio.h>

int main(void)
{
    unsigned number1 = 4294967294u;
    unsigned int number2 = 22U;

    printf("number1 = %u\n", number1);
    printf("number2 = %u\n", number2);
    return 0;
}
```

Тот же результат можно получить и без суффикса — преобразование сработает автоматически:

```cpp
unsigned number1 = 4294967294;
unsigned int number2 = 22;
```

Зачем тогда суффикс? Чтобы **избежать лишнего преобразования** и явно показать намерение. Это особенно полезно, когда число близко к границе диапазона.

### Пример со всеми типами

```cpp
#include <stdio.h>

int main(void)
{
    unsigned short number1 = 1u;
    unsigned short int number2 = 2u;
    short number3 = 3;
    short int number4 = -4;
    signed short number5 = 5;
    signed short int number6 = -6;

    long number7 = -2147483648l;
    long int number8 = -2147483648L;
    signed long number9 = 2147483647l;
    signed long int number10 = 2147483647L;

    unsigned long number11 = 4294967295ul;
    unsigned long int number12 = 4294967295UL;

    long long number13 = -9223372036854775807ll;
    long long int number14 = 9223372036854775807ll;
    signed long long number15 = -9223372036854775807LL;
    signed long long int number16 = 9223372036854775807LL;

    unsigned long long number17 = 18446744073709551615ull;
    unsigned long long int number18 = 18446744073709551615ULL;

    printf("number1 = %hu\n", number1);
    printf("number2 = %hu\n", number2);
    printf("number3 = %d\n", number3);
    printf("number4 = %d\n", number4);
    printf("number5 = %d\n", number5);
    printf("number6 = %d\n", number6);
    printf("number7 = %ld\n", number7);
    printf("number8 = %ld\n", number8);
    printf("number9 = %ld\n", number9);
    printf("number10 = %ld\n", number10);
    printf("number11 = %lu\n", number11);
    printf("number12 = %lu\n", number12);
    printf("number13 = %lld\n", number13);
    printf("number14 = %lld\n", number14);
    printf("number15 = %lld\n", number15);
    printf("number16 = %lld\n", number16);
    printf("number17 = %llu\n", number17);
    printf("number18 = %llu\n", number18);
    return 0;
}
```

## Спецификаторы printf для целых чисел

Каждому типу соответствует свой **спецификатор формата**. Если перепутать — программа выведет мусор или будет вести себя непредсказуемо.

| Тип | Спецификатор |
| :--- | :--- |
| `short` / `unsigned short` | `%hd` / `%hu` |
| `int` | `%d` |
| `unsigned int` | `%u` |
| `long` / `unsigned long` | `%ld` / `%lu` |
| `long long` / `unsigned long long` | `%lld` / `%llu` |
| `char` (как число) | `%d` |
| `char` (как символ) | `%c` |

Для `size_t`, который возвращает `sizeof`, используется `%zu`. В старом коде можно встретить `%lu` — он работает, если `size_t` определён как `unsigned long`, но `%zu` универсальнее.

## Запись чисел в разных системах счисления

C позволяет записывать числа в четырёх системах счисления:

| Система | Префикс | Пример | Значение |
| :--- | :--- | :--- | :--- |
| Двоичная | `0b` | `0b1011` | 11 |
| Восьмеричная | `0` | `013` | 11 |
| Десятичная | — | `11` | 11 |
| Шестнадцатеричная | `0x` / `0X` | `0xB` | 11 |

```cpp
#include <stdio.h>

int main(void)
{
    int code1 = 0b1011;   // двоичная  — 11
    int code2 = 013;      // восьмеричная — 11
    int code3 = 11;       // десятичная — 11
    int code4 = 0xB;      // шестнадцатеричная — 11

    printf("code1 = %d\n", code1);
    printf("code2 = %d\n", code2);
    printf("code3 = %d\n", code3);
    printf("code4 = %d\n", code4);
    return 0;
}
```

Все четыре переменные хранят одно и то же число — 11. Различается только запись в коде.

> **Осторожно с восьмеричной записью.** Число `013` — это не «13 с ведущим нулём», а число 11. Если случайно начать число с нуля, можно получить не то, что ожидали.

## Числа с плавающей точкой

Для вещественных чисел есть три типа:

| Тип | Размер | Диапазон |
| :--- | :--- | :--- |
| `float` | 4 байта | ±3.4E−38 … 3.4E+38 |
| `double` | 8 байт | ±1.7E−308 … 1.7E+308 |
| `long double` | 10 байт (обычно) | ±3.4E−4932 … 1.1E+4932 |

Разделитель целой и дробной части — **точка**, не запятая:

```cpp
#include <stdio.h>

int main(void)
{
    double number = 3.14159;
    printf("number = %f\n", number);
    return 0;
}
```

По умолчанию дробный литерал имеет тип `double`. Чтобы указать другой тип, используют суффиксы:

- `f` — `float`;
- `l` — `long double`.

```cpp
#include <stdio.h>

int main(void)
{
    float number1 = 3.14f;
    long double number2 = 123456.789l;

    printf("number1 = %f\n", number1);
    printf("number2 = %Lf\n", number2);
    return 0;
}
```

Для вывода `float` и `double` используется `%f`, для `long double` — `%Lf`. На некоторых платформах `%Lf` может работать некорректно (например, выводить `0`).

> **Не сравнивайте вещественные числа на равенство.** Из-за особенностей хранения дробных чисел `0.1 + 0.2` не равно `0.3`. Для сравнения используют проверку «разница меньше маленького числа».

## Символы

Для символов есть три типа: `char`, `signed char` и `unsigned char`. На практике обычно используют `char`.

**Знаковый он или беззнаковый — не определено стандартом.** Это решает компилятор. Чаще всего `char` — знаковый, с диапазоном −128 … 127 (так, например, в System V ABI для Unix-систем, включая Linux).

Значения `char` — это **символьные литералы**: символы в одинарных кавычках.

```cpp
char letter = 'A';
```

На самом деле переменная `char` хранит **число** — код символа из таблицы кодировки. Чаще всего используют **ASCII**, где символам сопоставлены числа от 0 до 127.

```cpp
#include <stdio.h>

int main(void)
{
    char letter = 'A';
    printf("letter: %d\n", letter);   // letter: 65
    printf("letter: %c\n", letter);   // letter: A
    return 0;
}
```

- `%d` — выводит числовой код символа (`65`);
- `%c` — выводит сам символ (`A`).

Можно присвоить и числовой код напрямую — результат тот же:

```cpp
char letter = 65;
```

> **Важно:** символьный литерал `'A'` в C имеет тип `int`, а не `char`. Это историческая особенность языка, о которой стоит помнить.

## typedef

Оператор `typedef` создаёт **псевдоним** для существующего типа. Это удобно, когда название типа длинное или когда нужно подчеркнуть смысл.

Общая форма:

```cpp
typedef существующий_тип псевдоним;
```

Пример: дадим типу `unsigned char` псевдоним `BYTE`.

```cpp
#include <stdio.h>

typedef unsigned char BYTE;

int main(void)
{
    BYTE byte = 22;
    printf("byte = %d\n", byte);
    return 0;
}
```

Теперь `BYTE` можно использовать как обычный тип. С точки зрения компилятора `BYTE` и `unsigned char` — это одно и то же, но в коде видно намерение.

## Размер типов и оператор sizeof

Оператор `sizeof` возвращает **размер в байтах**, который занимает тип или выражение:

```cpp
#include <stdio.h>

int main(void)
{
    printf("sizeof(int): %zu\n", sizeof(int));
    printf("sizeof(long): %zu\n", sizeof(long));
    printf("sizeof(unsigned long long): %zu\n", sizeof(unsigned long long));
    return 0;
}
```

Вывод на 64-разрядном Linux:

```text
sizeof(int): 4
sizeof(long): 8
sizeof(unsigned long long): 8
```

`sizeof` возвращает значение типа `size_t` — это псевдоним для беззнакового целого, достаточного для хранения размера. На 64-битном Linux `size_t` — это `unsigned long`, но на других системах может быть другим. Поэтому для вывода используют `%zu`.

Можно сохранить результат в переменную:

```cpp
size_t int_size = sizeof(int);
printf("sizeof(int): %zu\n", int_size);
```

### sizeof для переменной

`sizeof` работает и с переменными. Скобки в этом случае необязательны:

```cpp
#include <stdio.h>

int main(void)
{
    int number = 2;
    printf("sizeof(number): %zu\n", sizeof(number));
    printf("sizeof number: %zu\n", sizeof number);
    return 0;
}
```

Оба варианта дадут `4`, потому что `number` имеет тип `int`.

### sizeof для выражения

`sizeof` может вычислить размер **результата выражения**:

```cpp
#include <stdio.h>

int main(void)
{
    size_t size = sizeof printf("hello");
    printf("size = %zu\n", size);
    return 0;
}
```

Здесь `sizeof` вычисляет размер **результата** функции `printf` — а это `int`, то есть 4 байта. При этом сама `printf` **не выполняется** — компилятор смотрит только на тип выражения.

То же самое можно проделать с самим `sizeof`:

```cpp
size_t size = sizeof sizeof(int);   // 8
```

`sizeof(int)` возвращает `size_t` (8 байт на 64-битной системе), а `sizeof` от этого значения снова даёт `size_t`.

## Итог

- Тип определяет **значения** переменной и её **размер** в памяти.
- Целочисленные типы: `char`, `short`, `int`, `long`, `long long` — каждый бывает знаковым (`signed`) и беззнаковым (`unsigned`).
- **Размеры типов не гарантированы** стандартом — их лучше проверять через `sizeof`.
- Для явного указания типа литерала используют **суффиксы**: `u`, `l`, `ll`, `ull`.
- Числа можно писать в **двоичной, восьмеричной, десятичной и шестнадцатеричной** системах.
- Вещественные типы: `float`, `double`, `long double`. По умолчанию дробный литерал — `double`.
- `char` хранит **числовой код** символа. `%c` выводит символ, `%d` — его код.
- `typedef` создаёт **псевдоним** для типа.
- `sizeof` возвращает **размер в байтах**; результат имеет тип `size_t` и выводится через `%zu`.
