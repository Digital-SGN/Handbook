# Структура программы на C

Программа на C состоит из трёх основных частей:

- **директивы препроцессора** — управляют преобразованием текста до компиляции;
- **глобальные объекты** — определяют данные и состояние программы;
- **функции** — определяют поведение программы.

Простейшая программа на C выглядит так:

```cpp
#include <stdio.h>

int main(void)
{
    printf("Hello, world!\n");
    return 0;
}
```

## Инструкции

**Инструкция** (statement) — простейший строительный элемент программы. Каждая инструкция выполняет одно действие.

В C инструкция **завершается точкой с запятой** `;` — она говорит компилятору, что инструкция закончилась.

```cpp
printf("Hello, world!");
```

Здесь вызов функции `printf` — это инструкция, и она заканчивается `;`.

## Блоки кода

Несколько инструкций можно объединить в **блок кода**. Блок обрамляется фигурными скобками `{ }`, а инструкции размещаются между ними:

```cpp
{
    printf("Hello, world!");
    printf("Bye, world!");
}
```

В этом блоке две инструкции — обе вызывают `printf`.

## Директивы препроцессора

В примере выше используется функция `printf`. Чтобы она стала доступна в программе, нужно подключить **заголовочный файл** `stdio.h` с помощью директивы `include`:

```cpp
#include <stdio.h>
```

Особенности директив препроцессора:

- каждая директива размещается **на отдельной строке**;
- директива начинается со знака `#`;
- завершением директивы считается **перевод строки**, а не `;` — в отличие от обычных инструкций.

Помимо `include`, есть и другие директивы, например `define`.

### Что делает `include`

Директива `include` указывает, какие файлы включить в текст программы в этом месте. По умолчанию подключаются стандартные **заголовочные файлы** (header files), которые поставляются вместе с библиотеками компилятора. `stdio.h` — один из них.

Термин «заголовочный файл» как раз отражает, что его текст включается **в начало** программы. Поэтому заголовочные файлы обычно подключают в самом начале исходного кода. Кроме того, файл нужно подключить **до вызова** тех функций, которые он определяет: например, `stdio.h` хранит определение `printf`, значит его нужно подключить раньше, чем вызывать `printf`.

При этом сами директивы препроцессора **не обязательно** должны быть в начале файла — это просто соглашение.

### Как это работает при компиляции

Перед компиляцией запускается **препроцессор**. Он сканирует исходный код и ищет строки, начинающиеся с `#`. Такие строки он воспринимает как директивы и **преобразует текст**. Например, на месте

```cpp
#include <stdio.h>
```

подставляется содержимое файла `stdio.h`. И только после этого в дело вступает компилятор.

## Функция main

**Точка входа** в любую программу на C — функция `main`. Именно с неё начинается выполнение приложения. Имя `main` фиксировано: во всех программах на C оно одинаковое.

Функция — это тоже блок кода, поэтому её тело обрамляется фигурными скобками, между которыми идут инструкции.

В литературе и примерах можно встретить разные варианты записи. Например:

```cpp
#include <stdio.h>

void main()
{
    printf("Hello, world!");
}
```

или

```cpp
#include <stdio.h>

int main()
{
    printf("Hello, world!");
    return 0;
}
```

Оба варианта не являются ошибкой: программа выведет строку. Для большинства компиляторов это нормально. Но **стандартным и рекомендуемым** считается такой вид:

```cpp
int main(void)
{
    // ...
    return 0;
}
```

Причины:

- `int` перед `main` — функция возвращает целое число, которое сообщает ОС код завершения (0 — успех);
- `void` в скобках — функция не принимает аргументов;
- `return 0;` — явный возврат кода успеха.

## Комментарии

Комментарии содержат описание кода. При компиляции они **полностью игнорируются** и на работу программы не влияют. Но они помогают человеку понимать код — в том числе вам самим через полгода.

В C есть два типа комментариев.

### Блочный

Заключается между `/*` и `*/`. Может занимать несколько строк:

```cpp
#include <stdio.h>

/* Функция main выводит
   на консоль строку Hello, world */
int main(void)
{
    printf("Hello, world!\n");
    return 0;
}
```

### Строчный

Помещается на одной строке после `//`:

```cpp
#include <stdio.h>                  // подключаем заголовочный файл stdio.h

int main(void)                      // определяем функцию main
{                                   // начало функции
    printf("Hello, world!");        // выводим строку на консоль
    return 0;                       // выходим из функции
}                                   // конец функции
```

## Итог

- Программа на C = **директивы препроцессора** + **глобальные объекты** + **функции**.
- Инструкция заканчивается `;`, директива препроцессора — **переводом строки**.
- Блок кода обрамляется `{ }`.
- Директива `#include <stdio.h>` подключает заголовочный файл, где объявлена `printf`.
- **Точка входа** — функция `main`. Рекомендуемый вид: `int main(void) { ... return 0; }`.
- Комментарии бывают **блочные** `/* ... */` и **строчные** `// ...`.
