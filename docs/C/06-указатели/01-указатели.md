# Указатели

**Указатель** — это переменная, значением которой является **адрес** другого объекта в памяти. Указатели — ключевой инструмент C: без них невозможно ни эффективно работать с массивами, ни передавать данные в функции «по ссылке», ни управлять динамической памятью.

Эта глава — одна из самых важных в курсе. Если что-то непонятно — перечитайте, прежде чем идти дальше.

## Адрес в памяти

Все данные программы — переменные, константы, массивы — хранятся в **оперативной памяти** по определённым адресам.

Адрес — это целое число, обычно записанное в **шестнадцатеричной системе**. Например, `0x0060FEA8`. По этому адресу в памяти лежит конкретная переменная.

Если переменная имеет тип `int` и занимает 4 байта, она занимает **четыре подряд идущих адреса**:

```text
0x0060FEA8   ← x (первый байт)
0x0060FEA9
0x0060FEAA
0x0060FEAB
```

Когда мы говорим «адрес переменной `x`», имеем в виду адрес её **первого байта**: `0x0060FEA8`.

## Определение указателя

Синтаксис:

```cpp
тип_данных *имя_указателя;
```

- `тип_данных` — тип объекта, на который будет указывать указатель;
- `*` — символ, отмечающий, что это указатель;
- `имя_указателя` — имя переменной-указателя.

Пример указателя на `int`:

```cpp
int *p;
```

Пока `p` ни на что не указывает. Присвоим ему адрес переменной:

```cpp
int x = 10;
int *p;
p = &x;   // теперь p хранит адрес переменной x
```

> **Важно:** звёздочка в объявлении относится к **переменной**, а не к типу. Запись `int *p` означает «`p` — указатель на `int`». Если объявляете несколько переменных в одной строке:
> ```cpp
> int *a, b;    // a — указатель на int, b — просто int!
> int *a, *b;   // а вот так — оба указатели
> ```
> Новички часто спотыкаются на этом. Пишите объявления указателей **отдельной строкой**.

## Получение адреса: оператор `&`

**Оператор `&`** возвращает адрес объекта в памяти. Применяется только к объектам, у которых есть адрес: к переменным, элементам массива, полям структур.

```cpp
int x = 10;
&x;   // адрес переменной x
```

Тип результата `&x` — **указатель на `int`** (`int *`). Тип указателя должен **соответствовать типу объекта**:

- `&` для `int` → `int *`
- `&` для `double` → `double *`
- `&` для `char` → `char *`

Нельзя присвоить `int *p = &some_double;` без явного приведения.

### Пример: адрес переменной

```cpp
#include <stdio.h>

int main(void)
{
    int x = 10;
    int *p = &x;

    printf("Address of x: %p\n", (void *)p);
    return 0;
}
```

Пример вывода:

```text
Address of x: 0x7ffd4a3b2c4c
```

Адрес будет другим при каждом запуске — это нормально. Операционная система размещает программу в памяти каждый раз по-новому (ASLR, address space layout randomization).

## Разыменование: оператор `*`

**Оператор `*`** (dereference, разыменование) даёт **значение**, лежащее по адресу, который хранится в указателе.

```cpp
int x = 10;
int *p = &x;

printf("x = %d\n", *p);   // 10
```

`*p` означает «значение по адресу из `p`» — то же самое, что `x`.

### Звёздочка — это два разных оператора

В C символ `*` используется в двух смыслах:

1. **В объявлении** — «это указатель»:
   ```cpp
   int *p;   // объявление указателя
   ```
2. **В выражении** — «разыменовать, получить значение по адресу»:
   ```cpp
   *p = 5;   // разыменование
   ```

Компилятор различает их по контексту. Это одна из самых путающих деталей в C для новичков.

## Чтение и изменение значения

Через указатель можно не только **читать**, но и **изменять** значение по адресу:

```cpp
int x = 10;
int *p = &x;

*p = 45;
printf("x = %d\n", x);   // 45
```

Здесь `*p = 45` записывает `45` по адресу переменной `x`. Поскольку адрес тот же, меняется сама переменная `x`.

### Чтение через указатель

```cpp
int x = 10;
int *p = &x;
int y = *p;    // y = 10

printf("x = %d\n", y);
```

`*p` возвращает значение, и его можно присвоить другой переменной.

### Сводная таблица операторов

| Оператор | Название | Что делает |
| :---: | :--- | :--- |
| `&x` | Взятие адреса | Возвращает адрес переменной `x` |
| `*p` | Разыменование | Возвращает значение по адресу из `p` |

Это **взаимно обратные** операции: `*&x` то же самое, что `x`.

```cpp
int x = 10;
printf("%d\n", *&x);   // 10
```

## Указатели разных типов

Указатель **знает**, на объект какого типа он указывает. Это определяет, сколько байт читать при разыменовании.

```cpp
#include <stdio.h>

int main(void)
{
    char c = 'N';
    int d = 10;
    short s = 2;

    char *pc = &c;
    int *pd = &d;
    short *ps = &s;

    printf("c: address=%p\tvalue=%c\n", (void *)pc, *pc);
    printf("d: address=%p\tvalue=%d\n", (void *)pd, *pd);
    printf("s: address=%p\tvalue=%hd\n", (void *)ps, *ps);

    return 0;
}
```

Пример вывода:

```text
c: address=0x7ffd4a3b2c4b   value=N
d: address=0x7ffd4a3b2c44   value=10
s: address=0x7ffd4a3b2c42   value=2
```

Обратите внимание:

- адреса переменных идут **не строго по порядку** объявления — компилятор сам решает, как их разместить;
- переменные могут быть выровнены по границам (например, `int` часто выравнивается на адрес, кратный 4).

### Почему тип указателя важен

Если бы указатели не различались по типу, компилятор не знал бы, **сколько байт** читать при разыменовании. `char *` читает 1 байт, `int *` — обычно 4, `double *` — 8.

Поэтому `int *` и `char *` — **разные типы**, даже если оба хранят адрес.

## Вывод адреса через `%p`

Для вывода адреса используется спецификатор **`%p`**. Он ожидает аргумент типа `void *`.

```cpp
printf("Address = %p\n", (void *)p);
```

### Что такое `void *`

**`void *`** — это «указатель на что угодно». Такой указатель может хранить адрес объекта **любого** типа. Его часто используют для обобщённых функций (например, `malloc`, `qsort`).

Приведение `(void *)p` при выводе через `%p` — каноничный способ. Некоторые компиляторы и без этого работают нормально, но с флагами `-Wall` могут выдать предупреждение.

> **Важно:** `void *` — это **не** то же самое, что `int *` или `char *`. Разыменовать `void *` нельзя, пока не приведёте его к конкретному типу.

## Подводные камни

Указатели — источник большинства сложных ошибок в C. Вот основные.

### 1. Разыменование неинициализированного указателя

```cpp
int *p;      // указатель содержит "мусор"
*p = 5;      // ОШИБКА: запись в случайный адрес
```

Указатель `p` не инициализирован и содержит произвольное значение. Разыменование такой переменной — **неопределённое поведение**. Программа может упасть, а может испортить чужие данные.

**Решение:** всегда инициализируйте указатель при объявлении — либо адресом, либо `NULL`.

```cpp
int *p = NULL;   // указатель ни на что не указывает
```

### 2. Разыменование NULL-указателя

**`NULL`** — специальная константа, означающая «указатель ни на что». Разыменование `NULL` — гарантированный крах:

```cpp
int *p = NULL;
printf("%d\n", *p);   // ошибка времени выполнения (segmentation fault)
```

Проверяйте указатель перед разыменованием, если он мог стать `NULL`:

```cpp
if (p != NULL) {
    printf("%d\n", *p);
}
```

### 3. Висячий указатель (dangling pointer)

Если объект, на который указывает указатель, больше не существует — указатель становится **висячим**. Обращение к нему — неопределённое поведение.

```cpp
int *create(void)
{
    int x = 10;
    return &x;   // ОШИБКА: x уничтожится при выходе из функции
}

int *p = create();
printf("%d\n", *p);   // неопределённое поведение
```

Локальные переменные живут только **внутри** своей функции. Возвращать адрес локальной переменной нельзя.

### 4. Присваивание значения вместо адреса

```cpp
int x = 10;
int *p;
p = x;    // ОШИБКА: p хранит тип int, а не int *
```

Нужно `p = &x;` — взять адрес, а не значение. Компилятор с `-Wall` это поймает.

### 5. Тип не совпадает

```cpp
double d = 3.14;
int *p = &d;   // предупреждение: несовместимые типы указателей
```

Указатель на `int` не должен указывать на `double`. Если очень надо — используйте явное приведение `(int *)&d`, но помните: разыменование будет интерпретировать байты `double` как `int`, и результат непредсказуем.

## Итог

- **Указатель** хранит **адрес** объекта в памяти.
- Объявление: `тип *имя;`. Звёздочка относится к переменной, не к типу.
- **`&x`** — получить адрес переменной `x`.
- **`*p`** — разыменовать указатель, получить значение по адресу.
- `*&x` — то же самое, что `x`.
- Тип указателя важен: он определяет, сколько байт читать при разыменовании.
- **`void *`** — обобщённый указатель. Разыменовать его без приведения нельзя.
- Для вывода адреса — `%p` с приведением к `(void *)`.
- Всегда инициализируйте указатели. Не разыменовывайте `NULL`. Не возвращайте адрес локальной переменной.
- Указатели — основа для передачи данных «по ссылке», работы с массивами и динамической памяти. Следующие главы будут опираться на эту.
