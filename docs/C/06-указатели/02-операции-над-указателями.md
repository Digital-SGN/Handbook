# Операции с указателями

С указателями можно выполнять несколько видов операций:

- **присваивание** — адрес объекта, другой указатель или `NULL`;
- **разыменование** — получение значения по адресу;
- **получение адреса самого указателя** — `&p`;
- **сравнение** — `>`, `<`, `==`, `!=` и т.д.;
- **приведение типов** — к другому типу указателя.

## Присваивание

Указателю можно присвоить:

- **адрес объекта** того же типа;
- **значение другого указателя** того же типа;
- константу **`NULL`**.

### Адрес объекта

```cpp
int a = 10;
int *pa = &a;   // pa хранит адрес переменной a
```

Типы указателя и объекта должны **совпадать**. Указатель на `int` не может напрямую принять адрес `double`.

### Другой указатель

```cpp
#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 2;

    int *pa = &a;
    int *pb = &b;

    printf("a: address=%p\tvalue=%d\n", (void *)pa, *pa);
    printf("b: address=%p\tvalue=%d\n", (void *)pb, *pb);

    pa = pb;   // теперь pa хранит адрес b

    printf("pa now points to b: address=%p\tvalue=%d\n", (void *)pa, *pa);
    return 0;
}
```

Когда указателю присваивают другой указатель, оба начинают **указывать на один и тот же адрес**. Это не копирование данных — просто две переменные хранят одинаковый адрес.

### Константа NULL

Если указатель не должен ни на что указывать, ему присваивают **`NULL`**:

```cpp
int *pa = NULL;
```

`NULL` — специальная константа, означающая «нулевой указатель». Она определена в заголовочном файле `<stddef.h>`, но её косвенно подключают почти все стандартные заголовки, включая `<stdio.h>`.

Использование `NULL` — хорошая привычка. Если указатель не инициализирован, в нём может лежать «мусор», и разыменование приведёт к неопределённому поведению. С `NULL` вы всегда можете проверить, «живой» ли указатель:

```cpp
if (pa != NULL) {
    printf("%d\n", *pa);
}
```

> **Важно:** `NULL` — это **не** `0` в буквальном смысле, хотя обычно определяется через `0` или `(void *)0`. Не пишите `int *p = 0;` в новом коде — используйте `NULL`.

## Разыменование

Операция разыменования `*p` возвращает объект по адресу из указателя. Если указатель ведёт на переменную, разыменование — это **прямой доступ** к ней.

```cpp
#include <stdio.h>

int main(void)
{
    int a = 10;

    int *pa = &a;
    int *pb = pa;    // pb указывает туда же, куда pa

    *pa = 25;        // записываем 25 по адресу переменной a

    printf("Value of pa: %d\n", *pa);   // 25
    printf("Value of pb: %d\n", *pb);   // 25
    printf("Value of a:  %d\n", a);     // 25

    return 0;
}
```

Почему `pb` и `a` тоже равны `25`? Потому что все три «смотрят» на одну и ту же ячейку памяти:

```text
         ┌──────────────┐
pa ────► │              │
pb ────► │     25       │  ← переменная a
         │              │
         └──────────────┘
```

Изменение через любой указатель меняет **общий объект**.

### Два применения `*`

- `*pa` как **выражение** — получить значение;
- `*pa = 25` — **записать** значение.

Это одна и та же операция: она возвращает объект по адресу, и уже от контекста зависит, читаем мы его или пишем.

## Указатель на `void`

**`void *`** — «указатель на что угодно». Он может хранить адрес объекта **любого** типа.

Присвоить значение `void *` можно из указателя любого типа, и наоборот — **без явного приведения**:

```cpp
#include <stdio.h>

int main(void)
{
    int x = 123;
    int *ip = &x;
    void *vp = ip;       // неявное преобразование int* → void*

    printf("Value: %d\n", *((int *)vp));   // 123
    return 0;
}
```

### Разыменовать `void *` нельзя

Компилятор не знает, сколько байт читать, — тип не указан. Поэтому `*vp` **не скомпилируется**. Нужно сначала привести к конкретному типу:

```cpp
*((int *)vp)   // приводим void* к int*, потом разыменовываем
```

Разберём выражение по слоям:

1. `vp` — сам указатель;
2. `(int *)vp` — приводим к `int *`;
3. `*((int *)vp)` — разыменовываем.

### Применение `void *`

1. **Обобщённые функции.** `malloc`, `qsort`, `memcpy` принимают `void *` — так они работают с любыми типами.
2. **Вывод адреса.** `printf("%p", ...)` ожидает `void *`.

```cpp
#include <stdio.h>

int main(void)
{
    int x = 123;
    int *ip = &x;
    void *vp = ip;

    printf("vp: %p\n", vp);           // адрес из vp
    printf("ip: %p\n", (void *)ip);   // явное приведение int* → void*

    return 0;
}
```

> **Правило:** при выводе адреса указателя через `%p` **всегда** приводите его к `(void *)`. Даже если ваш компилятор не ругается — это требование стандарта.

## Адрес самого указателя

Указатель — **тоже переменная**. Он хранится в памяти и имеет собственный адрес. Получить его можно через `&`:

```cpp
int a = 10;
int *pa = &a;

printf("address of pointer: %p\n", (void *)&pa);   // адрес самого pa
printf("address in pointer: %p\n", (void *)pa);    // адрес a
printf("value on pointer:  %d\n", *pa);            // значение a
```

Три разных вещи:

| Выражение | Что это |
| :--- | :--- |
| `&pa` | Адрес **самого указателя** в памяти |
| `pa` | Адрес, **хранящийся** в указателе (адрес `a`) |
| `*pa` | Значение по адресу из указателя (значение `a`) |

Можно даже сделать указатель на указатель:

```cpp
int **ppa = &pa;   // указатель на указатель на int
```

Такие конструкции пригодятся позже — например, при передаче указателя в функцию, чтобы изменить его значение.

## Операции сравнения

К указателям применимы `>`, `>=`, `<`, `<=`, `==`, `!=`. Сравниваются **числовые значения адресов**.

```cpp
int a = 10;
int b = 20;
int *pa = &a;
int *pb = &b;

if (pa > pb)
    printf("pa (%p) is greater than pb (%p)\n", (void *)pa, (void *)pb);
else
    printf("pa (%p) is less or equal pb (%p)\n", (void *)pa, (void *)pb);
```

Пример вывода:

```text
pa (0x7ffd4a3b2c4c) is greater than pb (0x7ffd4a3b2c48)
```

### Правила сравнения

- Сравнивать можно только указатели **одного типа**.
- Любой указатель можно сравнить с `NULL`.
- Операции `<` и `>` **имеют смысл только** для указателей внутри одного массива или блока памяти. Между разными переменными результат зависит от компилятора.

### Проверка на NULL

Самое частое сравнение — проверка указателя на `NULL`:

```cpp
if (p == NULL) { /* не инициализирован или сброшен */ }
if (p != NULL) { /* можно безопасно разыменовать */ }
```

Пишите `p != NULL` или коротко `if (p)`. Второй вариант короче и эквивалентен: `NULL` — это ноль, ноль — ложь.

## Приведение типов

Иногда нужно присвоить указателю одного типа значение указателя другого типа. Для этого используют **явное приведение**:

```cpp
#include <stdio.h>

int main(void)
{
    char c = 'N';
    char *pc = &c;

    int *pd = (int *)pc;   // приведение char* → int*

    printf("pc = %p\n", (void *)pc);
    printf("pd = %p\n", (void *)pd);
    return 0;
}
```

Оба указателя хранят **один и тот же адрес**, но `pd` теперь «думает», что там лежит `int`.

> **Осторожно!** Разыменование такого указателя (`*pd`) — **неопределённое поведение**. Компилятор прочитает 4 байта начиная с адреса, где лежит всего 1 байт `char`, и захватит соседнюю память. Результат непредсказуем.

Приведение типов указателей оправдано, когда вы **точно знаете**, что делаете: например, работаете с сырой памятью, сериализацией, сетевыми протоколами.

## Итог

- Указателю можно присвоить **адрес объекта**, **другой указатель** или **`NULL`**.
- `*p` даёт доступ к объекту: можно **читать** и **писать**.
- Если два указателя хранят один адрес, изменение через любой из них меняет **общий объект**.
- **`void *`** может хранить адрес любого типа. Разыменовать его нельзя без приведения.
- При выводе через `%p` всегда приводите указатель к `(void *)`.
- Указатель сам имеет **адрес** — получить его можно через `&p`.
- Указатели можно **сравнивать**: `==`, `!=`, `<`, `>` и т.д.
- `<` и `>` имеют смысл только внутри одного массива.
- **Приведение типов** указателей возможно, но разыменование после него — на ваш риск.
