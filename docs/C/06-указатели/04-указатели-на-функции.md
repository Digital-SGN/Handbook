# Указатели на функции

У каждой функции в C есть **адрес** — место в памяти, откуда начинается её код. Значит, можно завести **указатель на функцию** — переменную, которая хранит этот адрес. Такой указатель позволяет вызывать функцию **косвенно**, через переменную.

Указатели на функции — основа **callbacks** (функций обратного вызова), обработчиков событий и обобщённых алгоритмов вроде `qsort`.

## Синтаксис

Определение указателя на функцию:

```cpp
тип (*имя_указателя)(типы_параметров);
```

Разберём:

- **`тип`** — тип возвращаемого значения функции;
- **`имя_указателя`** — имя переменной;
- **`(типы_параметров)`** — типы параметров функции. Если параметров нет — `void`.

### Пример

```cpp
void (*message)(void);
```

Это указатель `message`, который может указывать на функции:

- без параметров;
- возвращающие `void`.

> **Важно:** тип возвращаемого значения и список параметров указателя должны **точно совпадать** с функцией, на которую он указывает. Иначе — неопределённое поведение.

### Имя функции как указатель

Само имя функции — тоже указатель на её первый байт в памяти. Поэтому работают обе записи:

```cpp
message = hello;    // обычная запись
message = &hello;   // избыточно, но тоже верно
```

На практике пишут без `&` — так короче и понятнее.

## Определение и использование

```cpp
#include <stdio.h>

void hello()
{
    printf("Hello, World\n");
}

void goodbye()
{
    printf("Good Bye, World\n");
}

int main(void)
{
    void (*message)(void);   // указатель на функцию

    message = hello;         // указывает на hello
    message();               // вызываем

    message = goodbye;       // теперь указывает на goodbye
    message();               // вызываем снова

    return 0;
}
```

Вывод:

```text
Hello, World
Good Bye, World
```

Обратите внимание: синтаксис вызова **тот же**, что у обычной функции:

```cpp
message();
```

Хотя формально можно и `(*message)()` — это эквивалентно. Компилятор прощает оба варианта, но `message()` пишется короче.

### Зачем это нужно

Указатель на функцию позволяет:

- **выбирать** функцию во время выполнения — в зависимости от условий;
- **передавать** функцию как аргумент в другую функцию (callback);
- строить **таблицы** операций.

## Ловушка со скобками

Скобки вокруг имени **обязательны**. Вот два разных объявления:

```cpp
void (*message)(void);   // указатель на функцию
void *message(void);     // функция, возвращающая void*
```

Разница:

- **`void (*message)(void)`** — `message` это указатель на функцию `void → void`;
- **`void *message(void)`** — `message` это **функция** без параметров, возвращающая `void *`.

> **Правило:** если видите `(*имя)` — это указатель на функцию. Если `*имя(...)` — это функция, возвращающая указатель.

## Указатель с параметрами и результатом

Рассмотрим более сложный случай: функция с двумя `int`-параметрами, возвращающая `int`.

```cpp
#include <stdio.h>

int sum(int x, int y)
{
    return x + y;
}

int subtract(int x, int y)
{
    return x - y;
}

int main(void)
{
    int a = 10;
    int b = 5;
    int result;

    int (*operation)(int, int);   // указатель на функцию

    operation = sum;
    result = operation(a, b);
    printf("result = %d\n", result);   // 15

    operation = subtract;
    result = operation(a, b);
    printf("result = %d\n", result);   // 5

    return 0;
}
```

Здесь указатель `operation`:

- возвращает `int`;
- принимает два `int`.

Обе функции `sum` и `subtract` этому соответствуют — можно присваивать любую.

### Вызов через указатель с аргументами

Вызов выглядит как обычный:

```cpp
result = operation(a, b);
```

Указатель «знает» тип функции, поэтому компилятор проверит типы аргументов и результата.

## Массивы указателей на функции

Можно создать **массив** указателей на функции. Это позволяет строить **таблицы операций**.

Синтаксис:

```cpp
тип (*имя_массива[размер])(параметры)
```

Пример:

```cpp
#include <stdio.h>

void sum(int x, int y)      { printf("x + y = %d\n", x + y); }
void subtract(int x, int y) { printf("x - y = %d\n", x - y); }
void multiply(int x, int y) { printf("x * y = %d\n", x * y); }

int main(void)
{
    int a = 10;
    int b = 5;

    void (*operations[3])(int, int) = {sum, subtract, multiply};

    size_t length = sizeof(operations) / sizeof(operations[0]);

    for (size_t i = 0; i < length; i++)
    {
        operations[i](a, b);   // вызов функции из массива
    }

    return 0;
}
```

Вывод:

```text
x + y = 15
x - y = 5
x * y = 50
```

Разберём:

- `operations` — массив из 3 указателей на функции;
- каждая функция: `void (int, int)`;
- инициализация — прямо списком имён функций;
- `operations[i](a, b)` — вызвать функцию, на которую указывает `i`-й элемент.

### Зачем это нужно

Массив указателей на функции часто используется для:

- **калькуляторов** — таблица операций;
- **диспетчеров** — выбор обработчика по индексу;
- **state machines** — таблица переходов между состояниями.

Компилятор не требует, чтобы функции были названы одинаково, — важно лишь соответствие **сигнатуры**.

### Через typedef удобнее

Массив указателей на функции выглядит громоздко. `typedef` упрощает запись:

```cpp
typedef void (*operation_func)(int, int);

operation_func operations[3] = {sum, subtract, multiply};
```

Читается гораздо легче: массив из трёх `operation_func`.

## Итог

- У каждой функции есть **адрес**.
- **Указатель на функцию:** `тип (*имя)(параметры);`.
- Скобки вокруг `*имя` **обязательны** — иначе получится другая конструкция.
- Указателю можно присвоить любую функцию с подходящей сигнатурой.
- Вызов через указатель: `имя(аргументы)` — как у обычной функции.
- **Массив указателей** на функции позволяет строить таблицы операций.
- `typedef` сильно упрощает синтаксис — используйте его.
- Указатели на функции — основа **callbacks** и обобщённых алгоритмов.
