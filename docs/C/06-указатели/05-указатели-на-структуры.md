# Указатели на структуры

На структуры, как и на любой другой объект, можно объявлять **указатели**. Указатели на структуры — основа для работы со связанными списками, деревьями и другими структурами данных, а также для эффективной передачи больших структур в функции.

## Объявление и присваивание

```cpp
struct person *p;   // указатель на struct person
```

Указатели можно создавать и для **безымянных** структурных типов:

```cpp
struct
{
    int age;
    char name[20];
} *p1, *p2;
```

Присваивается указателю адрес объекта того же типа:

```cpp
struct person kate = {31, "Kate"};
struct person *p_kate = &kate;
```

## Доступ к полям: `->` и `(*p).`

Есть два эквивалентных способа:

1. **Оператор стрелка** `->`:
   ```cpp
   p->age
   ```
2. **Разыменование + точка**:
   ```cpp
   (*p).age
   ```

Скобки во втором варианте **обязательны**: без них `*p.age` означает «взять `p.age` (не существует) и разыменовать».

```cpp
#include <stdio.h>

struct person
{
    int age;
    char name[20];
};

int main(void)
{
    struct person kate = {31, "Kate"};
    struct person *p_kate = &kate;

    // оба способа эквивалентны
    char *name = p_kate->name;
    int age = (*p_kate).age;

    printf("name = %s\tage = %d\n", name, age);

    // изменяем через указатель
    p_kate->age = 32;
    printf("name = %s\tage = %d\n", kate.name, kate.age);

    return 0;
}
```

`->` — почти всегда удобнее. `(*p).` используется редко.

## Указатель структуры на саму себя

Структура может содержать указатель **на саму себя**:

```cpp
struct node
{
    char *value;
    struct node *next;   // указатель на следующий узел
};
```

Это основа **связного списка** — цепочки объектов, где каждый знает, где искать следующий.

```cpp
#include <stdio.h>

struct node
{
    char *value;
    struct node *next;
};

int main(void)
{
    struct node kate = { .value = "Kate" };
    struct node tom  = { .value = "Tom"  };
    struct node bob  = { .value = "Bob"  };

    kate.next = &tom;
    tom.next  = &bob;
    // bob.next остаётся NULL

    struct node *pointer = &kate;

    while (pointer != NULL)
    {
        printf("value = %s\n", pointer->value);
        pointer = pointer->next;
    }

    return 0;
}
```

Вывод:

```text
value = Kate
value = Tom
value = Bob
```

Разбор:

- `kate.next = &tom`, `tom.next = &bob`, `bob.next = NULL` — получаем цепочку **Kate → Tom → Bob**;
- `pointer = &kate` — становимся на начало;
- в цикле выводим `value`, затем переходим к `pointer->next`;
- `bob.next == NULL` завершает цикл.

Так строятся **связные списки**: каждый узел хранит данные и указатель на следующий узел. Последний указывает на `NULL`. Обход — циклом `while`.

## Неполный тип: указатель до определения

Структура **не может содержать поле** типа другой структуры, которая определена позже:

```cpp
struct rectangle
{
    struct color background;   // ошибка: struct color ещё не определена
    unsigned width;
    unsigned height;
};

struct color
{
    unsigned char red, green, blue, alpha;
};
```

Компилятор скажет:

```text
error: field 'background' has incomplete type
```

### Как исправить

**Сначала объявить** структуру, а потом использовать её **через указатель**:

```cpp
#include <stdio.h>

struct color;   // объявление (неполный тип)

struct rectangle
{
    struct color *background;   // указатель — можно
    unsigned width;
    unsigned height;
};

struct color                     // определение
{
    unsigned char red;
    unsigned char green;
    unsigned char blue;
    unsigned char alpha;
};

int main(void)
{
    struct color bg = { 255, 0, 0, 125 };
    struct rectangle rect = {
        .width = 100,
        .height = 50,
        .background = &bg
    };

    printf("Rectangle color: R=%d G=%d B=%d\n",
           rect.background->red,
           rect.background->green,
           rect.background->blue);

    return 0;
}
```

**Почему работает:** указатель — **полный тип**, его размер известен (8 байт на 64-битной системе). А вот размер структуры без определения неизвестен — поэтому саму структуру внутрь другой вложить нельзя, пока она не определена.

## Взаимные ссылки структур

Тот же приём позволяет описать структуры, которые **ссылаются друг на друга**:

```cpp
struct B;   // предварительное объявление

struct A
{
    struct B *b;   // указатель — можно
};

struct B
{
    struct A *a;
};
```

Это стандартный приём для деревьев, графов, сетевых узлов.

## Константные указатели на структуры

`const` перед `struct` — указатель на **константную** структуру: менять поля через него нельзя.

```cpp
#include <stdio.h>

const struct Number { int value; } *p;

int main(void)
{
    struct Number num = {6};
    num.value = 7;                 // саму переменную менять можно
    printf("num = %d\n", num.value);

    p = &num;                      // указатель можно переназначить
    printf("p->value = %d\n", p->value);   // читать — можно
    // p->value = 9;               // нельзя: поля только для чтения

    return 0;
}
```

`const struct Number *p` — то же самое. Поля через `p` доступны только для чтения, но **сам указатель** можно переназначить.

### `typedef` для такого указателя

```cpp
typedef const struct Number { int value; } *PNumber;
```

Теперь `PNumber` — тип «указатель на константную структуру `Number`».

```cpp
#include <stdio.h>

typedef const struct Number { int value; } *PNumber;

int main(void)
{
    struct Number n1 = {6};
    struct Number n2 = {8};

    PNumber p = &n1;
    printf("p->value = %d\n", p->value);   // 6

    p = &n2;                                // указатель менять можно
    printf("p->value = %d\n", p->value);   // 8

    // p->value = 10;                       // нельзя

    return 0;
}
```

### Константный указатель

`const` можно применить **и к самому указателю**: тогда нельзя изменить адрес, но можно менять поля через него.

```cpp
struct Number n1 = {6};
struct Number n2 = {8};

struct Number * const p = &n1;
p->value = 10;   // ок — меняем данные
// p = &n2;      // нельзя — меняем адрес
```

### Комбинации `const`

| Объявление | Что можно | Что нельзя |
| :--- | :--- | :--- |
| `struct T *p` | менять поля и адрес | — |
| `const struct T *p` | менять адрес | менять поля |
| `struct T * const p` | менять поля | менять адрес |
| `const struct T * const p` | ничего | ни поля, ни адрес |

> **Правило чтения:** `const` относится к тому, что стоит **сразу после** него. `const struct T *` — «указатель на константную `T`». `struct T * const` — «константный указатель на `T`».

## Итог

- Указатель на структуру: `struct T *p;`.
- Доступ к полям — через **`->`** или **`(*p).`**. Скобки во втором варианте обязательны.
- Структура может содержать указатель **на саму себя** — так строятся связные списки.
- Структуры, ссылающиеся друг на друга, объявляются через **предварительное объявление** + указатель.
- Саму структуру внутрь другой вложить до её определения нельзя — только указатель.
- **`const struct T *p`** — указатель на константную структуру: поля менять нельзя, указатель — можно.
- **`struct T * const p`** — константный указатель: адрес менять нельзя, поля — можно.
- Оба `const` можно комбинировать.
