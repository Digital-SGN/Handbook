# Дата и время

Заголовочный файл **`<time.h>`** предоставляет функции для работы с датой и временем: получить текущий момент, разложить его на компоненты (год, месяц, день), отформатировать в строку.

## Текущее время: `time`

Прототип:

```cpp
time_t time(time_t *arg);
```

Возвращает текущее время как **`time_t`** — целое число секунд, прошедших с 1 января 1970 года (Unix epoch).

Два способа использования:

```cpp
// 1. Через возвращаемое значение
time_t t1 = time(NULL);

// 2. Через указатель
time_t t2;
time(&t2);
```

Оба дают одно и то же. `time_t` — обычно 64-битное целое (на современных системах).

## Разбор: `localtime` и `struct tm`

`time_t` — просто число секунд. Чтобы получить год, месяц, день, часы — его разбирают в структуру **`struct tm`** через `localtime`:

```cpp
time_t mytime = time(NULL);
struct tm *now = localtime(&mytime);
```

`localtime` возвращает указатель на **статическую** структуру `tm`. Она перезаписывается при каждом вызове — если нужно сохранить результат, копируйте его.

### Поля `struct tm`

| Поле | Что хранит | Диапазон |
| :--- | :--- | :--- |
| `tm_sec` | Секунды | 0–60 (60 — високосная) |
| `tm_min` | Минуты | 0–59 |
| `tm_hour` | Часы | 0–23 |
| `tm_mday` | День месяца | 1–31 |
| `tm_mon` | Месяц | **0–11** |
| `tm_year` | Год **минус 1900** | например, 124 = 2024 |
| `tm_wday` | День недели | 0–6 (0 — воскресенье) |
| `tm_yday` | День года | 0–365 |
| `tm_isdst` | Летнее время | >0 — действует, 0 — нет, <0 — неизвестно |

### Странности, о которых легко забыть

- **Месяцы с нуля**: январь — `0`, декабрь — `11`. Для вывода прибавляйте `1`.
- **Год минус 1900**: 2024 хранится как `124`. Прибавляйте `1900`.
- **День недели с воскресенья**: воскресенье — `0`, понедельник — `1`, и т.д.

Пример:

```cpp
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t mytime = time(NULL);
    struct tm *now = localtime(&mytime);

    printf("Date: %d.%d.%d\n",
           now->tm_mday, now->tm_mon + 1, now->tm_year + 1900);
    printf("Time: %d:%02d:%02d\n",
           now->tm_hour, now->tm_min, now->tm_sec);

    return 0;
}
```

Пример вывода:

```text
Date: 13.1.2024
Time: 13:13:24
```

`%02d` — форматирование с ведущим нулём. Для даты можно так же: `%02d.%02d.%d`.

## Форматирование: `strftime`

`strftime` превращает `struct tm` в строку по указанному шаблону:

```cpp
size_t strftime(char *s, size_t max, const char *format, const struct tm *tm);
```

- `s` — буфер для результата;
- `max` — размер буфера;
- `format` — строка шаблона;
- `tm` — структура с датой/временем;
- возвращает число записанных символов или `0` при ошибке.

```cpp
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t mytime = time(NULL);
    struct tm *now = localtime(&mytime);

    char buf[64];

    strftime(buf, sizeof(buf), "%Y-%m-%d %H:%M:%S", now);
    printf("Time: %s\n", buf);

    strftime(buf, sizeof(buf), "%d %B %Y", now);
    printf("Date: %s\n", buf);

    return 0;
}
```

Возможный вывод:

```text
Time: 2024-01-13 13:13:24
Date: 13 January 2024
```

> **Важно:** размер буфера. Если итоговая строка не влезет, `strftime` вернёт `0`, но буфер может остаться частично заполненным. Всегда проверяйте результат или берите буфер с запасом.

## Спецификаторы `strftime`

| Спецификатор | Значение |
| :--- | :--- |
| `%Y` | Год, 4 цифры |
| `%y` | Год, 2 цифры |
| `%m` | Месяц, `01`–`12` |
| `%d` | День месяца, `01`–`31` |
| `%H` | Часы, `00`–`23` |
| `%M` | Минуты |
| `%S` | Секунды |
| `%B` | Полное название месяца |
| `%b`, `%h` | Сокращённое название месяца |
| `%A` | Полное название дня недели |
| `%a` | Сокращённое название дня недели |
| `%D` | То же, что `%m/%d/%y` |
| `%T` | То же, что `%H:%M:%S` |
| `%F` | То же, что `%Y-%m-%d` |
| `%%` | Знак `%` |

Пример получения только времени:

```cpp
char str[20];
strftime(str, sizeof(str), "%T", now);
printf("Time: %s\n", str);
```

## UTC vs локальное время

- **`localtime`** — возвращает время в **местной** зоне (с учётом `TZ`);
- **`gmtime`** — возвращает время в **UTC** (без часового пояса).

```cpp
struct tm *utc = gmtime(&mytime);
printf("UTC: %d:%02d\n", utc->tm_hour, utc->tm_min);
```

### О потокобезопасности

Обе функции возвращают указатель на **статическую** структуру. При следующем вызове она перезапишется. В многопоточных программах это проблема.

Есть потокобезопасные версии: `localtime_r`, `gmtime_r` — они принимают **свой буфер**:

```cpp
struct tm buf;
localtime_r(&mytime, &buf);   // POSIX, не в стандарте C
```

### Форматирование длительности

`<time.h>` определяет также **`clock_t`** и **`clock`** — для измерения процессорного времени:

```cpp
clock_t start = clock();
// ... какой-то код ...
clock_t end = clock();
double seconds = (double)(end - start) / CLOCKS_PER_SEC;
printf("Elapsed: %.3f seconds\n", seconds);
```

Это не про дату, а про **производительность**. Полезно для профилирования.

## Итог

- **`<time.h>`** — заголовок для работы с датой и временем.
- **`time(NULL)`** возвращает текущий момент как `time_t` (секунды с 1970).
- **`localtime`** разбирает `time_t` в `struct tm` с полями год/месяц/день/час.
- **Месяцы с нуля** (`0–11`), **год минус 1900**, **день недели с воскресенья** — три классические ловушки.
- **`strftime`** форматирует `tm` в строку по шаблону.
- Основные спецификаторы: `%Y`, `%m`, `%d`, `%H`, `%M`, `%S`, `%B`, `%A`, `%F`, `%T`.
- **`gmtime`** — UTC, `localtime` — местная зона.
- Возвращаемая структура **статическая** — копируйте, если нужно сохранить.
- **`clock`** — для измерения времени выполнения, не даты.
