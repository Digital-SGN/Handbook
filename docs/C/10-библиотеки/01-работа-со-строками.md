## Длина строки: strlen

Прототип:

```cpp
size_t strlen(const char *str);
```

Возвращает количество символов в строке **без** завершающего `\0`.

```cpp
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char str[] = "Hello";
    size_t length = strlen(str);

    printf("String length: %zu\n", length);   // 5
    return 0;
}
```

Результат имеет тип **`size_t`** — для вывода используется `%zu`.

### Что важно помнить

- `strlen("")` → `0`;
- `strlen("Hello")` → `5`, хотя в памяти строка занимает **6 байт** (плюс `\0`);
- `strlen` **считает символы**, а не байты в смысле размера массива. `sizeof(str)` вернёт размер массива, включая `\0`.

```cpp
const char str[] = "Hello";

strlen(str)    // 5 — количество символов
sizeof(str)    // 6 — размер массива в байтах
```

## Сравнение: strcmp

Прототип:

```cpp
int strcmp(const char *str1, const char *str2);
```

Посимвольно сравнивает две строки в **лексикографическом** порядке.

| Результат | Значение |
| :---: | :--- |
| `0` | Строки равны |
| `< 0` | `str1` идёт раньше `str2` |
| `> 0` | `str1` идёт позже `str2` |

```cpp
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *str1 = "Hello";
    const char *str2 = "Hello";
    int result = strcmp(str1, str2);

    if (result == 0) {
        printf("Strings are equal\n");
    } else {
        printf("Strings are not equal\n");
    }
    return 0;
}
```

### Чего нельзя делать

Сравнивать строки через `==` **бесполезно** — это сравнивает **адреса**, а не содержимое:

```cpp
if (str1 == str2) { ... }   // сравнивает указатели, а не строки!
```

Всегда используйте `strcmp`.

### Возвращаемое значение

Точное значение `strcmp` (например, `-1` или `+1`) **не гарантировано**. Стандарт требует только знак. Поэтому пишут:

```cpp
if (strcmp(a, b) == 0)   { /* равны */ }
if (strcmp(a, b) < 0)    { /* a < b */ }
```

А не `== -1` или `== 1`.

## Объединение: strcat

Прототип:

```cpp
char *strcat(char *dest, const char *src);
```

**Дописывает** `src` в конец `dest`. Возвращает `dest`.

```cpp
#include <stdio.h>
#include <string.h>

int main(void)
{
    char destination[30] = "Hello ";
    char source[30] = "METANIT.COM";

    strcat(destination, source);
    printf("%s\n", destination);   // Hello METANIT.COM
    return 0;
}
```

### Что важно помнить

- `dest` должен иметь **достаточно места** — `strcat` не проверяет границы;
- `dest` должен быть **изменяемым** — нельзя передавать строковый литерал;
- `src` может быть литералом;
- первая строка должна уже содержать `\0` — `strcat` найдёт её конец и допишет дальше.

```cpp
char buf[10] = "Hi";
strcat(buf, " world");   // переполнение: 9 символов + \0 в буфере из 10
```

## Копирование: strcpy

Прототип:

```cpp
char *strcpy(char *dest, const char *src);
```

Копирует `src` в `dest`, включая завершающий `\0`.

```cpp
#include <stdio.h>
#include <string.h>

int main(void)
{
    char destination[20];
    char source[20] = "Hello METANIT.COM!";

    strcpy(destination, source);
    printf("%s\n", destination);
    return 0;
}
```

> **`strcpy` опасна.** Она копирует, **пока не встретит `\0`**, не проверяя размер `dest`. Если `src` длиннее — **переполнение буфера**. Это классическая уязвимость, которой пользовались вирусы и эксплойты.

**Не используйте `strcpy` в новом коде.** Используйте `strncpy` или `snprintf`.

## Безопасное копирование: strncpy

Прототип:

```cpp
char *strncpy(char *dest, const char *src, size_t n);
```

Копирует **не более** `n` символов.

```cpp
#include <stdio.h>
#include <string.h>

int main(void)
{
    char destination[20];
    const char *source = "Hello METANIT.COM!!";
    size_t n = 20;

    strncpy(destination, source, n);
    destination[n - 1] = '\0';   // страховка

    printf("%s\n", destination);
    return 0;
}
```

### Особенности `strncpy`

- если `src` **короче** `n`, `strncpy` добьёт оставшиеся байты `\0`;
- если `src` **длиннее или равен** `n`, `\0` **не будет записан** — об этом легко забыть и потом получить чтение за пределами буфера.

Поэтому после `strncpy` вручную ставят `\0` в последний байт:

```cpp
destination[n - 1] = '\0';
```

> **`strncpy` — не «безопасная замена» `strcpy`.** Это функция с неочевидным поведением. На практике часто удобнее `snprintf`:
> ```cpp
> snprintf(destination, sizeof(destination), "%s", source);
> ```
> Он всегда добавляет `\0`, если в буфере есть место хотя бы под один символ.

### О `strncpy_s`

Некоторые источники упоминают `strncpy_s`:

```cpp
errno_t strncpy_s(char *dest, size_t destmax, const char *src, size_t srcmax);
```

> **Важно:** `strncpy_s` **не входит в стандарт C** (за исключением опционального Приложения K, которое почти никто не реализует). Это расширение Microsoft, доступное в MSVC и некоторых других компиляторах. **Полагаться на него в переносимом коде нельзя.** Используйте `snprintf` или проверяйте длину вручную.

## Поиск подстроки: strstr

Прототип:

```cpp
char *strstr(const char *string, const char *substring);
```

Ищет `substring` внутри `string`. Возвращает указатель на **первое вхождение** или `NULL`, если не нашёл.

```cpp
#include <stdio.h>
#include <string.h>
#include <stddef.h>

int main(void)
{
    char text[30] = "Hello METANIT.COM!";
    const char *substring = "METANIT";

    char *found = strstr(text, substring);

    if (found != NULL)
    {
        ptrdiff_t position = found - text;
        printf("Substring index: %td\n", position);   // 6
    }
    else
    {
        printf("Substring not found\n");
    }

    return 0;
}
```

### Как вычисляется позиция

`strstr` возвращает **адрес** найденной подстроки. Чтобы получить **индекс**, вычитаем адрес начала строки:

```cpp
ptrdiff_t position = found - text;
```

Это **арифметика указателей**: разность даёт количество элементов `char` между адресами — то есть индекс.

### Другие функции поиска

В `<string.h>` есть и другие функции:

- **`strchr(str, c)`** — первое вхождение символа `c`;
- **`strrchr(str, c)`** — последнее вхождение;
- **`strspn`**, **`strcspn`** — длина префикса, состоящего из символов набора;
- **`strpbrk`** — первый символ из набора;
- **`strtok`** — разбиение строки на токены (осторожно: изменяет строку).

## Итог

- Все функции для работы со строками — в **`<string.h>`**.
- **`strlen`** — длина строки (без `\0`), результат типа `size_t`, выводится через `%zu`.
- **`strcmp`** — сравнение строк. `0` = равны. Сравнение через `==` бесполезно.
- **`strcat`** — дописать строку в конец. Место под результат — на вас.
- **`strcpy`** — копировать строку. **Опасна** — переполняет буфер.
- **`strncpy`** — копирует до `n` символов, но **не всегда** ставит `\0`. Ставьте вручную.
- **`strncpy_s`** — расширение Microsoft, **не стандарт C**. Не полагайтесь на него.
- **`strstr`** — поиск подстроки, возвращает указатель. Позиция — разность указателей.
- Для безопасного форматирования строк используйте **`snprintf`**.
