## Возведение в степень: `pow`

```cpp
#include <math.h>
double pow(double base, double exp);
```

Возвращает `base` в степени `exp`. Всегда возвращает **`double`**, даже если аргументы целые.

```cpp
#include <stdio.h>
#include <math.h>

int main(void)
{
    printf("pow(2, 3) = %.0f\n", pow(2, 3));   // 8
    printf("pow(5, 2) = %.0f\n", pow(5, 2));   // 25
    printf("pow(2, -1) = %.2f\n", pow(2, -1)); // 0.50
    return 0;
}
```

> **Подводный камень:** `pow` работает с плавающей точкой. Для целочисленных степеней это **избыточно** и может давать неточности (`pow(10, 2)` может вернуть `99.9999999`). Для целых лучше писать свой цикл или использовать таблицу.

## Округление: `round`, `floor`, `ceil`

```cpp
double round(double x);   // ближайшее целое
double floor(double x);   // вниз
double ceil(double x);    // вверх
```

| Функция | `3.4` | `3.5` | `3.6` | `-3.4` |
| :--- | :---: | :---: | :---: | :---: |
| `round` | 3 | 4 | 4 | -3 |
| `floor` | 3 | 3 | 3 | -4 |
| `ceil` | 4 | 4 | 4 | -3 |

```cpp
#include <stdio.h>
#include <math.h>

int main(void)
{
    double vals[] = { 3.14, 3.49, 3.5, -3.5 };
    for (size_t i = 0; i < 4; i++) {
        printf("%5.2f → round=%5.0f floor=%5.0f ceil=%5.0f\n",
               vals[i], round(vals[i]), floor(vals[i]), ceil(vals[i]));
    }
    return 0;
}
```

> **`round` округляет половину от нуля** (`3.5 → 4`, `-3.5 → -4`). Это не то же самое, что «банковское округление» (`round half to even`). Если нужна такая логика — реализуйте вручную.

## Квадратный корень: `sqrt`

```cpp
double sqrt(double x);
```

Возвращает квадратный корень.

```cpp
#include <stdio.h>
#include <math.h>

int main(void)
{
    printf("sqrt(16) = %.0f\n", sqrt(16));       // 4
    printf("sqrt(2)  = %.5f\n", sqrt(2));        // 1.41421
    return 0;
}
```

> **Осторожно:** `sqrt(-1)` возвращает `NaN` (not a number) и выставляет `errno = EDOM`. Проверяйте аргумент, если он может быть отрицательным.

### Как проверить `NaN`

```cpp
#include <math.h>

if (isnan(result)) {
    printf("Результат — не число\n");
}
```

## Модуль числа: `abs`, `fabs`

| Функция | Заголовок | Тип аргумента | Тип результата |
| :--- | :--- | :--- | :--- |
| `abs` | `<stdlib.h>` | `int` | `int` |
| `labs` | `<stdlib.h>` | `long` | `long` |
| `llabs` | `<stdlib.h>` | `long long` | `long long` |
| `fabs` | `<math.h>` | `double` | `double` |
| `fabsf` | `<math.h>` | `float` | `float` |
| `fabsl` | `<math.h>` | `long double` | `long double` |

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

int main(void)
{
    int m = -15;
    double d = -3.7;

    printf("abs(m)  = %d\n", abs(m));     // 15
    printf("fabs(d) = %.1f\n", fabs(d));  // 3.7

    return 0;
}
```

> **Важно:** `abs` **не работает с `double`**! `abs(-3.7)` вернёт `3` (отбросит дробную часть и превратит в `int`). Для `double` — `fabs`, для `float` — `fabsf`.

## Тригонометрия и логарифмы

Основные функции `<math.h>`:

| Функция | Что считает |
| :--- | :--- |
| `sin(x)`, `cos(x)`, `tan(x)` | Синус, косинус, тангенс (в **радианах**) |
| `asin(x)`, `acos(x)`, `atan(x)` | Обратные тригонометрические |
| `atan2(y, x)` | Арктангенс `y/x` с учётом четверти |
| `exp(x)` | `e` в степени `x` |
| `log(x)` | Натуральный логарифм |
| `log10(x)` | Десятичный логарифм |
| `log2(x)` | Логарифм по основанию 2 |

> **Градусы и радианы.** Тригонометрические функции принимают **радианы**. Для градусов:

```cpp
#include <math.h>

#define PI 3.14159265358979323846

double to_radians(double degrees) {
    return degrees * PI / 180.0;
}

double to_degrees(double radians) {
    return radians * 180.0 / PI;
}
```

### Константы `M_PI`, `M_E`

Многие компиляторы определяют **`M_PI`**, **`M_E`** и другие математические константы в `<math.h>`. Но это **не часть стандарта C** — на некоторых системах их нужно включать через `#define _USE_MATH_DEFINES` (MSVC) или определять вручную. Для переносимости лучше задать свои:

```cpp
#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif
```

## Варианты для `float` и `long double`

Почти у каждой функции `<math.h>` есть **три версии**:

- **`pow`** — `double`;
- **`powf`** — `float`;
- **`powl`** — `long double`.

Использование подходящего варианта ускоряет вычисления там, где точности `double` избыточно, или повышает точность там, где её недостаточно.

```cpp
float  xf = powf(2.0f, 3.0f);      // float
double xd = pow(2.0, 3.0);         // double
long double xl = powl(2.0L, 3.0L); // long double
```

## Как подключить `<math.h>`

На Linux/macOS **некоторые** математические функции требуют линковки с библиотекой `libm`. При компиляции:

```bash
gcc main.c -o main -lm
```

Флаг `-lm` подключает математическую библиотеку. На Windows и на современных Linux с glibc это часто уже включено, но для переносимости указывайте `-lm` **после** всех `.cpp`-файлов.

> **Почему `-lm` в конце?** Компоновщик обрабатывает библиотеки в порядке слева направо. Если поставить `-lm` в начале, символы ещё не будут запрошены — и компоновка провалится. Это стандартное правило для `ld` и `gcc`.

## Итог

- **`<math.h>`** — основная библиотека математических функций.
- **`pow(base, exp)`** — возведение в степень, всегда возвращает `double`.
- **`round`**, **`floor`**, **`ceil`** — разные виды округления.
- **`sqrt(x)`** — квадратный корень; `sqrt(-1)` вернёт `NaN`.
- **`abs`** — для `int`. Для `double` — **`fabs`**. Не путайте.
- Тригонометрия работает в **радианах**, не в градусах.
- Функции имеют варианты: `pow` / `powf` / `powl` — для `double` / `float` / `long double`.
- **`M_PI`** — не стандарт C. Определяйте сами для переносимости.
- На Linux может потребоваться флаг **`-lm`** при линковке.
