# Структуры

**Структура** — составной тип данных, который объединяет несколько компонентов. В отличие от массива компоненты могут иметь **разные типы**. Структура позволяет описывать объекты реального мира: человека (имя + возраст), точку (x + y), товар (название + цена + количество) и т.д.

## Объявление и определение

Для создания структуры используется ключевое слово **`struct`**. Есть две формы: **объявление** (без тела) и **определение** (с телом).

### Объявление без определения

```cpp
struct person;
```

Здесь мы сообщаем компилятору, что существует структура с именем `person`, но **не описываем** её содержимое. Это **неполный тип** (incomplete type): компилятор не знает размер структуры и не может создать переменную такого типа.

### Определение с телом

```cpp
struct имя_структуры
{
    компоненты_структуры
};
```

**Важно:** после закрывающей `}` обязательно ставится **точка с запятой** — в отличие от функций.

Простейший пример:

```cpp
struct person
{
    char *name;
    int age;
};
```

Здесь определены два элемента: `name` (указатель на `char`) и `age` (`int`).

Компоненты структуры объявляются как обычные переменные. Но **память при определении структуры не выделяется** — мы создаём **новый тип**, а не переменную.

> **Правило одного определения.** Структуру можно **объявлять** сколько угодно раз, но **определить** — только один раз во всей программе. Иначе — ошибка «redefinition».

```cpp
struct person;             // объявление — можно
struct person {           // определение — только один раз
    char *name;
    int age;
};
struct person;             // снова объявление — можно
struct person;             // и снова — можно
```

## Неполный тип

Пока структура только **объявлена**, но не определена, она представляет **неполный тип**. С ней можно сделать только одно — объявить **указатель**:

```cpp
#include <stdio.h>

struct person;   // объявлена, но не определена

int main(void)
{
    struct person *tom;   // указатель — можно, размер указателя известен
    return 0;
}
```

Почему это работает? Указатель — это просто адрес. Его размер (обычно 8 байт на 64-разрядных системах) компилятор знает, независимо от того, что лежит по адресу.

А вот создать **саму переменную** или **обратиться к полям** неполного типа нельзя:

```cpp
struct person;   // неполный тип

int main(void)
{
    struct person tom = {"Tom", 22};   // ошибка: incomplete type
    printf("%s\n", tom.name);          // тоже ошибка
    return 0;
}

// определение структуры идёт уже после main — поздно
struct person {
    char *name;
    int age;
};
```

Причина простая: компилятор не знает **размер** структуры и **расположение** её полей, пока не увидит определение. Объявление указателя — единственное, что не требует этой информации.

## Использование структуры

После определения структуры можно создавать **переменные** этого типа:

```cpp
struct person
{
    char *name;
    int age;
};

int main(void)
{
    struct person tom;   // переменная типа struct person
    return 0;
}
```

При создании переменной память **выделяется** — под все поля структуры (с возможными выравниваниями).

## Инициализация

Структуру можно инициализировать при создании — как массив, фигурными скобками. Есть два способа.

### По позиции

Значения идут в том же порядке, что и поля в определении:

```cpp
struct person tom = {"Tom", 23};
```

- `"Tom"` → первое поле `name`;
- `23` → второе поле `age`.

> **Осторожно:** если поменяете порядок полей в структуре, придётся менять и порядок в инициализаторах. Компилятор не всегда предупредит — например, если оба поля `int`.

### По имени

Можно указать, какому полю какое значение — независимо от порядка:

```cpp
struct person tom = {.name = "Tom", .age = 23};
```

Перед именем поля ставится **точка**. Это надёжнее: перестановка полей в структуре не сломает инициализацию.

### Частичная инициализация

Пропущенные поля обнуляются:

```cpp
struct person tom = {.name = "Tom"};   // age = 0
```

## Обращение к элементам

Для доступа к полям используется **операция «точка»**:

```text
имя_переменной.имя_поля
```

Пример:

```cpp
#include <stdio.h>

struct person
{
    char *name;
    int age;
};

int main(void)
{
    struct person tom = {"Tom", 23};

    printf("Age: %d\tName: %s\n", tom.age, tom.name);
    return 0;
}
```

Вывод:

```text
Age: 23	Name: Tom
```

### Присваивание полям

Поля можно заполнять и после создания переменной:

```cpp
#include <stdio.h>

struct person
{
    char *name;
    int age;
};

int main(void)
{
    struct person tom;

    tom.name = "Tom";
    tom.age = 22;

    printf("Name: %s\tAge: %d\n", tom.name, tom.age);
    return 0;
}
```

С полями работают все обычные операции: их можно читать, им можно присваивать, передавать в функции — как обычные переменные соответствующих типов.

## Объединение с переменными

Можно **одновременно** определить структуру и объявить переменные этого типа — между `}` и `;`:

```cpp
struct person
{
    char *name;
    int age;
} tom;   // структура + переменная tom
```

Таких переменных может быть несколько:

```cpp
struct person
{
    char *name;
    int age;
} tom, bob, alice;
```

Можно сразу инициализировать:

```cpp
struct person
{
    char *name;
    int age;
} tom = {"Tom", 38};
```

### Структура без имени

Можно даже не задавать имя структуры:

```cpp
struct
{
    char *name;
    int age;
} tom;
```

Переменная `tom` создана, но **новые переменные этого типа создать уже не получится** — имени у типа нет. Такой приём используют, когда структура нужна один раз.

## typedef

Чаще всего структуры оформляют через **`typedef`** — это даёт короткий псевдоним типа и избавляет от необходимости писать `struct` перед каждой переменной.

```cpp
#include <stdio.h>

typedef struct
{
    char *name;
    int age;
} person;

int main(void)
{
    person tom = {"Tom", 23};

    printf("Name: %s\tAge: %d\n", tom.name, tom.age);
    return 0;
}
```

Здесь `person` — полноценный псевдоним типа. Дальше пишем `person tom` вместо `struct person tom`.

**Это самый распространённый стиль в современном C.** Если не знаете, как оформить — используйте `typedef`.

Можно объединить с именем структуры:

```cpp
typedef struct person
{
    char *name;
    int age;
} person;
```

Тогда доступны оба варианта: `struct person` и `person`.

> **Соглашение об именовании.** Часто тип пишут с заглавной буквы (`Person`), а переменные — со строчной (`tom`). Так сразу видно, где тип, а где переменная.

## Директива define

Структуру можно определить и через **препроцессорную директиву** `#define`:

```cpp
#include <stdio.h>

#define PERSON struct {int age; char name[20];}

int main(void)
{
    PERSON tom = {23, "Tom"};
    printf("Name: %s\tAge: %d\n", tom.name, tom.age);
    return 0;
}
```

Препроцессор **подставит** `struct {int age; char name[20];}` вместо `PERSON` до компиляции.

> **Так делать не рекомендуется.** `#define` не создаёт тип, а просто выполняет текстовую подстановку. Из-за этого:
> - нет нормального имени типа (нельзя объявить указатель `PERSON *p` в отдельной строке);
> - отладчик видит «безымянную» структуру;
> - сообщения об ошибках непонятные.
>
> Для сокращения записи используйте **`typedef`** — он создаёт именно тип, а не макрос.

## Область видимости

Как и переменные, структуры имеют **область видимости**. Структура видна только там, где объявлена.

### Уровень файла

Если структура определена вне функций — она видна **от точки определения до конца файла**:

```cpp
#include <stdio.h>

struct person
{
    char *name;
    int age;
};

void print_person(void)
{
    struct person bob = {"Bob", 33};
    printf("Name: %s\tAge: %d\n", bob.name, bob.age);
}

int main(void)
{
    struct person tom = {"Tom", 22};
    printf("Name: %s\tAge: %d\n", tom.name, tom.age);

    print_person();
    return 0;
}
```

Структура доступна и в `main`, и в `print_person`, потому что определена **выше** них на уровне файла.

### Уровень блока

Если структура объявлена **внутри** функции или блока кода — она видна до конца этого блока:

```cpp
int main(void)
{
    struct person
    {
        char *name;
        int age;
    };

    struct person tom = {"Tom", 22};   // ок

    return 0;   // здесь person ещё существует
}

// вне main структура person не видна
```

Это работает и для **анонимных блоков** `{ ... }`:

```cpp
int main(void)
{
    {
        struct person
        {
            char *name;
            int age;
        };
        struct person tom = {"Tom", 22};
        printf("%s\n", tom.name);
    }
    // здесь person уже не видна

    return 0;
}
```

### Скрытие

Если структура с одним именем объявлена в двух областях, **внутренняя скрывает внешнюю**:

```cpp
#include <stdio.h>

struct number { int x; };   // структура уровня файла

int main(void)
{
    struct number { long y; };   // скрывает внешнюю

    struct number n1 = {22};
    printf("n1: %ld\n", n1.y);   // 22

    return 0;
}
```

Внутри `main` под именем `number` понимается уже структура с полем `y`.

Но переменные, созданные от **внешнего** типа, продолжают работать — компилятор помнит их настоящий тип:

```cpp
#include <stdio.h>

struct number { int x; };
struct number external = {5};   // переменная внешнего типа

int main(void)
{
    struct number { long y; };   // скрывает внешнее определение

    struct number internal = {22};

    printf("external.x = %d\n", external.x);   // 5 — видит внешнее поле
    printf("internal.y = %ld\n", internal.y);  // 22 — внутреннее поле

    return 0;
}
```

Такой код не стоит писать специально — это рецепт путаницы. Но знать, что так можно, полезно.

## Копирование структур

Одну структуру можно присвоить другой **того же типа**. Все поля копируются:

```cpp
#include <stdio.h>

struct person
{
    char *name;
    int age;
};

int main(void)
{
    struct person tom = {"Tom", 38};
    struct person bob = tom;   // копируем поля

    bob.name = "Bob";          // меняем только bob

    printf("bob: %s, %d\n", bob.name, bob.age);   // Bob, 38
    printf("tom: %s, %d\n", tom.name, tom.age);   // Tom, 38

    return 0;
}
```

Вывод:

```text
bob: Bob, 38
tom: Tom, 38
```

После `bob = tom` у каждой переменной **своя копия** полей. Изменение `bob.name` не влияет на `tom.name`.

> **Осторожно с указателями внутри структуры.** Копируется **сам указатель**, а не данные, на которые он указывает. Если в структуре есть `char *`, обе структуры после копирования будут указывать на **одну и ту же строку**. Чтобы получить независимые данные, нужно копировать их отдельно (`strdup`, `malloc` + `strcpy`).

## Ввод с консоли

С полями структуры работают те же операции ввода, что и с обычными переменными. Просто указываем полный путь к полю:

```cpp
#include <stdio.h>

struct person
{
    int age;
    char name[20];
};

int main(void)
{
    struct person tom = {23, "Tom"};

    printf("Enter name: ");
    scanf("%s", tom.name);          // массив — без &

    printf("Enter age: ");
    scanf("%d", &tom.age);          // обычная переменная — с &

    printf("Name: %s\tAge: %d\n", tom.name, tom.age);
    return 0;
}
```

```text
Enter name: Eugene
Enter age: 33
Name: Eugene	Age: 33
```

Обратите внимание: `tom.name` — массив `char[20]`, поэтому `&` не нужен. А `tom.age` — обычный `int`, поэтому нужен `&`.

> **Важно:** если бы `name` был `char *` (указателем), а не массивом, `scanf` бы не сработал — указатель не указывает ни на какую выделенную память. Для ввода строк в структуру надёжнее использовать **массив фиксированного размера** или `malloc`.

## Итог

- **Структура** — составной тип из полей разных типов. Определяется через `struct`.
- После `}` ставится **точка с запятой**.
- **Объявление** (`struct person;`) создаёт неполный тип. Можно только объявить указатель.
- **Определение** описывает поля и позволяет создавать переменные.
- Память выделяется **при создании переменной**, а не при определении структуры.
- **Инициализация:** по позиции (`{"Tom", 23}`) или по имени (`{.name="Tom", .age=23}`).
- Доступ к полям — через **точку**: `tom.name`.
- **`typedef`** — стандартный способ оформить структуру; избавляет от `struct` перед каждой переменной.
- `#define` для структур — **плохая практика**, используйте `typedef`.
- Структуры имеют **область видимости**, как переменные. Внутренняя скрывает внешнюю.
- Структуры **копируются целиком**, включая указатели (но не данные, на которые они указывают).
- Поля структуры участвуют в `scanf`/`printf` как обычные переменные.
