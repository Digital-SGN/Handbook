# Перечисления

**Перечисление** (`enum`) — тип, содержащий **именованный набор констант**. Каждой константе соответствует целое число. Перечисления позволяют заменить «магические числа» (0, 1, 2) осмысленными именами (`ADD`, `SUBTRACT`, `MULTIPLY`).

## Определение

Синтаксис:

```c
enum название {
    константа1,
    константа2,
    ...
    константаN
};
```

Пример — перечисление арифметических операций:

```cpp
#include <stdio.h>

enum operation
{
    ADD,        // 0
    SUBTRACT,   // 1
    MULTIPLY    // 2
};

int main(void)
{
    enum operation op = ADD;
    printf("Operation: %d\n", op);   // 0
    return 0;
}
```

Переменная `op` объявлена как `enum operation`. Ей можно присвоить одну из констант — `ADD`, `SUBTRACT` или `MULTIPLY`.

> **Совет:** в C перед именем типа всегда пишется `struct`, `enum` или `union`. Например, `enum operation op;`. Чтобы не писать `enum` каждый раз, используйте `typedef` (см. ниже).

## Числовые значения

По умолчанию:

- первая константа получает **`0`**;
- каждая следующая — на **`1`** больше.

```cpp
enum operation { ADD, SUBTRACT, MULTIPLY };
// ADD=0, SUBTRACT=1, MULTIPLY=2
```

### Явное присваивание

Если первая константа задана, остальные продолжают нумерацию:

```cpp
enum operation
{
    ADD = 5,       // 5
    SUBTRACT,      // 6
    MULTIPLY       // 7
};
```

Можно задать **каждой** своё значение:

```cpp
enum operation
{
    ADD = 1,
    SUBTRACT = 2,
    MULTIPLY = 4
};
```

Значения могут **дублироваться** — компилятор не против. Но не стоит: теряется смысл перечисления.

### Перечисление — это `int`

Константы `enum` — целые числа типа `int` (обычно). Их можно присвоить обычной переменной:

```cpp
enum operation op = MULTIPLY;
int code = op;
printf("%d\n", code);   // 2
```

Обратное тоже работает: любое целое можно присвоить `enum`-переменной, даже не из набора. Язык это позволяет, но такое значение будет «нелегальным» с точки зрения логики программы. Проверка — на вас.

## typedef

Чаще всего перечисления оформляют через `typedef`, чтобы не писать `enum` перед каждой переменной:

```cpp
#include <stdio.h>

typedef enum
{
    ADD,
    SUBTRACT,
    MULTIPLY
} operation;

int main(void)
{
    operation op = SUBTRACT;
    printf("op = %d\n", op);   // 1
    return 0;
}
```

Теперь `operation` — полноценный псевдоним типа. `enum operation` больше не нужно.

Можно объединить имя и псевдоним:

```cpp
typedef enum operation
{
    ADD,
    SUBTRACT,
    MULTIPLY
} operation;
```

Тогда работают оба варианта: `enum operation` и `operation`.

## Применение в `switch`

Классический сценарий — выбрать поведение по значению перечисления:

```cpp
#include <stdio.h>

typedef enum
{
    ADD = 1,
    SUBTRACT = 2,
    MULTIPLY = 4
} operation;

int calculate(int x, int y, operation op)
{
    switch (op)
    {
        case ADD:      return x + y;
        case SUBTRACT: return x - y;
        case MULTIPLY: return x * y;
        default:       return 0;
    }
}

int main(void)
{
    printf("%d\n", calculate(4, 3, MULTIPLY));   // 12
    printf("%d\n", calculate(4, 3, ADD));        // 7
    printf("%d\n", calculate(4, 3, SUBTRACT));   // 1
    return 0;
}
```

Такой код читается гораздо лучше, чем `case 4:`. И компилятор может предупредить, если в `switch` пропущено одно из значений `enum` (например, с флагом `-Wswitch`).

## Анонимное перечисление в структуре

Если перечисление нужно **только внутри одной структуры**, ему можно не давать имя:

```cpp
#include <stdio.h>

struct binary_op
{
    int n1;
    int n2;
    enum { ADD, SUBTRACT, MULTIPLY } op;
};

int main(void)
{
    struct binary_op mul = { .n1 = 6, .n2 = 8, .op = MULTIPLY };

    printf("Operands: %d and %d, op: %d\n", mul.n1, mul.n2, mul.op);
    // Operands: 6 and 8, op: 2

    return 0;
}
```

Здесь `enum { ... } op` объявляет **поле** `op` — переменную безымянного типа-перечисления. Вне структуры эти константы использовать нельзя.

> **Осторожно:** анонимное перечисление внутри структуры **всё равно засоряет глобальное пространство имён**. Имена `ADD`, `SUBTRACT`, `MULTIPLY` видны и снаружи. Так что если у вас есть другая структура с полем `enum { ADD, ... }` — будет конфликт имён. Поэтому часто всё же дают имя.

## Зачем нужны перечисления

Можно было бы обойтись обычными числами:

```cpp
int result = calculate(4, 3, 4);   // что такое 4?
```

Но перечисления дают:

- **Читаемость.** `MULTIPLY` говорит само за себя, `4` — нет.
- **Ограниченный набор.** Компилятор подскажет доступные варианты.
- **Безопасность изменений.** Если добавите новую операцию, легко найти все места, где нужно её обработать.
- **Самодокументируемость.** Объявление `enum operation` сразу описывает возможные значения.

## Итог

- **`enum`** — тип из именованных целочисленных констант.
- По умолчанию первая константа — `0`, каждая следующая — `+1`.
- Значения можно задавать явно: `ADD = 5` — и далее по порядку, либо каждой.
- Константы `enum` — это `int`, их можно присваивать числовым переменным.
- Чаще всего оформляют через **`typedef`**, чтобы не писать `enum` перед переменной.
- Основное применение — **`switch`** по значению перечисления.
- Анонимные `enum` внутри структур **не изолируют** имена — они всё равно глобальные.
- `enum` заменяет «магические числа» на осмысленные имена и делает код надёжнее.
