# Введение в массивы и строки

Когда нужно хранить не одно значение, а **набор однотипных** — используют **массивы**.

**Массив** — это набор значений одного типа, расположенных в памяти подряд. Каждое значение доступно по своему **индексу**.

```cpp
тип_переменной имя_массива[длина_массива];
```

Пример — массив из четырёх `int`:

```cpp
int numbers[4];
```

## Индексы

Обратиться к отдельному элементу массива можно по **индексу** — номеру элемента в квадратных скобках. Индексы начинаются **с нуля**.

```cpp
#include <stdio.h>

int main(void)
{
    int numbers[4];
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    numbers[3] = 4;

    printf("numbers[0] = %d\n", numbers[0]);   // 1
    printf("numbers[2] = %d\n", numbers[2]);   // 3

    return 0;
}
```

| Значение | 1 | 2 | 3 | 4 |
| :--- | :--- | :--- | :--- | :--- |
| Индекс | 0 | 1 | 2 | 3 |

> **Важно:** выход за пределы массива в C **не проверяется**. Обращение к `numbers[10]` в массиве из четырёх элементов не вызовет ошибку компиляции и, скорее всего, не вызовет ошибку во время выполнения — но прочитает или запишет «мусор» из соседней памяти. Это одна из самых частых причин загадочных багов в C.

## Инициализация массива

Массив можно инициализировать **при объявлении**, перечислив значения в фигурных скобках:

```cpp
int numbers[4] = { 1, 2, 3, 5 };
printf("numbers[2] = %d", numbers[2]);   // 3
```

Значения присваиваются элементам **по порядку**.

### Длину можно не указывать

Если в инициализаторе перечислены все элементы, длину массива можно опустить — компилятор посчитает её сам:

```cpp
int numbers[] = { 1, 2, 3, 5 };   // длина 4
```

### Частичная инициализация

Если значений меньше, чем элементов, остальные **обнуляются**:

```cpp
int numbers[5] = { 10, 12 };   // 10, 12, 0, 0, 0
```

Это важное отличие от локальных переменных без инициализации: там значение не определено, а в массиве отсутствующие элементы получают `0`.

### Инициализация по индексам

Можно указать конкретные индексы через `[i] =`:

```cpp
int numbers[5] = { [1] = 11, [3] = 13 };
```

Это эквивалентно:

```cpp
int numbers[5] = { 0, 11, 0, 13, 0 };
```

Удобно, когда нужно задать только отдельные элементы.

## Размер и количество элементов

Оператор `sizeof` возвращает **размер массива в байтах**:

```cpp
#include <stdio.h>

int main(void)
{
    int numbers[] = { 5, 6, 7 };
    size_t size = sizeof(numbers);

    printf("numbers size: %zu\n", size);   // 12
    return 0;
}
```

Почему 12? Массив содержит 3 элемента типа `int`, каждый — 4 байта: `3 × 4 = 12`.

`sizeof` возвращает значение типа `size_t`. Для вывода используем спецификатор `%zu`.

### Количество элементов

Зная размер одного элемента, можно получить **количество**:

```cpp
size_t count = sizeof(numbers) / sizeof(int);            // 3
```

Или, что надёжнее, — через первый элемент массива:

```cpp
size_t count = sizeof(numbers) / sizeof(numbers[0]);     // 3
```

Второй способ предпочтительнее: если тип элементов изменится, `sizeof(int)` придётся править, а `sizeof(numbers[0])` подстроится сам.

### Динамическое вычисление элементов

Элементы массива могут быть вычислены на этапе инициализации:

```cpp
int sizes[] = { sizeof(int), sizeof(long), sizeof(long long) };
sizes[1] = sizeof(char);   // теперь sizes[1] == 1
```

## Перебор элементов

По массиву удобно проходить циклом `for`:

```cpp
#include <stdio.h>

int main(void)
{
    int numbers[] = { 10, 12, 13, 54, 43 };
    size_t count = sizeof(numbers) / sizeof(numbers[0]);

    for (size_t i = 0; i < count; i++)
    {
        printf("numbers[%zu] = %d\n", i, numbers[i]);
    }
    return 0;
}
```

### `size_t` или `int` для индекса

Технически можно использовать и `int`:

```cpp
for (int i = 0; i < count; i++)
{
    printf("numbers[%d] = %d\n", i, numbers[i]);
}
```

Результат тот же, но у `int` есть **знаковый** диапазон, и на очень больших массивах его может не хватить. `size_t` — беззнаковый тип, специально предназначенный для размеров и индексов. **Рекомендуется использовать `size_t`.**

## Динамическая установка размера

Размер массива можно задать переменной или константой:

```cpp
#include <stdio.h>

int main(void)
{
    int maxSize = 3;
    int array[maxSize];

    array[0] = 1;
    array[1] = 2;
    array[2] = 3;

    for (int i = 0; i < maxSize; i++)
    {
        printf("%d", array[i]);
    }
    return 0;
}
```

> **Осторожно: это VLA (Variable-Length Array).** Такие массивы появились в стандарте **C99**, но их поддержка **необязательна** — некоторые компиляторы их не принимают, а C11 сделал их опциональными. Для динамических размеров надёжнее использовать `malloc` из `<stdlib.h>` (разбирается в главе про динамическую память).

### Нельзя совместить динамический размер с инициализацией

```cpp
int maxSize = 3;
int array[maxSize] = { 1, 2, 3 };   // ошибка
```

Если размер не константа — инициализатор использовать нельзя.

## Константные массивы

Элементы обычного массива можно менять:

```cpp
#include <stdio.h>

int main(void)
{
    int numbers[3] = { 11, 12, 13 };
    numbers[1] = 22;

    printf("numbers[1] = %d\n", numbers[1]);   // 22
    return 0;
}
```

Если массив не должен изменяться, его объявляют через `const`:

```cpp
#include <stdio.h>

int main(void)
{
    const int numbers[3] = { 11, 12, 13 };
    // numbers[1] = 22;   // ошибка: массив константный

    printf("numbers[1] = %d\n", numbers[1]);   // 12
    return 0;
}
```

Попытка изменить элемент константного массива — **ошибка компиляции**.

## Многомерные массивы

Массив может быть **многомерным**: его элементы — тоже массивы. Чаще всего используют двумерные массивы, которые удобно представлять как таблицу.

```cpp
int numbers[3][2] = { {1, 2}, {4, 5}, {7, 8} };
```

Здесь 3 строки по 2 столбца:

| | | 
| :---: | :---: |
| 1 | 2 | 
| 4 | 5 | 
| 7 | 8 | 

Обращение к элементу — по двум индексам:

```cpp
printf("numbers[1][0] = %d\n", numbers[1][0]);   // 4
```

Другой пример — 2 строки по 3 столбца:

```cpp
int numbers[2][3] = { {1, 2, 4}, {5, 7, 8} };
```

### Перебор двумерного массива

Используют **вложенные циклы**:

```cpp
#include <stdio.h>

int main(void)
{
    int numbers[3][2] = { {1, 2}, {4, 5}, {7, 8} };

    for (int i = 0; i < 3; i++)         // строки
    {
        for (int j = 0; j < 2; j++)     // столбцы
        {
            printf("numbers[%d][%d] = %d\n", i, j, numbers[i][j]);
        }
    }
    return 0;
}
```

### Размеры через sizeof

Как и в одномерном случае, размеры можно получить через `sizeof`:

```cpp
size_t rows_count    = sizeof(numbers) / sizeof(numbers[0]);            // 3
size_t columns_count = sizeof(numbers[0]) / sizeof(numbers[0][0]);      // 2
```

`numbers[0]` — это первая строка (массив из 2 элементов), `numbers[0][0]` — первый элемент этой строки.

### Многомерный массив — это абстракция

Физически все массивы в C — **одномерные блоки памяти**. Двумерный массив — просто способ **адресации**: `numbers[i][j]` превращается в `numbers[i * columns + j]`.

Поэтому такой массив можно инициализировать как плоский:

```cpp
int numbers[3][2] = { 1, 2, 4, 5, 7, 8 };
```

Компилятор разложит значения по строкам сам.

## Строки

**Строка** в C — это **массив символов** `char`. Отдельного типа «строка» в языке нет.

```cpp
#include <stdio.h>

int main(void)
{
    char message[] = "Hello";
    printf("message: %s\n", message);   // message: Hello
    return 0;
}
```

Строки записываются в **двойных кавычках**.

### Нулевой символ `\0`

Каждая строка заканчивается **нулевым символом** `\0` — байтом со значением `0`. Это признак конца строки.

В строке `"Hello"` на самом деле **6 символов**, а не 5:

| H | e | l | l | o | \0 |
| :---: | :---: | :---: | :---: | :---: | :---: |

Пример — вывод ASCII-кодов всех символов:

```cpp
#include <stdio.h>

int main(void)
{
    char message[] = "Hello";
    size_t length = sizeof(message) / sizeof(char);   // 6

    for (size_t i = 0; i < length; i++)
    {
        printf("%d ", message[i]);
    }
    return 0;
}
```

Вывод:

```text
72 101 108 108 111 0
```

В конце — `0`: это и есть нулевой байт.

### Строка как явный массив символов

То же самое можно записать вручную:

```cpp
char message[] = { 'H', 'e', 'l', 'l', 'o', '\0' };
```

Без завершающего `\0` это будет уже **не строка**, а просто массив символов. Функции вроде `printf("%s", ...)` не поймут, где заканчивается текст, и будут читать память дальше — до первого случайного нуля.

> **Подробнее о строках** — отдельная глава. Здесь достаточно понимать, что строка в C — это массив `char` с завершающим `\0`.

## Пример: умножение матриц

Разберём классическую задачу — умножение двух матриц.

```cpp
#include <stdio.h>

int main(void)
{
    const int r1 = 3, c1r2 = 2, c2 = 1;

    int matrix1[3][2] = { {1, 2}, {3, 4}, {5, 6} };
    int matrix2[2][1] = { {10}, {20} };
    int matmult[r1][c2];

    // обнуляем результирующую матрицу
    for (int i = 0; i < r1; i++)
    {
        for (int j = 0; j < c2; j++)
        {
            matmult[i][j] = 0;
        }
    }

    // умножаем
    for (int i = 0; i < r1; i++)
    {
        for (int j = 0; j < c2; j++)
        {
            for (int k = 0; k < c1r2; k++)
            {
                matmult[i][j] += matrix1[i][k] * matrix2[k][j];
            }
        }
    }

    // выводим результат
    printf("Result\n");
    for (int i = 0; i < r1; i++)
    {
        for (int j = 0; j < c2; j++)
        {
            printf("%d ", matmult[i][j]);
        }
        printf("\n");
    }

    return 0;
}
```

Вывод:

```text
Result
50
110
170
```

### Разбор

Даны две матрицы:

- `matrix1` — 3×2:

  | 1 | 2 |
  | :---: | :---: |
  | 3 | 4 |
  | 5 | 6 |

- `matrix2` — 2×1 (фактически столбец):

  | 10 |
  | :---: |
  | 20 |

Размеры:

```cpp
const int r1   = 3;   // строк в первой матрице
const int c1r2 = 2;   // столбцов в первой и строк во второй
const int c2   = 1;   // столбцов во второй
```

**Правило умножения матриц:** элемент результата в строке `i` и столбце `j` — это сумма произведений элементов `i`-й строки первой матрицы на соответствующие элементы `j`-го столбца второй.

Формула:

```text
c[i][j] = a[i][0]*b[0][j] + a[i][1]*b[1][j] + ...
```

Три вложенных цикла:

- `i` — по строкам первой матрицы;
- `j` — по столбцам второй матрицы;
- `k` — по общим элементам строки/столбца.

Обратите внимание на `+=`:

```cpp
matmult[i][j] += matrix1[i][k] * matrix2[k][j];
```

Это то же самое, что:

```cpp
matmult[i][j] = matmult[i][j] + matrix1[i][k] * matrix2[k][j];
```

Но короче и сразу показывает, что значение **накапливается**.

## Итог

- **Массив** — набор однотипных значений, доступных по индексу.
- Индексы начинаются с **нуля**; выход за пределы массива **не проверяется**.
- Инициализатор — `{ ... }`. Недостающие элементы обнуляются.
- Длину можно не указывать, если заданы все элементы.
- `sizeof(arr)` — размер в байтах; `sizeof(arr) / sizeof(arr[0])` — количество элементов.
- Для индексов лучше использовать **`size_t`**.
- Динамический размер массива (**VLA**) поддерживается не всеми компиляторами — для надёжности используйте `malloc`.
- `const` массив запрещает изменение элементов.
- **Двумерный массив** — таблица; для перебора нужны вложенные циклы. Физически это плоский блок памяти.
- **Строка** — массив `char`, заканчивающийся нулевым символом `\0`.
