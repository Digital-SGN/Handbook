# Специальные сортировки

**Специальные сортировки** способны обгонять барьер `O(n log n)`, потому что **не сравнивают элементы друг с другом**. Вместо сравнений они опираются на природу данных: известный диапазон целых чисел, разряды или равномерное распределение.

## Сортировка подсчётом (Counting Sort)

Подходит для **целых чисел** из небольшого известного диапазона `[0, k]`:
1. Считаем, сколько раз встречается каждое число из диапазона.
2. Вычисляем префиксные суммы — узнаём точную позицию в итоговом массиве для каждого значения.
3. Проходим исходный массив **с конца** и расставляем элементы по местам (обход с конца сохраняет устойчивость).

- **Сложность:** `O(n + k)` по времени и `O(n + k)` по памяти. Если `k` сопоставимо с `n`, получаем линейное время `O(n)`.
- **Устойчивость:** устойчива.
- **Где применять:** оценки (`0–100`), возраст, байты (`0–255`), любые ключи из узкого целочисленного диапазона.

## Поразрядная сортировка (Radix Sort)

Сортирует числа или строки фиксированной длины **по разрядам** — от младшего разряда к старшему (LSD Radix Sort). На каждом разряде запускается устойчивая сортировка (обычно Counting Sort по одной цифре).

**Пример для `170, 45, 75, 90, 802, 24, 2, 66`:**
- по единицам: `170, 90, 802, 2, 24, 45, 75, 66`
- по десяткам: `802, 2, 24, 45, 66, 170, 75, 90`
- по сотням: `2, 24, 45, 66, 75, 90, 170, 802`

- **Сложность:** `O(d · (n + k))`, где `d` — число разрядов, `k` — основание системы счисления. При фиксированном `d` сложность линейна.
- **Устойчивость:** устойчива.

## Блочная сортировка (Bucket Sort)

Хорошо работает для чисел, **равномерно распределённых** на интервале `[0, 1)`:
1. Создаём `n` корзин (блоков).
2. Раскладываем элементы по корзинам пропорционально их значению.
3. Сортируем каждую корзину отдельно (например, вставками) и объединяем результат.

- **Сложность:** `O(n)` в среднем при равномерном распределении, но `O(n²)` в худшем случае, если почти все числа попадут в одну корзину.
- **Устойчивость:** зависит от сортировки внутри корзин.
