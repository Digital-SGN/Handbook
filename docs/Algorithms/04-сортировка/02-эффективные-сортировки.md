# Эффективные сортировки

**Эффективные сортировки** работают за `O(n log n)` — это асимптотический предел для любых алгоритмов сортировки, основанных на попарных сравнениях элементов.

## Пирамидальная сортировка (Heapsort)

**Бинарная куча (пирамида)** — это почти полное бинарное дерево, упакованное прямо в обычный массив без указателей. Для индекса `i` (при нумерации с нуля):
- левый потомок: `2i + 1`;
- правый потомок: `2i + 2`;
- родитель: `(i - 1) / 2`.

В **max-heap** каждый родитель не меньше своих потомков, поэтому в корне (`a[0]`) всегда лежит максимум.

**Как работает сортировка:**
1. Строим max-heap на месте за `O(n)`, просеивая элементы вниз начиная с середины массива.
2. `n - 1` раз меняем корень `a[0]` с последним элементом кучи, уменьшаем размер кучи и восстанавливаем её свойство просеиванием.

- **Сложность:** `O(n log n)` в лучшем, среднем и худшем случае.
- **Память:** `O(1)` дополнительной памяти.
- **Устойчивость:** не устойчива.

## Быстрая сортировка (Quicksort)

Алгоритм по принципу **«разделяй и властвуй»**:
1. Выбираем опорный элемент (`pivot`).
2. Разделяем массив (`partition`) так, чтобы слева оказались элементы `≤ pivot`, а справа — `≥ pivot`.
3. Рекурсивно сортируем левую и правую части.

- **Сложность:** `O(n log n)` в среднем, но `O(n²)` в худшем случае (если опорный элемент раз за разом оказывается минимальным или максимальным).
- **Память:** `O(log n)` на стек рекурсии в среднем, сортировка идёт на месте.
- **Устойчивость:** не устойчива.
- **На практике:** часто быстрее других алгоритмов за счёт малых констант и отличной работы с кэшем процессора.

### Как защититься от худшего случая
- Выбирать опорный элемент **случайно** или как **медиану из трёх** (первый, средний, последний).
- Использовать **интроспективную сортировку (Introsort)**: если глубина рекурсии превышает `2 · log₂ n`, переключаться на Heapsort (так устроен `std::sort` в C++).

## Сортировка слиянием (Merge Sort)

Тоже «разделяй и властвуй», но основная работа происходит при объединении частей:
1. Делим массив пополам, пока не останутся подмассивы длины `1`.
2. Рекурсивно сортируем обе половины.
3. **Сливаем** два отсортированных подмассива в один за `O(n)`.

- **Сложность:** `O(n log n)` гарантированно в любом случае.
- **Память:** требует `O(n)` дополнительной памяти под временный буфер.
- **Устойчивость:** устойчива.
- **Где незаменима:** внешняя сортировка файлов (когда данные не влезают в RAM) и сортировка связных списков (там слияние работает без лишней памяти).

## Реализация на C

```c
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

// ===== Пирамидальная сортировка =====

// Просеивание элемента i вниз для восстановления свойства max-heap
static void heapify(int a[], size_t n, size_t i) {
    size_t largest = i;
    size_t left = 2 * i + 1;
    size_t right = 2 * i + 2;

    if (left < n && a[left] > a[largest]) {
        largest = left;
    }
    if (right < n && a[right] > a[largest]) {
        largest = right;
    }

    if (largest != i) {
        int tmp = a[i];
        a[i] = a[largest];
        a[largest] = tmp;
        heapify(a, n, largest);
    }
}

void heapSort(int a[], size_t n) {
    if (n < 2) {
        return;
    }

    // 1. Строим max-heap на месте снизу вверх
    for (long i = (long)n / 2 - 1; i >= 0; i--) {
        heapify(a, n, (size_t)i);
    }

    // 2. Выталкиваем максимум в конец и восстанавливаем кучу на оставшейся части
    for (size_t i = n; i > 1; i--) {
        int tmp = a[0];
        a[0] = a[i - 1];
        a[i - 1] = tmp;
        heapify(a, i - 1, 0);
    }
}

// ===== Быстрая сортировка =====

static void quickSortRec(int a[], long left, long right) {
    if (left >= right) {
        return;
    }

    // Берём средний элемент как опорный
    int pivot = a[left + (right - left) / 2];
    long i = left;
    long j = right;

    // Разделяем участок [left..right] относительно pivot
    while (i <= j) {
        while (a[i] < pivot) {
            i++;
        }
        while (a[j] > pivot) {
            j--;
        }
        if (i <= j) {
            int tmp = a[i];
            a[i] = a[j];
            a[j] = tmp;
            i++;
            j--;
        }
    }

    quickSortRec(a, left, j);
    quickSortRec(a, i, right);
}

void quickSort(int a[], size_t n) {
    if (n > 1) {
        quickSortRec(a, 0, (long)n - 1);
    }
}

// ===== Сортировка слиянием =====

// Сливает два отсортированных участка a[left..mid] и a[mid+1..right]
static void merge(int a[], int tmp[], size_t left, size_t mid, size_t right) {
    size_t i = left;
    size_t j = mid + 1;
    size_t k = left;

    while (i <= mid && j <= right) {
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    }
    while (i <= mid) {
        tmp[k++] = a[i++];
    }
    while (j <= right) {
        tmp[k++] = a[j++];
    }

    for (size_t p = left; p <= right; p++) {
        a[p] = tmp[p];
    }
}

static void mergeSortRec(int a[], int tmp[], size_t left, size_t right) {
    if (left >= right) {
        return;
    }
    size_t mid = left + (right - left) / 2;
    mergeSortRec(a, tmp, left, mid);
    mergeSortRec(a, tmp, mid + 1, right);
    merge(a, tmp, left, mid, right);
}

void mergeSort(int a[], size_t n) {
    if (n < 2) {
        return;
    }
    int *tmp = malloc(n * sizeof(int));
    if (tmp == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }
    mergeSortRec(a, tmp, 0, n - 1);
    free(tmp);
}
```

## Итог

- **Heapsort** даёт стабильные `O(n log n)` без лишней памяти, но не устойчива.
- **Quicksort** быстрее всех на практике в среднем (`O(n log n)`), но в худшем случае деградирует до `O(n²)` без защиты выбора опорного элемента.
- **Merge Sort** гарантирует `O(n log n)` и устойчивость, но требует `O(n)` дополнительной памяти.
