# Бинарные деревья поиска

Представьте, что у вас есть миллион чисел, и вам нужно быстро отвечать
на вопросы «есть ли тут число X?», «какое следующее по величине после X?»,
«что самое маленькое?». Хеш-таблица умеет только первое. Массив —
медленно. А **бинарное дерево поиска** (BST) умеет всё четыре, и каждое
действие — за `O(log n)` в среднем случае.

BST — это и словарь, и упорядоченное множество, и очередь с приоритетами
одновременно. Неудивительно, что это одна из самых изучаемых структур
данных.

В этой главе разберёмся: как BST хранит порядок, как искать, вставлять
и удалять, и почему удаление — самая хитрая операция из всех.

## Свойство бинарного дерева поиска

Каждый узел BST содержит:

- `key` — ключ, по которому идёт сравнение;
- `left` — указатель на левого ребёнка (или `NULL`);
- `right` — указатель на правого ребёнка (или `NULL`);
- `parent` — указатель на родителя (нужен для некоторых операций).

**Свойство BST:** для любого узла `x` все ключи в его **левом** поддереве
**не больше** `key[x]`, а все ключи в **правом** — **не меньше** `key[x]`.

```
         15
        /  \
       6    18
      / \   / \
     3   7 17 20
```

Проверьте: в левом поддереве корня (15) все ключи ≤ 15. В правом — ≥ 15.
То же самое для каждого поддерева рекурсивно.

> **Главная мысль:** BST — это упорядоченность, встроенная в структуру.
> На каждом шаге поиска вы **отбрасываете половину** дерева, потому что
> знаете: «всё, что меньше — слева, всё, что больше — справа».

Высота `h` — ключевое число. Если дерево **сбалансировано**, `h = O(log n)`
и все операции `O(log n)`. Если дерево **вырождено** (вставили ключи
по возрастанию — получили «палку»), `h = O(n)` и BST превращается
в связный список. Об этом — в следующей главе про балансировку.

## Поиск ключа

Идея простая: спускаемся от корня, на каждом узле сравниваем ключ.

- Совпал — нашли.
- Искомый меньше — идём влево.
- Искомый больше — идём вправо.

```text
TREE_SEARCH(x, k):
1  if x = NIL или k = key[x] then return x
2  if k < key[x] then return TREE_SEARCH(left[x], k)
3  else return TREE_SEARCH(right[x], k)
```

Рекурсия легко превращается в цикл — и **так делать почти всегда лучше**:

```c
Node* bstSearch(Bst *tree, int key) {
    Node *x = tree->root;
    while (x != NULL && key != x->key) {
        x = (key < x->key) ? x->left : x->right;
    }
    return x;
}
```

> **Важно:** итеративная версия не тратит стек вызовов и работает быстрее.
> Рекурсия здесь — только для красоты псевдокода. В реальном коде — цикл.

Время работы — **`O(h)`**, где `h` — высота дерева.

## Минимум и максимум

Минимум — это **самый левый** узел. Максимум — **самый правый**.
Логика: если всё слева меньше, то идти влево, пока можно, — и упрётесь
в минимум.

```c
Node* bstMinimum(Node *x) {
    while (x != NULL && x->left != NULL) x = x->left;
    return x;
}

Node* bstMaximum(Node *x) {
    while (x != NULL && x->right != NULL) x = x->right;
    return x;
}
```

Обе — `O(h)`. Простые и быстрые.

## Предшествующий и последующий

**Последующий** (successor) — узел с наименьшим ключом, **большим** чем
`key[x]`. **Предшествующий** (predecessor) — с наибольшим ключом,
**меньшим** `key[x]`. Проще говоря: «следующий по величине» и
«предыдущий по величине».

Логика successor:

1. Если у узла **есть правое поддерево** — successor это **минимум**
   в этом правом поддереве. Потому что все ключи справа больше `x`,
   а минимум среди них — ближайший.
2. Если правого поддерева **нет** — поднимаемся к родителю, пока не
   найдём такого, для которого `x` — **левый** ребёнок. Этот родитель
   и есть successor.

```c
Node* bstSuccessor(Node *x) {
    if (x->right != NULL) return bstMinimum(x->right);
    Node *y = x->parent;
    while (y != NULL && x == y->right) {
        x = y;
        y = y->parent;
    }
    return y;
}
```

Predecessor — симметрично: либо максимум левого поддерева, либо первый
родитель, у которого `x` — правый ребёнок.

Обе операции — `O(h)`.

> **Главная мысль:** successor/predecessor — это «соседи по сортировке».
> Они нужны в задачах «найти следующий элемент в упорядоченном множестве»,
> «пройти по всем ключам по порядку», «найти ближайший ключ к заданному».

## Вставка

Вставка нового ключа `z`:

1. Спускаемся от корня, как при поиске, запоминая родителя `y`.
2. Когда дошли до `NULL` — вставляем `z` как ребёнка `y`.

```c
Node* bstInsert(Bst *tree, int key) {
    Node *z = malloc(sizeof(Node));
    z->key = key;
    z->left = z->right = z->parent = NULL;

    Node *y = NULL;
    Node *x = tree->root;
    while (x != NULL) {
        y = x;
        x = (key < x->key) ? x->left : x->right;
    }
    z->parent = y;
    if (y == NULL) tree->root = z;
    else if (key < y->key) y->left = z;
    else y->right = z;
    tree->count++;
    return z;
}
```

Время — `O(h)`.

> **Важно:** если ключ уже есть в дереве, эта реализация добавит дубликат
> в правое поддерево. Часто это нежелательно — в таком случае перед
> вставкой проверяют, что ключа нет, и обновляют значение, если есть.

## Удаление

Вот здесь начинается веселье. Удалить лист — легко. Удалить узел
с одним ребёнком — тоже несложно. А вот удалить узел с **двумя** детьми —
это задача, на которой спотыкаются на собеседованиях.

Три случая:

**Случай 1: у узла нет детей.** Просто обнуляем ссылку родителя.

**Случай 2: у узла один ребёнок.** «Склеиваем» родителя с этим ребёнком.

**Случай 3: у узла два ребёнка.** Находим **successor** (минимум правого
поддерева). Он точно не имеет левого ребёнка. Ставим его на место
удаляемого узла.

```c
static void bstTransplant(Bst *tree, Node *u, Node *v) {
    if (u->parent == NULL) tree->root = v;
    else if (u == u->parent->left) u->parent->left = v;
    else u->parent->right = v;
    if (v != NULL) v->parent = u->parent;
}

void bstDelete(Bst *tree, Node *z) {
    if (z->left == NULL) {
        bstTransplant(tree, z, z->right);
    } else if (z->right == NULL) {
        bstTransplant(tree, z, z->left);
    } else {
        Node *y = bstMinimum(z->right);   // successor
        if (y->parent != z) {
            bstTransplant(tree, y, y->right);
            y->right = z->right;
            y->right->parent = y;
        }
        bstTransplant(tree, z, y);
        y->left = z->left;
        y->left->parent = y;
    }
    free(z);
    tree->count--;
}
```

> **Важно:** функция `bstTransplant` — это «пересадка» поддерева.
> Она используется трижды в `bstDelete`, поэтому вынесена отдельно.
> Это классический приём: общий код — в вспомогательную функцию,
> а не копипаста.

Время — `O(h)`.

## Реализация на C

Полная рабочая реализация — в листинге ниже. Здесь всё, что нужно
для практики: инициализация, поиск, минимум/максимум, successor,
вставка, удаление, симметричный обход (проверка сортировки), освобождение.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct BstNode {
    int              key;
    struct BstNode  *left;
    struct BstNode  *right;
    struct BstNode  *parent;
} BstNode;

typedef struct {
    BstNode *root;
    size_t   count;
} Bst;

void bstInit(Bst *tree) {
    tree->root  = NULL;
    tree->count = 0;
}

BstNode* bstSearch(Bst *tree, int key) {
    BstNode *x = tree->root;
    while (x != NULL && key != x->key) {
        x = (key < x->key) ? x->left : x->right;
    }
    return x;
}

BstNode* bstMinimum(BstNode *x) {
    while (x != NULL && x->left != NULL) x = x->left;
    return x;
}

BstNode* bstMaximum(BstNode *x) {
    while (x != NULL && x->right != NULL) x = x->right;
    return x;
}

BstNode* bstSuccessor(BstNode *x) {
    if (x->right != NULL) return bstMinimum(x->right);
    BstNode *y = x->parent;
    while (y != NULL && x == y->right) {
        x = y;
        y = y->parent;
    }
    return y;
}

BstNode* bstInsert(Bst *tree, int key) {
    BstNode *z = malloc(sizeof(BstNode));
    if (z == NULL) return NULL;
    z->key    = key;
    z->left   = NULL;
    z->right  = NULL;
    z->parent = NULL;

    BstNode *y = NULL;
    BstNode *x = tree->root;

    while (x != NULL) {
        y = x;
        x = (key < x->key) ? x->left : x->right;
    }
    z->parent = y;

    if (y == NULL) tree->root = z;
    else if (key < y->key) y->left = z;
    else y->right = z;
    tree->count++;
    return z;
}

static void bstTransplant(Bst *tree, BstNode *u, BstNode *v) {
    if (u->parent == NULL) tree->root = v;
    else if (u == u->parent->left) u->parent->left = v;
    else u->parent->right = v;
    if (v != NULL) v->parent = u->parent;
}

void bstDelete(Bst *tree, BstNode *z) {
    if (z->left == NULL) {
        bstTransplant(tree, z, z->right);
    } else if (z->right == NULL) {
        bstTransplant(tree, z, z->left);
    } else {
        BstNode *y = bstMinimum(z->right);
        if (y->parent != z) {
            bstTransplant(tree, y, y->right);
            y->right = z->right;
            y->right->parent = y;
        }
        bstTransplant(tree, z, y);
        y->left = z->left;
        y->left->parent = y;
    }
    free(z);
    tree->count--;
}

void bstInorder(BstNode *x) {
    if (x == NULL) return;
    bstInorder(x->left);
    printf("%d ", x->key);
    bstInorder(x->right);
}

void bstFree(BstNode *x) {
    if (x == NULL) return;
    bstFree(x->left);
    bstFree(x->right);
    free(x);
}

int main(void) {
    Bst tree;
    bstInit(&tree);
    int keys[] = { 15, 6, 18, 3, 7, 17, 20, 2, 4, 13, 9 };
    size_t n = sizeof(keys) / sizeof(keys[0]);
    for (size_t i = 0; i < n; i++) bstInsert(&tree, keys[i]);

    printf("Симметричный обход: ");
    bstInorder(tree.root);
    printf("\n");

    bstDelete(&tree, tree.root);
    printf("После удаления корня: ");
    bstInorder(tree.root);
    printf("\n");

    bstFree(tree.root);
    return 0;
}
```

### Что важно в реализации

- **Указатель `parent`** — нужен для `successor` и `delete`. Без него
  пришлось бы каждый раз искать родителя перебором, и `O(h)` превратилось
  бы в `O(n)`.
- **Итеративный поиск** — не тратит стек, работает быстрее рекурсивного.
- **`bstTransplant`** — общая логика для трёх случаев удаления.
- **`bstFree`** — обратный обход (сначала дети, потом узел), потому что
  нельзя освободить родителя раньше детей.

---

## Итог

- **BST** — дерево с инвариантом: левое поддерево ≤ узел ≤ правое поддерево.
- Все операции — `O(h)`, где `h` — высота. Сбалансированное → `O(log n)`,
  вырожденное → `O(n)`.
- **Поиск** — спуск от корня, на каждом шаге отбрасываем половину.
- **Минимум** — самый левый, **максимум** — самый правый.
- **Successor** — либо минимум правого поддерева, либо первый родитель,
  у которого узел — левый ребёнок.
- **Вставка** — поиск места + привязка к родителю.
- **Удаление** — три случая; самый хитрый — узел с двумя детьми
  (замена на successor).
- В C храните `parent` и аккуратно освобождайте память обратным обходом.
