# АТД «Вектор»

**Вектор** — это абстрактный тип данных, который представляет линейную последовательность элементов и даёт доступ к ним по индексу, а также позволяет вставлять и удалять элементы в нужной позиции.

В отличие от «сырого» массива фиксированного размера, вектор описывает поведение последовательности и часто опирается на динамический массив, который сам расширяется при нехватке места.

## Что такое вектор и разряд элемента

Представим последовательность из `n` элементов. Позицию элемента в таком списке называют **разрядом** (rank) — это число элементов, стоящих перед ним:
- у первого элемента разряд `0`;
- у последнего — `n - 1`.

Важно разделять **разряд** (логическая позиция в последовательности) и **индекс в массиве** (физическая ячейка памяти). В простой реализации на массиве элемент с разрядом `r` лежит по индексу `r`, но сам АТД этого жёстко не требует.

При вставке или удалении разряды элементов после точки изменения сдвигаются: если вставить элемент в начало, разряд всех остальных вырастет на `1`.

## Основные операции АТД «Вектор»

Базовый набор операций вектора:

- `elemAtRank(r)` — вернуть элемент с разрядом `r` (ошибка, если `r < 0` или `r >= n`).
- `replaceAtRank(r, e)` — заменить элемент с разрядом `r` на `e` и вернуть старый элемент.
- `insertAtRank(r, e)` — вставить `e` на разряд `r`, сдвинув элементы начиная с `r` вправо (ошибка, если `r < 0` или `r > n`).
- `removeAtRank(r)` — удалить элемент с разрядом `r`, сдвинув элементы правее влево, и вернуть удалённый элемент.
- `size()` и `isEmpty()` — текущий размер и проверка на пустоту.

## Реализация на массиве и расширяемый массив

Если хранить элементы в обычном массиве `A` ёмкости `N`:
- чтение и замена по разряду работают за `O(1)`;
- вставка и удаление в произвольный разряд требуют сдвига элементов — в худшем случае (при `r = 0`) это `O(n)`. Вставка и удаление **в конец** (`r = n` или `r = n - 1`) работают за `O(1)`.

### Проблема фиксированного размера и удвоение ёмкости
Обычный массив имеет жёсткий предел `N`: мало выделили — переполнение, много — лишняя память.

Чтобы этого избежать, используют **расширяемый массив**: когда `n == N`, выделяют новый массив размером `2N`, копируют туда элементы и переключаются на него.
- Увеличивать размер на `+1` каждый раз невыгодно: серия из `n` вставок даст `O(n²)`.
- При **удвоении** ёмкости отдельные перекопирования случаются редко, поэтому добавление в конец работает за **амортизированное `O(1)`**.

## Примеры на разных языках

### C: ручная реализация

В C динамический вектор собирают из структуры с указателем на буфер, текущим размером и ёмкостью.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int *data;          // указатель на динамический массив элементов
    size_t size;        // текущее количество элементов в векторе
    size_t capacity;    // сколько элементов помещается без перевыделения памяти
} Vector;

// Создание пустого вектора
Vector* vectorCreate(void) {
    Vector *vector = malloc(sizeof(Vector));
    if (!vector) {
        return NULL;
    }
    vector->data = NULL;
    vector->size = 0;
    vector->capacity = 0;
    return vector;
}

// Добавление элемента в конец (push_back)
void vectorPushBack(Vector *vector, int value) {
    // Если буфер заполнен — увеличиваем ёмкость вдвое
    if (vector->size >= vector->capacity) {
        size_t new_capacity = (vector->capacity == 0) ? 1 : vector->capacity * 2;
        int *new_data = realloc(vector->data, new_capacity * sizeof(int));
        if (!new_data) {
            fprintf(stderr, "Ошибка: не удалось выделить память\n");
            exit(1);
        }
        vector->data = new_data;
        vector->capacity = new_capacity;
    }
    vector->data[vector->size++] = value;
}

// Получение элемента по разряду (индексу)
int vectorElemAtRank(const Vector *vector, size_t rank) {
    if (rank >= vector->size) {
        fprintf(stderr, "Ошибка: разряд %zu вне диапазона\n", rank);
        exit(1);
    }
    return vector->data[rank];
}

// Вставка элемента на позицию rank со сдвигом остальных вправо
void vectorInsertAtRank(Vector *vector, size_t rank, int value) {
    if (rank > vector->size) {
        fprintf(stderr, "Ошибка: разряд %zu вне диапазона\n", rank);
        exit(1);
    }
    // Расширяем вектор на 1 элемент в конце, чтобы гарантировать место
    vectorPushBack(vector, 0);

    // Сдвигаем элементы вправо, двигаясь с конца к позиции rank
    for (size_t i = vector->size - 1; i > rank; i--) {
        vector->data[i] = vector->data[i - 1];
    }
    vector->data[rank] = value;
}

// Удаление элемента на позиции rank со сдвигом остальных влево
int vectorRemoveAtRank(Vector *vector, size_t rank) {
    if (rank >= vector->size) {
        fprintf(stderr, "Ошибка: разряд %zu вне диапазона\n", rank);
        exit(1);
    }
    int removed = vector->data[rank];

    // Сдвигаем элементы влево, закрывая образовавшуюся «дыру»
    for (size_t i = rank; i < vector->size - 1; i++) {
        vector->data[i] = vector->data[i + 1];
    }
    vector->size--;
    return removed;
}

// Полное освобождение памяти вектора
void vectorFree(Vector *vector) {
    if (!vector) {
        return;
    }
    free(vector->data);
    free(vector);
}

int main(void) {
    Vector *vector = vectorCreate();

    vectorPushBack(vector, 10);
    vectorPushBack(vector, 20);
    vectorPushBack(vector, 30);

    vectorInsertAtRank(vector, 1, 15);   // [10, 15, 20, 30]

    printf("Элемент с разрядом 2: %d\n", vectorElemAtRank(vector, 2)); // 20

    int removed = vectorRemoveAtRank(vector, 0);
    printf("Удалён: %d\n", removed);     // 10

    for (size_t i = 0; i < vector->size; i++) {
        printf("%d ", vector->data[i]);  // 15 20 30
    }
    printf("\n");

    vectorFree(vector);
    return 0;
}
```

> **Важно в C:** проверяйте результат `realloc` (при ошибке он возвращает `NULL`, но старый указатель `vector->data` при этом остаётся валидным) и всегда освобождайте память через `vectorFree`.

### Сложность операций

| Операция | Сложность | Примечание |
| :--- | :--- | :--- |
| `elemAtRank(r)` (доступ по индексу) | `O(1)` | Адрес вычисляется арифметически: `base + r * size` |
| `replaceAtRank(r, e)` (замена) | `O(1)` | Прямая запись в ячейку памяти |
| `insertAtRank(r, e)` (вставка) | `O(n)` | Требует сдвига всех элементов правее `r` |
| `insertLast(e)` (вставка в конец) | `O(1)` аморт. | В среднем константа, редкие перевыделения памяти сглаживаются |
| `removeAtRank(r)` (удаление) | `O(n)` | Требует сдвига всех элементов правее `r` |
| `removeLast()` (удаление с конца) | `O(1)` | Достаточно уменьшить счётчик размера |
| Поиск по значению | `O(n)` | Линейный проход по массиву |

## Стандартные реализации в других языках

- **C++:** `std::vector` — динамический массив с автоматическим расширением (`push_back` за амортизированное `O(1)`, вставка и удаление через итераторы `insert`/`erase` за `O(n)`).
- **Python:** встроенный `list` — динамический массив ссылок на объекты (`append` за амортизированное `O(1)`, `insert` и `pop(i)` в произвольной позиции за `O(n)`).
- **Java:** `ArrayList` — расширяемый массив объектов (`add` в конец за амортизированное `O(1)`, доступ через `get` за `O(1)`, вставка и удаление по индексу за `O(n)`).
- **C#:** `List<T>` — обобщённый динамический массив (`Add` за амортизированное `O(1)`, доступ по индексу `[]` за `O(1)`, `Insert` и `RemoveAt` за `O(n)`).

| Язык | Тип | Добавление в конец | Вставка в середину | Доступ по индексу |
| :--- | :--- | :--- | :--- | :--- |
| **C** | Ручная структура | `O(1)` аморт. | `O(n)` | `O(1)` |
| **C++** | `std::vector` | `O(1)` аморт. | `O(n)` | `O(1)` |
| **Python** | `list` | `O(1)` аморт. | `O(n)` | `O(1)` |
| **Java** | `ArrayList` | `O(1)` аморт. | `O(n)` | `O(1)` |
| **C#** | `List<T>` | `O(1)` аморт. | `O(n)` | `O(1)` |

## Итог

- **Вектор** даёт быстрый доступ по позиции (`O(1)`) и поддерживает вставку/удаление элементов.
- **Разряд** — логическая позиция элемента от `0` до `n - 1`.
- Вставка и удаление в середину сдвигают элементы — это `O(n)`, а добавление в конец в расширяемом массиве работает за амортизированное `O(1)`.
- Удвоение ёмкости при переполнении позволяет избежать квадратичных затрат на серии вставок.
- В стандартных библиотеках это `std::vector` (C++), `list` (Python), `ArrayList` (Java), `List<T>` (C#).
