# АТД «Вектор»

Абстрактный тип данных «вектор» расширяет конкретную структуру данных **массива**. Он предоставляет не только доступ к элементам последовательности, но и методы **обновления**, позволяющие удалять и добавлять элементы с определённым индексом.

## Что такое вектор

Пусть `S` — линейная последовательность из `n` элементов. Каждый элемент `e` последовательности `S` имеет **уникальный индекс** — целое число в интервале `[0, n-1]`, равное числу элементов, предшествующих `e`.

Линейная последовательность элементов, в которой доступ к элементам осуществляется по их индексу, называется **вектором**.

Вектор — это **абстрактный тип данных**, который поддерживает доступ к элементам по индексу и операции вставки/удаления. Важно понимать: АТД «вектор» **не определяет**, как именно хранятся данные. Это может быть массив, связный список или что-то ещё. АТД задаёт только **поведение** — какие операции доступны и что они делают.

## Разряд элемента

Для отличия от процесса доступа к элементам конкретной структуры данных (массива) при обозначении индекса элемента вектора используется термин **«разряд»**.

**Разряд элемента `e`** последовательности `S` равен количеству элементов, находящихся в `S` перед `e`. То есть разряд первого элемента равен `0`, а последнего — `n-1`. Этот принцип соответствует индексированию массивов в Java, C, C++ и большинстве других языков.

Важно: в определении **не требуется**, чтобы реализованная последовательность хранила элемент с разрядом `0` в ячейке с индексом `0`. Это лишь один из возможных вариантов. Понятие разряда позволяет обращаться к «индексу» элемента последовательности **без учёта конкретной реализации**.

Разряд элемента может **изменяться** при обновлении последовательности. Например, при добавлении нового элемента в начале последовательности разряд каждого существующего элемента увеличится на `1`.

Разряд — простое и удобное средство: с его помощью определяется место добавления нового элемента или удаления существующего. Можно указать, какой разряд получит новый элемент после добавления (например, `insert at rank 2`), или какой элемент должен быть удалён (например, `remove the element at rank 2`).

## Основные методы АТД «вектор»

Вектор `S` поддерживает следующие основные методы:

**`elemAtRank(r)`** возвращает элемент `S` с разрядом `r`. Если `r < 0` или `r > n-1`, где `n` — текущее число элементов, выдаётся сообщение об ошибке. Вход: целое число. Выход: объект.

**`replaceAtRank(r, e)`** замещает объектом `e` элемент с разрядом `r` и возвращает замещаемый объект. Если `r < 0` или `r > n-1`, выдаётся сообщение об ошибке. Вход: целое число `r` и объект `e`. Выход: объект.

**`insertAtRank(r, e)`** добавляет в `S` новый элемент `e`. Если `r < 0` или `r > n`, выдаётся сообщение об ошибке. Вход: целое число `r` и объект `e`. Выход: нет.

**`removeAtRank(r)`** удаляет из `S` элемент с разрядом `r`. Если `r < 0` или `r > n-1`, выдаётся сообщение об ошибке. Вход: целое число. Выход: объект.

Кроме того, АТД «вектор» обычно поддерживает стандартные методы **`size()`** и **`isEmpty()`**.

## Реализация на основе массива

Самый очевидный способ реализации векторного АТД — на основе **массива** `A`, где `A[i]` содержит ссылку на элемент разряда `i`. Считаем длину `N` массива `A` достаточно большой, а для обозначения количества элементов вектора используем переменную `n < N`.

Реализация методов векторного АТД достаточно проста. При выполнении операции `elemAtRank(r)` программа возвращает `A[r]`. Реализация методов `insertAtRank(r, e)` и `removeAtRank(r)` чуть сложнее.

Одна из операций, занимающая значительную часть времени, — **перемещение элементов** таким образом, чтобы занятые ячейки массива образовывали неразрывную последовательность. Такое перемещение необходимо для соблюдения правила о хранении элемента с разрядом `i` в `A` с индексом `i`.

Алгоритм `insertAtRank(r, e)`:

```text
1  for i = n - 1, n - 2, ..., r do
2      A[i + 1] ← A[i]     // создаёт место для нового элемента
3  A[r] ← e
4  n ← n + 1
```

Алгоритм `removeAtRank(r)`:

```text
1  e ← A[r]                // e — временная переменная
2  for i = r, r + 1, ..., n - 2 do
3      A[i] ← A[i + 1]     // замещает удалённый элемент
4  n ← n - 1
5  return e
```

### Время выполнения

Методы `isEmpty`, `size` и `elemAtRank` выполняются за время **`O(1)`**. Однако для вставки и удаления может потребоваться гораздо больше времени.

В худшем случае `insertAtRank(r, e)` выполняется за время **`Θ(n)`**. Худшие условия — когда `r = 0`: все существующие `n` элементов должны быть перемещены вперёд. То же самое можно сказать и о `removeAtRank(r)`: в худшем случае `r = 0`, и необходимо переместить `n - 1` элементов.

Если предположить, что каждый разряд **равновероятно** может быть аргументом этих операций, среднее время выполнения — **`Θ(n)`**, так как в среднем необходимо переместить `n/2` элементов.

При более детальном рассмотрении видно, что время выполнения каждой из этих операций равно **`O(n - r + 1)`**: перемещаются только элементы с разрядом `r` и выше. Таким образом, для добавления или удаления элемента **в конце** вектора (`insertAtRank(n, e)` и `removeAtRank(n-1)`) необходимо время **`O(1)`**.

### Недостаток

Основной недостаток реализации на основе простого массива — необходимость **предварительного указания размера** `N`, то есть максимального числа элементов вектора. Если действительное число элементов значительно меньше `N`, бесполезно занимается память. Хуже того, если `n` окажется больше `N`, реализация приведёт к **сбою программы**.

## Расширяемый массив

Проблему с фиксированным размером решает **стратегия замещения массивов** (extendable array). Предположим, у нас есть средства увеличить размер массива `A`.

При возникновении переполнения (то есть при `n = N`) и вызове метода `insertAtRank` выполняются следующие операции:

1. Создаётся новый массив `B` длиной `2N`.
2. Копируется `A[i]` в `B[i]`, где `i = 0, ..., N-1`.
3. Присваивается `A = B` — массив `B` используется как новый массив, содержащий `S`.

**Почему удвоение, а не +1?** Если увеличивать размер на 1 при каждом добавлении, каждое добавление в худшем случае будет `O(n)`. Амортизированное (усреднённое) время при удвоении — **`O(1)`**. Это классический приём, который используется во всех стандартных реализациях динамических массивов.

## Примеры на разных языках

### C: ручная реализация

В C нет встроенного вектора — его реализуют вручную через `struct` и функции. Основная идея: хранить указатель на массив, текущий размер и ёмкость.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int *data;          // указатель на массив
    size_t size;        // текущее число элементов
    size_t capacity;    // текущая ёмкость
} Vector;

// Создание вектора
Vector* vectorCreate(void) {
    Vector *vector = malloc(sizeof(Vector));
    if (!vector)
        return NULL;
    vector->data = NULL;
    vector->size = 0;
    vector->capacity = 0;
    return vector;
}

// Добавление элемента в конец (push_back)
void vectorPushBack(Vector *vector, int value) {
    if (vector->size >= vector->capacity) {
        size_t new_capacity = (vector->capacity == 0) ? 1 : vector->capacity * 2;
        int *new_data = realloc(vector->data, new_capacity * sizeof(int));
        if (!new_data)
            return;   // ошибка выделения памяти
        vector->data = new_data;
        vector->capacity = new_capacity;
    }
    vector->data[vector->size++] = value;
}

// Доступ по разряду
int vectorElemAtRank(const Vector *vector, size_t rank) {
    if (rank >= vector->size) {
        fprintf(stderr, "Ошибка: разряд %zu вне диапазона\n", rank);
        exit(1);
    }
    return vector->data[rank];
}

// Вставка по разряду (insertAtRank)
void vectorInsertAtRank(Vector *vector, size_t rank, int value) {
    if (rank > vector->size) {
        fprintf(stderr, "Ошибка: разряд %zu вне диапазона\n", rank);
        return;
    }
    // Сдвигаем элементы вправо, начиная с конца
    vectorPushBack(vector, 0);   // временно увеличиваем размер
    for (size_t i = vector->size - 1; i > rank; i--) {
        vector->data[i] = vector->data[i - 1];
    }
    vector->data[rank] = value;
}

// Удаление по разряду (removeAtRank)
int vectorRemoveAtRank(Vector *vector, size_t rank) {
    if (rank >= vector->size) {
        fprintf(stderr, "Ошибка: разряд %zu вне диапазона\n", rank);
        exit(1);
    }
    int removed = vector->data[rank];
    for (size_t i = rank; i < vector->size - 1; i++) {
        vector->data[i] = vector->data[i + 1];
    }
    vector->size--;
    return removed;
}

// Освобождение памяти
void vectorFree(Vector *vector) {
    free(vector->data);
    free(vector);
}

int main(void) {
    Vector *vector = vectorCreate();

    vectorPushBack(vector, 10);
    vectorPushBack(vector, 20);
    vectorPushBack(vector, 30);

    vectorInsertAtRank(vector, 1, 15);   // [10, 15, 20, 30]

    printf("Элемент с разрядом 2: %d\n", vectorElemAtRank(v, 2));  // 20

    int removed = vectorRemoveAtRank(vector, 0);
    printf("Удалён: %d\n", removed);   // 10

    for (size_t i = 0; i < vector->size; i++) {
        printf("%d ", vector->data[i]);      // 15 20 30
    }
    printf("\n");

    vectorFree(vector);
    return 0;
}
```

> **Важно:** в C приходится вручную управлять памятью. `realloc` может вернуть `NULL` — это нужно проверять. И не забывайте `free` — иначе утечка.

### C++: `std::vector`

В C++ вектор — часть стандартной библиотеки (**STL**). Это динамический массив с автоматическим управлением памятью.

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {10, 20, 30};

    // Добавление в конец
    v.push_back(40);   // [10, 20, 30, 40]

    // Вставка по разряду
    v.insert(v.begin() + 1, 15);   // [10, 15, 20, 30, 40]

    // Доступ по разряду
    std::cout << "Элемент с разрядом 2: " << v[2] << "\n";   // 20

    // Безопасный доступ с проверкой границ
    try {
        std::cout << v.at(10) << "\n";   // исключение out_of_range
    } catch (const std::out_of_range& e) {
        std::cout << "Ошибка: " << e.what() << "\n";
    }

    // Удаление по разряду
    v.erase(v.begin());   // удаляет первый элемент -> [15, 20, 30, 40]

    // Размер и ёмкость
    std::cout << "Размер: " << v.size() << ", Ёмкость: " << v.capacity() << "\n";

    // Резервирование памяти
    v.reserve(100);

    // Перебор
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << "\n";

    return 0;
}
```

`std::vector` реализует именно ту стратегию, которую мы описали: при переполнении ёмкость **удваивается**. Метод `capacity()` показывает текущую ёмкость, `size()` — число элементов. `reserve(n)` заранее выделяет память, чтобы избежать многократных перевыделений.

### Python: `list`

В Python встроенный `list` — это и есть динамический массив. Отдельного типа `vector` нет, но `list` выполняет ту же роль.

```python
# Создание вектора
v = [10, 20, 30]

# Добавление в конец
v.append(40)            # [10, 20, 30, 40]

# Вставка по разряду
v.insert(1, 15)         # [10, 15, 20, 30, 40]

# Доступ по разряду
print(v[2])             # 20

# Удаление по разряду
removed = v.pop(0)      # удаляет элемент с индексом 0
print(removed)          # 10

# Размер
print(len(v))           # 4

# Перебор
for x in v:
    print(x)
```

Python `list` реализован на C и использует ту же стратегию удвоения ёмкости. Операции `append` и `pop` (с конца) амортизированно `O(1)`, вставка и удаление в середине — `O(n)`.

### Java: `ArrayList`

В Java есть два класса, реализующих динамический массив: `ArrayList` и `Vector`. **`Vector` устарел** — он синхронизирован (потокобезопасен), но из-за этого медленнее. В современном коде используют `ArrayList`.

```java
import java.util.ArrayList;

public class VectorExample {
    public static void main(String[] args) {
        // Создание вектора
        ArrayList<Integer> v = new ArrayList<>();
        v.add(10);
        v.add(20);
        v.add(30);

        // Вставка по разряду
        v.add(1, 15);   // [10, 15, 20, 30]

        // Доступ по разряду
        System.out.println("Элемент с разрядом 2: " + v.get(2));   // 20

        // Удаление по разряду
        int removed = v.remove(0);
        System.out.println("Удалён: " + removed);   // 10

        // Размер
        System.out.println("Размер: " + v.size());

        // Перебор
        for (int x : v) {
            System.out.println(x);
        }
    }
}
```

`ArrayList` внутри — это массив `Object[]`, который автоматически расширяется. При добавлении элемента, когда массив заполнен, создаётся новый массив в **1.5 раза** больше (у `Vector` — в 2 раза). Это тоже амортизированно `O(1)` для `add`.

### C#: `List<T>`

В C# аналог вектора — обобщённый класс `List<T>`.

```csharp
using System;
using System.Collections.Generic;

class Program {
    static void Main() {
        // Создание вектора
        List<int> v = new List<int> { 10, 20, 30 };

        // Добавление в конец
        v.Add(40);   // [10, 20, 30, 40]

        // Вставка по разряду
        v.Insert(1, 15);   // [10, 15, 20, 30, 40]

        // Доступ по разряду
        Console.WriteLine("Элемент с разрядом 2: " + v[2]);   // 20

        // Удаление по разряду
        v.RemoveAt(0);   // удаляет первый элемент

        // Размер
        Console.WriteLine("Размер: " + v.Count);

        // Перебор
        foreach (int x in v) {
            Console.WriteLine(x);
        }
    }
}
```

`List<T>` внутри использует массив и удваивает его при переполнении. Свойство `Capacity` показывает текущую ёмкость, `Count` — число элементов. `List<T>` — это дженерик, поэтому работает с любым типом без упаковки.

Во всех языках вставка и удаление **в середину** требуют сдвига элементов — это `O(n)`. Именно это ограничение и определяет, когда вектор подходит, а когда нет.

## Итог

- **Вектор** — АТД, расширяющий массив операциями вставки и удаления по разряду.
- **Разряд** — позиция элемента в последовательности, аналог индекса, но без привязки к реализации.
- Основные методы: `elemAtRank`, `replaceAtRank`, `insertAtRank`, `removeAtRank`, `size`, `isEmpty`.
- Реализация на массиве даёт `O(1)` для доступа, но `O(n)` для вставки/удаления в середину.
- **Расширяемый массив** решает проблему фиксированного размера: при переполнении ёмкость удваивается, амортизированно `O(1)`.
- В C вектор реализуется вручную; в C++ — `std::vector`; в Python — `list`; в Java — `ArrayList`; в C# — `List<T>`.
- Вставка и удаление **в середину** — всегда `O(n)`, потому что нужно сдвигать элементы.
