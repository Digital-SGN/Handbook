# АТД «Дек»

**Дек** (deque — double-ended queue) — это структура данных, напоминающая очередь, но с более широкими возможностями: добавление и удаление элементов можно выполнять **как в начало, так и в конец**. По-русски его часто называют **двунаправленной очередью**.

## Что такое дек

Абстрактный тип данных «дек» обладает большими возможностями, чем стек или очередь. По сути, он объединяет их: с его помощью можно эмулировать и стек, и очередь, но при этом работать с обоими концами последовательности напрямую. Именно поэтому дек часто используется как универсальная структура для реализации других АТД.

## Методы АТД «Дек»

Пусть `D` обозначает дек. Он поддерживает четыре основных метода.

**`insertFirst(e)`** помещает новый элемент `e` в начало `D`. Вход: объект. Выход: нет.

**`insertLast(e)`** помещает новый элемент `e` в конец `D`. Вход: объект. Выход: нет.

**`removeFirst()`** удаляет и возвращает первый элемент `D`; если `D` пуст, выдаётся ошибка. Вход: нет. Выход: объект.

**`removeLast()`** удаляет и возвращает последний элемент `D`; если `D` пуст, выдаётся ошибка. Вход: нет. Выход: объект.

Кроме того, дек поддерживает дополнительные методы:

**`first()`** возвращает первый элемент `D`, не удаляя его; если `D` пуст — ошибка. Вход: нет. Выход: объект.

**`last()`** возвращает последний элемент `D`, не удаляя его; если `D` пуст — ошибка. Вход: нет. Выход: объект.

**`size()`** возвращает число элементов `D`. Вход: нет. Выход: целое число.

**`isEmpty()`** возвращает логическое значение: пуст ли `D`. Вход: нет. Выход: логическое значение.

## Реализация на C через двусвязный список

Дек предусматривает возможность добавления и удаления объектов **на обоих концах**. Реализация на основе односвязного списка не может быть эффективной: чтобы удалить последний элемент, пришлось бы проходить весь список — `O(n)`. Поэтому для дека используют **двусвязный список**, где каждый узел содержит две ссылки: `next` — на следующий узел и `prev` — на предыдущий.

Для упрощения программирования на обоих концах списка добавляют **сигнальные узлы**: узел `header` перед первым узлом списка и узел `trailer` после последнего. Эти «холостые» узлы не содержат элементов. Узел `header` содержит действительную ссылку `next` и нулевую `prev`, а узел `trailer` — действительную `prev` и нулевую `next`. В пустом списке сигнальные узлы ссылаются друг на друга.

Благодаря ссылке `prev` отпадает необходимость просматривать весь список, чтобы добраться до предпоследнего узла. Добавление и удаление элементов на обоих концах выполняются за `O(1)`.

### Интерфейс

```c
#ifndef DEQUE_H
#define DEQUE_H

#include <stdbool.h>
#include <stddef.h>

typedef struct Node {
    int value;
    struct Node *prev;
    struct Node *next;
} Node;

typedef struct {
    Node *header;   // сигнальный узел перед первым
    Node *trailer;  // сигнальный узел после последнего
    size_t count;
} Deque;

Deque dequeInit(void);
bool dequeIsEmpty(const Deque *d);
size_t dequeSize(const Deque *d);
void dequeInsertFirst(Deque *d, int value);
void dequeInsertLast(Deque *d, int value);
int dequeRemoveFirst(Deque *d);
int dequeRemoveLast(Deque *d);
int dequeFirst(const Deque *d);
int dequeLast(const Deque *d);
void dequeFree(Deque *d);

#endif
```

### Реализация

```c
#include "deque.h"
#include <stdio.h>
#include <stdlib.h>

// Вспомогательная функция: вставка нового узла после узла p
static Node* dequeInsertAfter(Deque *d, Node *p, int value) {
    Node *newNode = malloc(sizeof(Node));
    if (newNode == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }

    newNode->value = value;
    newNode->prev = p;
    newNode->next = p->next;

    p->next->prev = newNode;
    p->next = newNode;

    d->count++;
    return newNode;
}

// Вспомогательная функция: удаление узла
static int dequeRemoveNode(Deque *d, Node *node) {
    int value = node->value;

    node->prev->next = node->next;
    node->next->prev = node->prev;

    free(node);
    d->count--;

    return value;
}

Deque dequeInit(void) {
    Deque d;

    d.header = malloc(sizeof(Node));
    d.trailer = malloc(sizeof(Node));
    if (d.header == NULL || d.trailer == NULL) {
        free(d.header);
        free(d.trailer);
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }

    d.header->next = d.trailer;
    d.header->prev = NULL;
    d.trailer->prev = d.header;
    d.trailer->next = NULL;
    d.count = 0;

    return d;
}

bool dequeIsEmpty(const Deque *d) {
    return d->count == 0;
}

size_t dequeSize(const Deque *d) {
    return d->count;
}

void dequeInsertFirst(Deque *d, int value) {
    dequeInsertAfter(d, d->header, value);
}

void dequeInsertLast(Deque *d, int value) {
    dequeInsertAfter(d, d->trailer->prev, value);
}

int dequeRemoveFirst(Deque *d) {
    if (dequeIsEmpty(d)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return dequeRemoveNode(d, d->header->next);
}

int dequeRemoveLast(Deque *d) {
    if (dequeIsEmpty(d)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return dequeRemoveNode(d, d->trailer->prev);
}

int dequeFirst(const Deque *d) {
    if (dequeIsEmpty(d)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return d->header->next->value;
}

int dequeLast(const Deque *d) {
    if (dequeIsEmpty(d)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return d->trailer->prev->value;
}

void dequeFree(Deque *d) {
    Node *current = d->header->next;
    while (current != d->trailer) {
        Node *next = current->next;
        free(current);
        current = next;
    }
    free(d->header);
    free(d->trailer);
    d->header = NULL;
    d->trailer = NULL;
    d->count = 0;
}
```

### Пример использования

```c
#include "deque.h"
#include <stdio.h>

int main(void) {
    Deque d = dequeInit();

    // Добавляем с обоих концов
    dequeInsertFirst(&d, 20);
    dequeInsertFirst(&d, 10);
    dequeInsertLast(&d, 30);
    dequeInsertLast(&d, 40);
    // дек: 10 <-> 20 <-> 30 <-> 40

    printf("Первый: %d\n", dequeFirst(&d)); // 10
    printf("Последний: %d\n", dequeLast(&d)); // 40
    printf("Размер: %zu\n", dequeSize(&d)); // 4

    // Удаляем с обоих концов
    printf("RemoveFirst: %d\n", dequeRemoveFirst(&d)); // 10
    printf("RemoveLast:  %d\n", dequeRemoveLast(&d)); // 40

    printf("Размер: %zu\n", dequeSize(&d)); // 2
    printf("Первый: %d\n", dequeFirst(&d)); // 20
    printf("Последний: %d\n", dequeLast(&d)); // 30

    dequeFree(&d);
    return 0;
}
```

### Как дек эмулирует стек и очередь

Дек — универсальная структура. Из него легко получить и стек, и очередь.

**Стек (LIFO):** используем только один конец.

```c
// push — в конец, pop — с конца
dequeInsertLast(&d, value);
int x = dequeRemoveLast(&d);
```

**Очередь (FIFO):** добавление в конец, удаление с начала.

```c
// enqueue — в конец, dequeue — с начала
dequeInsertLast(&d, value);
int x = dequeRemoveFirst(&d);
```

### Сложность

| Операция | Сложность |
| :--- | :--- |
| `insertFirst` | `O(1)` |
| `insertLast` | `O(1)` |
| `removeFirst` | `O(1)` |
| `removeLast` | `O(1)` |
| `first`, `last` | `O(1)` |
| `size`, `isEmpty` | `O(1)` |

Все операции за константное время. Память — `O(n)` по числу элементов.

## Стандартные реализации в других языках

### C++: `std::deque`

```cpp
#include <iostream>
#include <deque>

int main() {
    std::deque<int> d;

    d.push_back(30);
    d.push_front(20);
    d.push_front(10);
    d.push_back(40);
    // дек: 10, 20, 30, 40

    std::cout << "Первый: " << d.front() << "\n";   // 10
    std::cout << "Последний: " << d.back() << "\n"; // 40
    std::cout << "Размер: " << d.size() << "\n";    // 4

    d.pop_front();    // удаляет 10
    d.pop_back();     // удаляет 40

    for (int x : d) {
        std::cout << x << " ";
    }
    std::cout << "\n";

    return 0;
}
```

`std::deque` — не связный список, а **массив блоков фиксированного размера** с индексацией. Это даёт `O(1)` на оба конца и `O(1)` на доступ по индексу — быстрее, чем `std::list`. На практике именно `std::deque` — контейнер по умолчанию для `std::stack` и `std::queue`.

### Python: `collections.deque`

```python
from collections import deque

d = deque()

d.append(30)          # в конец
d.appendleft(20)      # в начало
d.appendleft(10)
d.append(40)
# дек: 10, 20, 30, 40

print(d[0])           # 10 — первый
print(d[-1])          # 40 — последний
print(len(d))         # 4

d.popleft()           # удаляет 10
d.pop()               # удаляет 40

# Обход
for x in d:
    print(x)

# Ограниченный дек — автоматически вытесняет старые элементы
bounded = deque(maxlen=3)
bounded.append(1)
bounded.append(2)
bounded.append(3)
bounded.append(4)     # вытеснит 1
print(bounded)        # deque([2, 3, 4], maxlen=3)
```

`deque` в Python — двусвязный список блоков. Даёт `O(1)` на операции с обоими концами. Умеет работать как **ограниченный дек** через `maxlen` — удобно для скользящего окна.

### Java: `ArrayDeque`

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class DequeExample {
    public static void main(String[] args) {
        Deque<Integer> d = new ArrayDeque<>();

        d.addLast(30);
        d.addFirst(20);
        d.addFirst(10);
        d.addLast(40);
        // дек: 10, 20, 30, 40

        System.out.println(d.peekFirst());   // 10
        System.out.println(d.peekLast());    // 40
        System.out.println(d.size());        // 4

        d.pollFirst();                        // удаляет 10
        d.pollLast();                         // удаляет 40

        for (int x : d) {
            System.out.println(x);
        }
    }
}
```

`ArrayDeque` реализован на **циклическом массиве** — как очередь из предыдущей главы, но с доступом с обоих концов. `addFirst`/`addLast`/`pollFirst`/`pollLast` работают за `O(1)`. Java рекомендует `ArrayDeque` вместо устаревшего `Stack` и медленного `LinkedList`.

### C#: `LinkedList<T>`

В C# нет отдельного класса `Deque`, но его роль выполняет `LinkedList<T>`: методы `AddFirst`, `AddLast`, `RemoveFirst`, `RemoveLast` дают `O(1)` на обоих концах.

```csharp
using System;
using System.Collections.Generic;

class Program {
    static void Main() {
        LinkedList<int> d = new LinkedList<int>();

        d.AddLast(30);
        d.AddFirst(20);
        d.AddFirst(10);
        d.AddLast(40);
        // дек: 10, 20, 30, 40

        Console.WriteLine(d.First.Value);   // 10
        Console.WriteLine(d.Last.Value);    // 40
        Console.WriteLine(d.Count);         // 4

        d.RemoveFirst();                     // удаляет 10
        d.RemoveLast();                      // удаляет 40

        foreach (int x in d) {
            Console.WriteLine(x);
        }
    }
}
```

## Итог

- **Дек** — двунаправленная очередь: добавление и удаление с обоих концов.
- Методы: `insertFirst`, `insertLast`, `removeFirst`, `removeLast`, `first`, `last`, `size`, `isEmpty`.
- **Реализация через двусвязный список** с сигнальными узлами `header` и `trailer` даёт `O(1)` на все операции.
- Сигнальные узлы упрощают код: не нужно обрабатывать пустой список отдельно.
- Дек **эмулирует** стек (`insertLast` + `removeLast`) и очередь (`insertLast` + `removeFirst`).
- В C++ — `std::deque`; в Python — `collections.deque`; в Java — `ArrayDeque`; в C# — `LinkedList<T>`.
- Применяется в алгоритмах со скользящим окном, в планировщиках, в задачах BFS с двухсторонним обходом.
