# АТД «Дек»

**Дек** (*double-ended queue*, двунаправленная очередь) разрешает добавлять и удалять элементы **с обоих концов** — и с начала, и с конца.

За счёт этого дек объединяет возможности стека и очереди и часто используется в задачах со скользящим окном, двустороннем поиске и как базовый контейнер в стандартных библиотеках.

## Зачем нужен дек

Обычная очередь закрыта с одного конца, а стек — с другого. Дек открыт с обеих сторон:
- как стек: `insertLast` + `removeLast` (LIFO);
- как очередь: `insertLast` + `removeFirst` (FIFO).

В односвязном списке удалить последний элемент за `O(1)` не получится, потому что не видно предыдущий узел. Поэтому для ручной реализации на связных узлах берут **двусвязный список** (желательно с сигнальными узлами `head` и `tail`).

## Основные операции АТД «Дек»

- `insertFirst(e)`, `insertLast(e)` — добавить элемент `e` в начало или в конец.
- `removeFirst()`, `removeLast()` — удалить и вернуть первый или последний элемент (ошибка, если дек пуст).
- `first()`, `last()` — посмотреть первый или последний элемент без удаления.
- `size()`, `isEmpty()` — размер и проверка на пустоту.

## Реализация на C через двусвязный список

Сигнальные узлы `head` и `tail` стоят на краях списка и не содержат данных. За счёт них вставка и удаление на любом конце сводятся к одинаковым операциям перепривязки указателей за `O(1)`.


```c
#include <stdbool.h>
#include <stddef.h>

typedef struct Node {
    int value;
    struct Node *prev;
    struct Node *next;
} Node;

typedef struct {
    Node *head;     // сигнальный узел перед первым элементом
    Node *tail;    // сигнальный узел после последнего элемента
    size_t count;
} Deque;

// Вспомогательная функция: вставляет новый узел сразу после узла p
static Node* dequeInsertAfter(Deque *deque, Node *p, int value) {
    Node *newNode = malloc(sizeof(Node));
    if (newNode == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }

    newNode->value = value;
    newNode->prev = p;
    newNode->next = p->next;

    p->next->prev = newNode;
    p->next = newNode;

    deque->count++;
    return newNode;
}

// Вспомогательная функция: вырезает узел из списка и возвращает его значение
static int dequeRemoveNode(Deque *deque, Node *node) {
    int value = node->value;
    node->prev->next = node->next;
    node->next->prev = node->prev;

    free(node);
    deque->count--;
    return value;
}

Deque dequeInit(void) {
    Deque deque;

    // Создаём два сигнальных узла по краям
    deque.head = malloc(sizeof(Node));
    deque.tail = malloc(sizeof(Node));
    if (deque.head == NULL || deque.tail == NULL) {
        free(deque.head);
        free(deque.tail);
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }

    // Связываем края в пустом деке
    deque.head->next = deque.tail;
    deque.head->prev = NULL;
    deque.tail->prev = deque.head;
    deque.tail->next = NULL;
    deque.count = 0;

    return deque;
}

bool dequeIsEmpty(const Deque *deque) {
    return deque->count == 0;
}

size_t dequeSize(const Deque *deque) {
    return deque->count;
}

// Вставка в начало — после head
void dequeInsertFirst(Deque *deque, int value) {
    dequeInsertAfter(deque, deque->head, value);
}

// Вставка в конец — перед tail (то есть после tail->prev)
void dequeInsertLast(Deque *deque, int value) {
    dequeInsertAfter(deque, deque->tail->prev, value);
}

// Удаление с начала — узел сразу после head
int dequeRemoveFirst(Deque *deque) {
    if (dequeIsEmpty(deque)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return dequeRemoveNode(deque, deque->head->next);
}

// Удаление с конца — узел сразу перед tail
int dequeRemoveLast(Deque *deque) {
    if (dequeIsEmpty(deque)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return dequeRemoveNode(deque, deque->tail->prev);
}

int dequeFirst(const Deque *deque) {
    if (dequeIsEmpty(deque)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return deque->head->next->value;
}

int dequeLast(const Deque *deque) {
    if (dequeIsEmpty(deque)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return deque->tail->prev->value;
}

void dequeFree(Deque *deque) {
    Node *current = deque->head->next;
    while (current != deque->tail) {
        Node *next = current->next;
        free(current);
        current = next;
    }
    free(deque->head);
    free(deque->tail);
    deque->head = NULL;
    deque->tail = NULL;
    deque->count = 0;
}
```

### Пример использования

```c
#include "deque.h"
#include <stdio.h>

int main(void) {
    Deque deque = dequeInit();

    dequeInsertFirst(&deque, 20);
    dequeInsertFirst(&deque, 10);
    dequeInsertLast(&deque, 30);
    dequeInsertLast(&deque, 40);

    printf("Первый: %d\n", dequeFirst(&deque));
    printf("Последний: %d\n", dequeLast(&deque));
    printf("RemoveFirst: %d\n", dequeRemoveFirst(&deque));
    printf("RemoveLast: %d\n", dequeRemoveLast(&deque));
    printf("Размер: %zu\n", dequeSize(&deque));

    dequeFree(&deque);
    return 0;
}
```

## Стандартные реализации в других языках

- **C++:** `std::deque` — обычно реализован как массив блоков фиксированного размера, даёт `O(1)` на оба конца и быстрый доступ по индексу.
- **Python:** `collections.deque` — двусвязный список блоков; поддерживает `maxlen` для ограниченного скользящего окна.
- **Java:** `ArrayDeque` — циклический массив с `addFirst`/`addLast`/`pollFirst`/`pollLast` за `O(1)`.
- **C#:** отдельного класса `Deque` нет, но `LinkedList<T>` закрывает работу с обоих концов (`AddFirst`, `AddLast`, `RemoveFirst`, `RemoveLast`).

| Язык | Тип | Внутренняя основа |
| :--- | :--- | :--- |
| **C** | Ручная структура | Двусвязный список с сигнальными узлами |
| **C++** | `std::deque` | Блоки памяти фиксированного размера |
| **Python** | `collections.deque` | Двусвязный список блоков |
| **Java** | `ArrayDeque` | Циклический массив |
| **C#** | `LinkedList<T>` | Двусвязный список |

## Итог

- **Дек** позволяет добавлять и удалять элементы с обоих концов за `O(1)`.
- Из дека легко собрать и стек (LIFO), и очередь (FIFO).
- В C для реализации на узлах нужен двусвязный список, а сигнальные узлы упрощают работу с краями.
