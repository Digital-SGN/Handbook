# АТД «Дек»

**Дек** (deque — double-ended queue) — это структура данных, напоминающая очередь, но с более широкими возможностями: добавление и удаление элементов можно выполнять **как в начало, так и в конец**. По-русски его часто называют **двунаправленной очередью**.

## Что такое дек

Абстрактный тип данных «дек» обладает большими возможностями, чем стек или очередь. По сути, он объединяет их: с его помощью можно эмулировать и стек, и очередь, но при этом работать с обоими концами последовательности напрямую. Именно поэтому дек часто используется как универсальная структура для реализации других АТД.

## Методы АТД «Дек»

Пусть `deque` обозначает дек. Он поддерживает четыре основных метода.

**`insertFirst(e)`** помещает новый элемент `e` в начало `deque`. Вход: объект. Выход: нет.

**`insertLast(e)`** помещает новый элемент `e` в конец `deque`. Вход: объект. Выход: нет.

**`removeFirst()`** удаляет и возвращает первый элемент `deque`; если `deque` пуст, выдаётся ошибка. Вход: нет. Выход: объект.

**`removeLast()`** удаляет и возвращает последний элемент `deque`; если `deque` пуст, выдаётся ошибка. Вход: нет. Выход: объект.

Кроме того, дек поддерживает дополнительные методы:

**`first()`** возвращает первый элемент `deque`, не удаляя его; если `deque` пуст — ошибка. Вход: нет. Выход: объект.

**`last()`** возвращает последний элемент `deque`, не удаляя его; если `deque` пуст — ошибка. Вход: нет. Выход: объект.

**`size()`** возвращает число элементов `deque`. Вход: нет. Выход: целое число.

**`isEmpty()`** возвращает логическое значение: пуст ли `deque`. Вход: нет. Выход: логическое значение.

## Реализация на C через двусвязный список

Дек предусматривает возможность добавления и удаления объектов **на обоих концах**. Реализация на основе односвязного списка не может быть эффективной: чтобы удалить последний элемент, пришлось бы проходить весь список — `O(n)`. Поэтому для дека используют **двусвязный список**, где каждый узел содержит две ссылки: `next` — на следующий узел и `prev` — на предыдущий.

Для упрощения программирования на обоих концах списка добавляют **сигнальные узлы**: узел `header` перед первым узлом списка и узел `trailer` после последнего. Эти «холостые» узлы не содержат элементов. Узел `header` содержит действительную ссылку `next` и нулевую `prev`, а узел `trailer` — действительную `prev` и нулевую `next`. В пустом списке сигнальные узлы ссылаются друг на друга.

Благодаря ссылке `prev` отпадает необходимость просматривать весь список, чтобы добраться до предпоследнего узла. Добавление и удаление элементов на обоих концах выполняются за `O(1)`.

### Интерфейс

```c
#ifndef DEQUE_H
#define DEQUE_H

#include <stdbool.h>
#include <stddef.h>

typedef struct Node {
    int value;
    struct Node *prev;
    struct Node *next;
} Node;

typedef struct {
    Node *header;   // сигнальный узел перед первым
    Node *trailer;  // сигнальный узел после последнего
    size_t count;
} Deque;

Deque dequeInit(void);
bool dequeIsEmpty(const Deque *deque);
size_t dequeSize(const Deque *deque);
void dequeInsertFirst(Deque *deque, int value);
void dequeInsertLast(Deque *deque, int value);
int dequeRemoveFirst(Deque *deque);
int dequeRemoveLast(Deque *deque);
int dequeFirst(const Deque *deque);
int dequeLast(const Deque *deque);
void dequeFree(Deque *deque);

#endif
```

### Реализация

```c
#include "deque.h"
#include <stdio.h>
#include <stdlib.h>

// Вспомогательная функция: вставка нового узла после узла p
static Node* dequeInsertAfter(Deque *deque, Node *p, int value) {
    Node *newNode = malloc(sizeof(Node));
    if (newNode == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }

    newNode->value = value;
    newNode->prev = p;
    newNode->next = p->next;

    p->next->prev = newNode;
    p->next = newNode;

    deque->count++;
    return newNode;
}

// Вспомогательная функция: удаление узла
static int dequeRemoveNode(Deque *deque, Node *node) {
    int value = node->value;

    node->prev->next = node->next;
    node->next->prev = node->prev;

    free(node);
    deque->count--;

    return value;
}

Deque dequeInit(void) {
    Deque deque;

    deque.header = malloc(sizeof(Node));
    deque.trailer = malloc(sizeof(Node));
    if (deque.header == NULL || deque.trailer == NULL) {
        free(deque.header);
        free(deque.trailer);
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }

    deque.header->next = deque.trailer;
    deque.header->prev = NULL;
    deque.trailer->prev = deque.header;
    deque.trailer->next = NULL;
    deque.count = 0;

    return deque;
}

bool dequeIsEmpty(const Deque *deque) {
    return deque->count == 0;
}

size_t dequeSize(const Deque *deque) {
    return deque->count;
}

void dequeInsertFirst(Deque *deque, int value) {
    dequeInsertAfter(deque, deque->header, value);
}

void dequeInsertLast(Deque *deque, int value) {
    dequeInsertAfter(deque, deque->trailer->prev, value);
}

int dequeRemoveFirst(Deque *deque) {
    if (dequeIsEmpty(deque)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return dequeRemoveNode(deque, deque->header->next);
}

int dequeRemoveLast(Deque *deque) {
    if (dequeIsEmpty(deque)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return dequeRemoveNode(deque, deque->trailer->prev);
}

int dequeFirst(const Deque *deque) {
    if (dequeIsEmpty(deque)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return deque->header->next->value;
}

int dequeLast(const Deque *deque) {
    if (dequeIsEmpty(deque)) {
        fprintf(stderr, "Ошибка: дек пуст\n");
        exit(1);
    }
    return deque->trailer->prev->value;
}

void dequeFree(Deque *deque) {
    Node *current = deque->header->next;
    while (current != deque->trailer) {
        Node *next = current->next;
        free(current);
        current = next;
    }
    free(deque->header);
    free(deque->trailer);
    deque->header = NULL;
    deque->trailer = NULL;
    deque->count = 0;
}
```

### Пример использования

```c
#include "deque.h"
#include <stdio.h>

int main(void) {
    Deque deque = dequeInit();

    // Добавляем с обоих концов
    dequeInsertFirst(&deque, 20);
    dequeInsertFirst(&deque, 10);
    dequeInsertLast(&deque, 30);
    dequeInsertLast(&deque, 40);
    // дек: 10 <-> 20 <-> 30 <-> 40

    printf("Первый: %deque\n", dequeFirst(&deque)); // 10
    printf("Последний: %deque\n", dequeLast(&deque)); // 40
    printf("Размер: %zu\n", dequeSize(&deque)); // 4

    // Удаляем с обоих концов
    printf("RemoveFirst: %deque\n", dequeRemoveFirst(&deque)); // 10
    printf("RemoveLast:  %deque\n", dequeRemoveLast(&deque)); // 40

    printf("Размер: %zu\n", dequeSize(&deque)); // 2
    printf("Первый: %deque\n", dequeFirst(&deque)); // 20
    printf("Последний: %deque\n", dequeLast(&deque)); // 30

    dequeFree(&deque);
    return 0;
}
```

### Как дек эмулирует стек и очередь

Дек — универсальная структура. Из него легко получить и стек, и очередь.

**Стек (LIFO):** используем только один конец.

```c
// push — в конец, pop — с конца
dequeInsertLast(&deque, value);
int x = dequeRemoveLast(&deque);
```

**Очередь (FIFO):** добавление в конец, удаление с начала.

```c
// enqueue — в конец, dequeue — с начала
dequeInsertLast(&deque, value);
int x = dequeRemoveFirst(&deque);
```

### Сложность

| Операция | Сложность |
| :--- | :--- |
| `insertFirst` | `O(1)` |
| `insertLast` | `O(1)` |
| `removeFirst` | `O(1)` |
| `removeLast` | `O(1)` |
| `first`, `last` | `O(1)` |
| `size`, `isEmpty` | `O(1)` |

Все операции за константное время. Память — `O(n)` по числу элементов.

## Стандартные реализации в других языках

### C++: `std::deque`

```cpp
#include <iostream>
#include <deque>

int main() {
    std::deque<int> deque;

    deque.push_back(30);
    deque.push_front(20);
    deque.push_front(10);
    deque.push_back(40);
    // дек: 10, 20, 30, 40

    std::cout << "Первый: " << deque.front() << "\n";   // 10
    std::cout << "Последний: " << deque.back() << "\n"; // 40
    std::cout << "Размер: " << deque.size() << "\n";    // 4

    deque.pop_front();    // удаляет 10
    deque.pop_back();     // удаляет 40

    for (int x : deque) {
        std::cout << x << " ";
    }
    std::cout << "\n";

    return 0;
}
```

`std::deque` — не связный список, а **массив блоков фиксированного размера** с индексацией. Это даёт `O(1)` на оба конца и `O(1)` на доступ по индексу — быстрее, чем `std::list`. На практике именно `std::deque` — контейнер по умолчанию для `std::stack` и `std::queue`.

### Python: `collections.deque`

```python
from collections import deque

deque = deque()

deque.append(30)          # в конец
deque.appendleft(20)      # в начало
deque.appendleft(10)
deque.append(40)
# дек: 10, 20, 30, 40

print(deque[0])           # 10 — первый
print(deque[-1])          # 40 — последний
print(len(deque))         # 4

deque.popleft()           # удаляет 10
deque.pop()               # удаляет 40

# Обход
for x in deque:
    print(x)

# Ограниченный дек — автоматически вытесняет старые элементы
bounded = deque(maxlen=3)
bounded.append(1)
bounded.append(2)
bounded.append(3)
bounded.append(4)     # вытеснит 1
print(bounded)        # deque([2, 3, 4], maxlen=3)
```

`deque` в Python — двусвязный список блоков. Даёт `O(1)` на операции с обоими концами. Умеет работать как **ограниченный дек** через `maxlen` — удобно для скользящего окна.

### Java: `ArrayDeque`

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class DequeExample {
    public static void main(String[] args) {
        Deque<Integer> deque = new ArrayDeque<>();

        deque.addLast(30);
        deque.addFirst(20);
        deque.addFirst(10);
        deque.addLast(40);
        // дек: 10, 20, 30, 40

        System.out.println(deque.peekFirst());   // 10
        System.out.println(deque.peekLast());    // 40
        System.out.println(deque.size());        // 4

        deque.pollFirst();                        // удаляет 10
        deque.pollLast();                         // удаляет 40

        for (int x : deque) {
            System.out.println(x);
        }
    }
}
```

`ArrayDeque` реализован на **циклическом массиве** — как очередь из предыдущей главы, но с доступом с обоих концов. `addFirst`/`addLast`/`pollFirst`/`pollLast` работают за `O(1)`. Java рекомендует `ArrayDeque` вместо устаревшего `Stack` и медленного `LinkedList`.

### C#: `LinkedList<T>`

В C# нет отдельного класса `Deque`, но его роль выполняет `LinkedList<T>`: методы `AddFirst`, `AddLast`, `RemoveFirst`, `RemoveLast` дают `O(1)` на обоих концах.

```csharp
using System;
using System.Collections.Generic;

class Program {
    static void Main() {
        LinkedList<int> deque = new LinkedList<int>();

        deque.AddLast(30);
        deque.AddFirst(20);
        deque.AddFirst(10);
        deque.AddLast(40);
        // дек: 10, 20, 30, 40

        Console.WriteLine(deque.First.Value);   // 10
        Console.WriteLine(deque.Last.Value);    // 40
        Console.WriteLine(deque.Count);         // 4

        deque.RemoveFirst();                     // удаляет 10
        deque.RemoveLast();                      // удаляет 40

        foreach (int x in deque) {
            Console.WriteLine(x);
        }
    }
}
```

## Итог

- **Дек** — двунаправленная очередь: добавление и удаление с обоих концов.
- Методы: `insertFirst`, `insertLast`, `removeFirst`, `removeLast`, `first`, `last`, `size`, `isEmpty`.
- **Реализация через двусвязный список** с сигнальными узлами `header` и `trailer` даёт `O(1)` на все операции.
- Сигнальные узлы упрощают код: не нужно обрабатывать пустой список отдельно.
- Дек **эмулирует** стек (`insertLast` + `removeLast`) и очередь (`insertLast` + `removeFirst`).
- В C++ — `std::deque`; в Python — `collections.deque`; в Java — `ArrayDeque`; в C# — `LinkedList<T>`.
- Применяется в алгоритмах со скользящим окном, в планировщиках, в задачах BFS с двухсторонним обходом.
