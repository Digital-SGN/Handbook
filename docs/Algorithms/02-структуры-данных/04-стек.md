# АТД «Стек»

<img width="100%" height="495" alt="image" src="https://github.com/user-attachments/assets/7caed3e5-903c-4239-8033-087ad89fba4f" />

**Стек** — структура данных с правилом **LIFO** (*last in — first out*, «последним пришёл — первым вышел»). Представьте стопку тарелок: новую кладут сверху, и снять тоже можно только верхнюю.

На практике стек встречается постоянно: стек вызовов функций в программе, кнопка «Назад» в браузере, история отмен (`Undo`) в редакторах, разбор скобочных выражений.

## Как работает стек и где применяется

В стеке есть только одна активная точка — **вершина** (top).
- `push` кладёт элемент на вершину.
- `pop` снимает верхний элемент и возвращает его.

Стек идеально подходит там, где нужно «развернуть» вложенные действия в обратном порядке: например, выйти из функций в порядке, обратном вызову, или отменить последние правки в документе.

## Основные операции АТД «Стек»

- `push(o)` — положить элемент `o` на вершину стека.
- `pop()` — снять и вернуть верхний элемент (ошибка, если стек пуст).
- `top()` — посмотреть верхний элемент без удаления (ошибка, если стек пуст).
- `size()` — количество элементов в стеке.
- `isEmpty()` — пуст ли стек.

## Реализация на C через массив

Храним элементы в массиве фиксированного размера и держим индекс вершины `topIndex` (для пустого стека — `-1`). Все операции работают за `O(1)`, но размер ограничен константой `STACK_SIZE`.

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

#define STACK_SIZE 1000

typedef struct {
    int data[STACK_SIZE];
    int topIndex;    // индекс верхнего элемента (-1, если стек пуст)
} Stack;

Stack stackInit(void) {
    Stack stack;
    stack.topIndex = -1;   // пустой стек
    return stack;
}

bool stackIsEmpty(const Stack *stack) {
    return stack->topIndex < 0;
}

bool stackIsFull(const Stack *stack) {
    return stack->topIndex >= STACK_SIZE - 1;
}

size_t stackSize(const Stack *stack) {
    return (size_t)(stack->topIndex + 1);
}

void stackPush(Stack *stack, int value) {
    if (stackIsFull(stack)) {
        fprintf(stderr, "Ошибка: стек переполнен\n");
        exit(1);
    }
    stack->topIndex++;                     // сдвигаем вершину вверх
    stack->data[stack->topIndex] = value;  // записываем новый элемент
}

int stackPop(Stack *stack) {
    if (stackIsEmpty(stack)) {
        fprintf(stderr, "Ошибка: стек пуст\n");
        exit(1);
    }
    int value = stack->data[stack->topIndex];
    stack->topIndex--;                     // сдвигаем вершину вниз
    return value;
}

int stackTop(const Stack *stack) {
    if (stackIsEmpty(stack)) {
        fprintf(stderr, "Ошибка: стек пуст\n");
        exit(1);
    }
    return stack->data[stack->topIndex];
}
```

### Пример использования

```c
#include "stack.h"
#include <stdio.h>

int main(void) {
    Stack stack = stackInit();

    stackPush(&stack, 10);
    stackPush(&stack, 20);
    stackPush(&stack, 30);

    printf("Размер: %zu\n", stackSize(&stack));
    printf("Вершина: %d\n", stackTop(&stack));
    printf("Pop: %d\n", stackPop(&stack));
    printf("Пуст? %s\n", stackIsEmpty(&stack) ? "да" : "нет");

    return 0;
}
```

## Реализация на C через связный список

Если заранее неизвестно, сколько элементов окажется в стеке, можно сделать его на односвязном списке: вершина находится в **начале** списка, поэтому `push` и `pop` тоже выполняются за `O(1)`.

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;    // ссылка на предыдущий элемент (ниже по стеку)
} Node;

typedef struct {
    Node *topNode;        // вершина стека (голова односвязного списка)
    size_t size;          // текущее количество элементов
} StackList;

void stackListInit(StackList *stack) {
    stack->topNode = NULL;
    stack->size = 0;
}

bool stackListIsEmpty(const StackList *stack) {
    return stack->topNode == NULL;
}

size_t stackListSize(const StackList *stack) {
    return stack->size;
}

void stackListPush(StackList *stack, int value) {
    Node *newNode = malloc(sizeof(Node));
    if (newNode == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }

    newNode->value = value;
    newNode->next = stack->topNode;   // новый узел ссылается на старую вершину
    stack->topNode = newNode;         // обновляем вершину стека
    stack->size++;
}

int stackListPop(StackList *stack) {
    if (stackListIsEmpty(stack)) {
        fprintf(stderr, "Ошибка: стек пуст\n");
        exit(1);
    }

    Node *oldTop = stack->topNode;
    int value = oldTop->value;

    stack->topNode = oldTop->next;    // вершиной становится следующий узел
    free(oldTop);                     // освобождаем память снятого узла
    stack->size--;
    return value;
}

int stackListTop(const StackList *stack) {
    if (stackListIsEmpty(stack)) {
        fprintf(stderr, "Ошибка: стек пуст\n");
        exit(1);
    }
    return stack->topNode->value;
}

void stackListFree(StackList *stack) {
    while (stack->topNode != NULL) {
        Node *next = stack->topNode->next;
        free(stack->topNode);
        stack->topNode = next;
    }
    stack->size = 0;
}
```

### Что выбрать: массив или список?

- **Массив** проще, лучше дружит с кэшем процессора и не требует частых `malloc`/`free`, но имеет фиксированный лимит.
- **Связный список** растёт динамически, пока хватает памяти, но добавляет накладные расходы на выделение узлов и требует освобождать их через `stackListFree`.

## Стандартные реализации в других языках

- **C++:** `std::stack` (по умолчанию адаптер над `std::deque`).
- **Python:** обычный `list` (`append` и `pop` с конца) или `collections.deque` (`append` и `pop`).
- **Java:** `ArrayDeque` с методами `push`, `pop`, `peek` (устаревший `java.util.Stack` использовать не рекомендуют).
- **C#:** `Stack<T>` (`Push`, `Pop`, `Peek`).

| Язык | Рекомендуемый тип | Внутренняя основа |
| :--- | :--- | :--- |
| **C** | Ручная структура | Массив или связный список |
| **C++** | `std::stack` | Обычно `std::deque` |
| **Python** | `list` или `collections.deque` | Динамический массив / блоки |
| **Java** | `ArrayDeque` | Циклический массив |
| **C#** | `Stack<T>` | Массив |

## Итог

- **Стек** работает по принципу **LIFO**: последний пришёл — первым вышел.
- Все базовые операции (`push`, `pop`, `top`, `size`, `isEmpty`) выполняются за `O(1)`.
- На массиве стек компактнее и быстрее, на связном списке — без жёсткого лимита размера.
