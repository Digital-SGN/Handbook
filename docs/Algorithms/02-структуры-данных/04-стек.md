**Стек** (англ. stack — стопка) — структура данных, в которой доступ к элементам организован по принципу **LIFO** (last in — first out, «последним пришёл — первым вышел»). Принцип работы стека чаще всего сравнивают со стопкой тарелок: чтобы взять вторую сверху, нужно сначала снять верхнюю.

## Что такое стек

Добавление элемента — **проталкивание** (push) — возможно только в **вершину** стека. Добавленный элемент становится первым сверху. Удаление — **выталкивание** (pop) — тоже возможно только из вершины, при этом второй сверху элемент становится верхним.

Такая дисциплина доступа называется **LIFO**. Она встречается везде: от архитектуры процессоров до интернет-браузеров.

## Где применяются стеки

Стеки широко применяются в вычислительной технике. Для отслеживания точек возврата из подпрограмм используется **стек вызовов** — неотъемлемая часть архитектуры большинства современных процессоров. Языки высокого уровня тоже используют его для передачи параметров при вызове процедур.

Арифметические сопроцессоры, программируемые микрокалькуляторы и язык Forth применяют стековую модель вычислений.

В интернет-браузерах адреса посещаемых сайтов хранятся в виде стеков. При открытии нового сайта его адрес «вдавливается» в стек, а кнопка «Назад» извлекает предыдущий адрес.

В большинстве текстовых редакторов существует механизм отмены действий **Undo**. Он реализуется через хранение проводимых изменений в виде стека.

Наглядно работу стека можно представить через аналогию с железнодорожным разъездом, которую предложил **Эдсгер Дейкстра**.

Многие исследователи независимо друг от друга пришли к важности стеков и очередей и дали им разные имена. Стеки называли **магазинными списками** (push-down lists), **реверсивными хранилищами** (reversion storages), **магазинами** (cellars), **вложенными хранилищами** (nesting stores), **кучами** (piles) и даже **флюгерными списками** (yo-yo lists).

## Методы АТД «Стек»

Стек `S` — абстрактный тип данных с двумя основными методами:

**`push(o)`** помещает объект `o` в вершину стека. Вход: объект. Выход: нет.

**`pop()`** удаляет объект из стека и возвращает новый верхний объект; если стек пуст, выдаётся сообщение об ошибке. Вход: нет. Выход: объект.

Кроме того, обычно поддерживаются дополнительные методы:

**`size()`** возвращает число объектов в стеке. Вход: нет. Выход: целое число.

**`isEmpty()`** возвращает логическое значение: пуст ли стек. Вход: нет. Выход: логическое значение.

**`top()`** возвращает верхний объект в стеке, не удаляя его; если стек пуст, выдаётся ошибка. Вход: нет. Выход: объект.

## Реализация на C через массив

Самый простой способ реализации стека — хранить элементы в **массиве**. Поскольку длина массива задаётся при создании, нужно определить максимальный размер `N`. Стек состоит из массива `S` на `N` элементов и целочисленной переменной `t` — индекса последнего элемента. Изначально `t = -1`, что означает пустой стек.

### Интерфейс

```c
#ifndef STACK_H
#define STACK_H

#include <stdbool.h>
#include <stddef.h>

#define STACK_SIZE 1000

typedef struct {
    int data[STACK_SIZE];
    int topIndex;
} Stack;

Stack stackInit(void);
bool stackIsEmpty(const Stack *s);
bool stackIsFull(const Stack *s);
size_t stackSize(const Stack *s);
void stackPush(Stack *s, int value);
int stackPop(Stack *s);
int stackTop(const Stack *s);

#endif
```

### Реализация

```c
#include "stack.h"
#include <stdio.h>
#include <stdlib.h>

Stack stackInit(void) {
    Stack s;
    s.topIndex = -1;
    return s;
}

bool stackIsEmpty(const Stack *s) {
    return s->topIndex < 0;
}

bool stackIsFull(const Stack *s) {
    return s->topIndex >= STACK_SIZE - 1;
}

size_t stackSize(const Stack *s) {
    return (size_t)(s->topIndex + 1);
}

void stackPush(Stack *s, int value) {
    if (stackIsFull(s)) {
        fprintf(stderr, "Ошибка: стек переполнен\n");
        exit(1);
    }
    s->topIndex++;
    s->data[s->topIndex] = value;
}

int stackPop(Stack *s) {
    if (stackIsEmpty(s)) {
        fprintf(stderr, "Ошибка: стек пуст\n");
        exit(1);
    }
    int value = s->data[s->topIndex];
    s->topIndex--;
    return value;
}

int stackTop(const Stack *s) {
    if (stackIsEmpty(s)) {
        fprintf(stderr, "Ошибка: стек пуст\n");
        exit(1);
    }
    return s->data[s->topIndex];
}
```

### Пример использования

```c
#include "stack.h"
#include <stdio.h>

int main(void) {
    Stack s = stackInit();

    stackPush(&s, 10);
    stackPush(&s, 20);
    stackPush(&s, 30);

    printf("Размер: %zu\n", stackSize(&s));     // 3
    printf("Вершина: %d\n", stackTop(&s));      // 30

    printf("Pop: %d\n", stackPop(&s));          // 30
    printf("Pop: %d\n", stackPop(&s));          // 20
    printf("Pop: %d\n", stackPop(&s));          // 10

    printf("Пуст? %s\n", stackIsEmpty(&s) ? "да" : "нет");

    return 0;
}
```

### Сложность

При реализации через массив **все методы** работают за **`O(1)`**. Это максимально быстро.

**Недостаток.** Размер `N` задан заранее. Если элементов больше — переполнение. Если меньше — память тратится впустую.

## Реализация на C через связный список

Альтернатива — представить стек как **односвязный список**. Вершина стека — в **начале** списка, потому что добавление и удаление за `O(1)` возможны только в начале. Для `size()` за `O(1)` храним счётчик в структуре стека.

Преимущество перед массивом: **размер не нужно задавать заранее**. Пространство растёт по мере добавления элементов — `O(n)`, где `n` — текущее число элементов.

### Интерфейс

```c
#ifndef STACK_LIST_H
#define STACK_LIST_H

#include <stdbool.h>
#include <stddef.h>

// Узел односвязного списка
typedef struct Node {
    int value;
    struct Node *next;
} Node;

// Сам стек: указатель на вершину + счётчик
typedef struct {
    Node *topNode;
    size_t     count;
} StackList;

// жизненный цикл 
void stackListInit(StackList *s);
void stackListFree(StackList *s);

// состояние
bool stackListIsEmpty(const StackList *s);
size_t stackListSize(const StackList *s);

// операции 
void stackListPush(StackList *s, int value);
int stackListPop(StackList *s);
int stackListTop(const StackList *s);

#endif
```

### Реализация

```c
#include "stack_list.h"
#include <stdio.h>
#include <stdlib.h>

void stackListInit(StackList *s) {
    s->topNode = NULL;
    s->count   = 0;
}

bool stackListIsEmpty(const StackList *s) {
    return s->topNode == NULL;
}

size_t stackListSize(const StackList *s) {
    return s->count;
}

void stackListPush(StackList *s, int value) {
    Node *newNode = malloc(sizeof(Node));
    if (newNode == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }

    newNode->value = value;
    newNode->next  = s->topNode;   // новый узел указывает на прежнюю вершину
    s->topNode     = newNode;      // теперь он сам — вершина
    s->count++;
}

int stackListPop(StackList *s) {
    if (stackListIsEmpty(s)) {
        fprintf(stderr, "Ошибка: стек пуст\n");
        exit(1);
    }

    Node *oldTop = s->topNode;
    int        value  = oldTop->value;

    s->topNode = oldTop->next;     // вершиной становится следующий узел
    free(oldTop);
    s->count--;

    return value;
}

int stackListTop(const StackList *s) {
    if (stackListIsEmpty(s)) {
        fprintf(stderr, "Ошибка: стек пуст\n");
        exit(1);
    }
    return s->topNode->value;
}

void stackListFree(StackList *s) {
    while (s->topNode != NULL) {
        Node *next = s->topNode->next;
        free(s->topNode);
        s->topNode = next;
    }
    s->count = 0;
}
```

### Пример использования

```c
#include "stack_list.h"
#include <stdio.h>

int main(void) {
    StackList s;
    stackListInit(&s);

    stackListPush(&s, 1);
    stackListPush(&s, 2);
    stackListPush(&s, 3);

    printf("Размер: %zu\n", stackListSize(&s));    // 3
    printf("Вершина: %d\n", stackListTop(&s));     // 3

    while (!stackListIsEmpty(&s)) {
        printf("Pop: %d\n", stackListPop(&s));
    }

    stackListFree(&s);
    return 0;
}
```

### Сложность

| Операция | Сложность |
| :--- | :--- |
| `push` | `O(1)` |
| `pop` | `O(1)` |
| `top` | `O(1)` |
| `size` | `O(1)` |
| `isEmpty` | `O(1)` |

Память — `O(n)`, где `n` — текущее число элементов. Никакого фиксированного предела нет: стек растёт, пока есть память в куче.

> **Что выбрать?** Массив проще, не требует `malloc`/`free` и работает чуть быстрее за счёт локальности. Список гибче: размер не задан заранее. Если максимальный размер известен — берите массив. Если нет — список.

## Стандартные реализации в других языках

### C++: `std::stack`

```cpp
#include <iostream>
#include <stack>

int main() {
    std::stack<int> s;

    s.push(10);
    s.push(20);
    s.push(30);

    std::cout << "Вершина: " << s.top() << "\n";   // 30
    std::cout << "Размер: " << s.size() << "\n";   // 3

    s.pop();                                        // удаляем 30
    std::cout << "Вершина: " << s.top() << "\n";   // 20

    while (!s.empty()) {
        std::cout << s.top() << " ";
        s.pop();
    }
    std::cout << "\n";

    return 0;
}
```

`std::stack` — адаптер контейнера. По умолчанию строится поверх `std::deque`, но можно указать `std::vector` или `std::list`.

### Python: `list` как стек

В Python стек удобно эмулировать через список: `append` и `pop` работают с концом за `O(1)`.

```python
s = []

s.append(10)
s.append(20)
s.append(30)

print(s[-1])        # 30 — вершина
print(len(s))       # 3

print(s.pop())      # 30
print(s.pop())      # 20

# Проверка на пустоту
if not s:
    print("Пуст")

# Более явный вариант — collections.deque
from collections import deque
stack = deque()
stack.append(10)
stack.append(20)
print(stack.pop())  # 20
```

`list` даёт амортизированное `O(1)` на `append` и `pop`. Для явной семантики стека часто используют `deque`.

### Java: `ArrayDeque`

Класс `java.util.Stack` устарел (он наследуется от `Vector` и синхронизирован). Современный вариант — **`ArrayDeque`** с методами `push` и `pop`.

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class StackExample {
    public static void main(String[] args) {
        Deque<Integer> stack = new ArrayDeque<>();

        stack.push(10);       // добавить в вершину
        stack.push(20);
        stack.push(30);

        System.out.println(stack.peek());   // 30 — вершина
        System.out.println(stack.size());   // 3

        System.out.println(stack.pop());    // 30
        System.out.println(stack.pop());    // 20

        System.out.println(stack.isEmpty()); // false
    }
}
```

`ArrayDeque` реализован на массиве и не синхронизирован — быстрее, чем `Stack`.

### C#: `Stack<T>`

```csharp
using System;
using System.Collections.Generic;

class Program {
    static void Main() {
        Stack<int> s = new Stack<int>();

        s.Push(10);
        s.Push(20);
        s.Push(30);

        Console.WriteLine(s.Peek());    // 30
        Console.WriteLine(s.Count);     // 3

        Console.WriteLine(s.Pop());     // 30
        Console.WriteLine(s.Pop());     // 20

        Console.WriteLine(s.Count);     // 1
    }
}
```

`Stack<T>` — стандартный дженерик-класс. По умолчанию реализован на массиве, при переполнении удваивает ёмкость.

## Итог

- **Стек** работает по принципу **LIFO**: последний пришёл — первым вышел.
- Основные методы: `push` и `pop`. Дополнительные: `top`, `size`, `isEmpty`.
- Применяется в стеке вызовов, Undo, навигации браузера, вычислениях на стековой модели.
- **Реализация через массив:** все операции `O(1)`, но размер нужно задать заранее.
- **Реализация через связный список:** все операции `O(1)`, размер не ограничен, но нужны `malloc`/`free`.
- В C стек пишут вручную; в C++ — `std::stack`; в Python — `list` или `deque`; в Java — `ArrayDeque`; в C# — `Stack<T>`.
