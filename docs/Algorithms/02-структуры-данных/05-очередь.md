# АТД «Очередь»

<img width="100%" height="300" alt="image" src="https://github.com/user-attachments/assets/885fb6e4-2a49-40c2-abb9-acf05e2a176a" />

**Очередь** работает по принципу **FIFO** (*first in — first out*, «первым пришёл — первым вышел»). Как в очереди на кассу: новые приходят в конец, а обслуживают тех, кто стоит в начале дольше всех.

Очереди используют в планировщиках задач, буферах сообщений, обработке запросов и в алгоритмах обхода графов в ширину (BFS).

## Как работает очередь

У очереди два конца:
- элементы добавляются **в конец** (`enqueue`);
- элементы забираются **с начала** (`dequeue`).

Если хранить очередь в обычном массиве и при каждом удалении с начала сдвигать все остальные элементы влево, удаление станет `O(n)`. Чтобы избежать сдвигов и получить `O(1)` на обе операции, используют **циклический буфер** либо **связный список** с двумя указателями (на начало и на конец).

## Основные операции АТД «Очередь»

- `enqueue(o)` — добавить элемент `o` в конец очереди.
- `dequeue()` — удалить и вернуть первый элемент (ошибка, если очередь пуста).
- `front()` — вернуть первый элемент без удаления (ошибка, если очередь пуста).
- `size()` — количество элементов в очереди.
- `isEmpty()` — пуста ли очередь.

## Реализация на C через циклический массив

Индексы `front` и `rear` двигаются по кругу с помощью остатка от деления `% QUEUE_SIZE`. В примере ниже мы дополнительно храним счётчик `count`, чтобы легко проверять пустоту и заполненность (с ограничением до `QUEUE_SIZE - 1` элементов).

### Интерфейс (`queue.h`)

```c
#ifndef QUEUE_H
#define QUEUE_H

#include <stdbool.h>
#include <stddef.h>

#define QUEUE_SIZE 1000

typedef struct {
    int data[QUEUE_SIZE];
    size_t front;
    size_t rear;
    size_t count;
} Queue;

Queue queueInit(void);
bool queueIsEmpty(const Queue *queue);
size_t queueSize(const Queue *queue);
void queueEnqueue(Queue *queue, int value);
int queueDequeue(Queue *queue);
int queueFront(const Queue *queue);

#endif
```

### Реализация (`queue.c`)

```c
#include "queue.h"
#include <stdio.h>
#include <stdlib.h>

Queue queueInit(void) {
    Queue queue;
    queue.front = 0;
    queue.rear = 0;
    queue.count = 0;
    return queue;
}

bool queueIsEmpty(const Queue *queue) {
    return queue->count == 0;
}

size_t queueSize(const Queue *queue) {
    return queue->count;
}

void queueEnqueue(Queue *queue, int value) {
    if (queue->count == QUEUE_SIZE - 1) {
        fprintf(stderr, "Ошибка: очередь переполнена\n");
        exit(1);
    }

    queue->data[queue->rear] = value;
    queue->rear = (queue->rear + 1) % QUEUE_SIZE;
    queue->count++;
}

int queueDequeue(Queue *queue) {
    if (queueIsEmpty(queue)) {
        fprintf(stderr, "Ошибка: очередь пуста\n");
        exit(1);
    }

    int value = queue->data[queue->front];
    queue->front = (queue->front + 1) % QUEUE_SIZE;
    queue->count--;
    return value;
}

int queueFront(const Queue *queue) {
    if (queueIsEmpty(queue)) {
        fprintf(stderr, "Ошибка: очередь пуста\n");
        exit(1);
    }
    return queue->data[queue->front];
}
```

### Пример использования

```c
#include "queue.h"
#include <stdio.h>

int main(void) {
    Queue queue = queueInit();

    queueEnqueue(&queue, 10);
    queueEnqueue(&queue, 20);
    queueEnqueue(&queue, 30);

    printf("Размер: %zu\n", queueSize(&queue));
    printf("Начало: %d\n", queueFront(&queue));
    printf("Dequeue: %d\n", queueDequeue(&queue));
    printf("Dequeue: %d\n", queueDequeue(&queue));
    printf("Пуста? %s\n", queueIsEmpty(&queue) ? "да" : "нет");

    return 0;
}
```

## Реализация на C через связный список

В односвязном списке удобно удалять с начала (`frontNode`) и добавлять в конец (`rearNode`). Оба указателя позволяют делать `enqueue` и `dequeue` за `O(1)` без заранее заданного лимита размера.

### Интерфейс (`queue_list.h`)

```c
#ifndef QUEUE_LIST_H
#define QUEUE_LIST_H

#include <stdbool.h>
#include <stddef.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;

typedef struct {
    Node *frontNode;
    Node *rearNode;
    size_t count;
} QueueList;

void queueListInit(QueueList *queue);
bool queueListIsEmpty(const QueueList *queue);
size_t queueListSize(const QueueList *queue);
void queueListEnqueue(QueueList *queue, int value);
int queueListDequeue(QueueList *queue);
int queueListFront(const QueueList *queue);
void queueListFree(QueueList *queue);

#endif
```

### Реализация (`queue_list.c`)

```c
#include "queue_list.h"
#include <stdio.h>
#include <stdlib.h>

void queueListInit(QueueList *queue) {
    queue->frontNode = NULL;
    queue->rearNode = NULL;
    queue->count = 0;
}

bool queueListIsEmpty(const QueueList *queue) {
    return queue->frontNode == NULL;
}

size_t queueListSize(const QueueList *queue) {
    return queue->count;
}

void queueListEnqueue(QueueList *queue, int value) {
    Node *newNode = malloc(sizeof(Node));
    if (newNode == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }

    newNode->value = value;
    newNode->next = NULL;

    if (queue->rearNode == NULL) {
        queue->frontNode = newNode;
        queue->rearNode = newNode;
    } else {
        queue->rearNode->next = newNode;
        queue->rearNode = newNode;
    }

    queue->count++;
}

int queueListDequeue(QueueList *queue) {
    if (queueListIsEmpty(queue)) {
        fprintf(stderr, "Ошибка: очередь пуста\n");
        exit(1);
    }

    Node *oldFront = queue->frontNode;
    int value = oldFront->value;
    queue->frontNode = oldFront->next;

    if (queue->frontNode == NULL) {
        queue->rearNode = NULL;
    }

    free(oldFront);
    queue->count--;
    return value;
}

int queueListFront(const QueueList *queue) {
    if (queueListIsEmpty(queue)) {
        fprintf(stderr, "Ошибка: очередь пуста\n");
        exit(1);
    }
    return queue->frontNode->value;
}

void queueListFree(QueueList *queue) {
    while (queue->frontNode != NULL) {
        Node *next = queue->frontNode->next;
        free(queue->frontNode);
        queue->frontNode = next;
    }
    queue->rearNode = NULL;
    queue->count = 0;
}
```

### На что обратить внимание в списке
- При добавлении в пустую очередь оба указателя (`frontNode` и `rearNode`) должны указать на новый узел.
- При удалении последнего элемента `rearNode` нужно обнулить — иначе он останется висячим указателем.

## Стандартные реализации в других языках

- **C++:** `std::queue` (по умолчанию поверх `std::deque`).
- **Python:** `collections.deque` (`append` в конец, `popleft` с начала); для многопоточности есть `queue.Queue`.
- **Java:** `ArrayDeque` или `LinkedList` через интерфейс `Queue` (`offer`, `poll`, `peek`).
- **C#:** `Queue<T>` (`Enqueue`, `Dequeue`, `Peek`), построенный на циклическом массиве.

| Язык | Рекомендуемый тип | Внутренняя основа |
| :--- | :--- | :--- |
| **C** | Ручная структура | Циклический массив или список |
| **C++** | `std::queue` | Обычно `std::deque` |
| **Python** | `collections.deque` | Двусвязный список блоков |
| **Java** | `ArrayDeque` | Циклический массив |
| **C#** | `Queue<T>` | Циклический массив |

## Итог

- **Очередь** работает по принципу **FIFO**: первый пришёл — первым вышел.
- Все базовые операции (`enqueue`, `dequeue`, `front`, `size`, `isEmpty`) выполняются за `O(1)`.
- Циклический массив экономит память и не требует аллокаций на каждый элемент, а связный список не ограничен фиксированной ёмкостью.
