# АТД «Очередь»

<img width="100%" height="300" alt="image" src="https://github.com/user-attachments/assets/885fb6e4-2a49-40c2-abb9-acf05e2a176a" />


**Очередь** — ещё одна базовая структура данных. Она похожа на стек, но работает по другому принципу: **FIFO** (first-in first-out, «первым пришёл — первым ушёл»). Добавлять объекты в очередь можно в любое время, но удалить — только тот, который был добавлен первым. Элементы добавляются **в конец** очереди, а удаляются **с начала**.

## Аналогия и определение

Очередь данных удобно сравнивать с очередью людей в парке аттракционов. Люди встают в очередь с конца, а те, кто пришёл первым, катаются первыми. Точно так же работает и очередь как структура данных.

Формально **АТД «Очередь»** представляет собой последовательность объектов, в которой доступ и удаление разрешены только для первого элемента, называемого **началом очереди**, а добавление — только **в конец**.

## Методы АТД «Очередь»

Очередь `S` поддерживает два основных метода:

**`enqueue(o)`** помещает объект `o` в конец очереди. Вход: объект. Выход: нет.

**`dequeue()`** удаляет и возвращает объект из начала очереди; если очередь пуста — ошибка. Вход: нет. Выход: объект.

Кроме того, как и у стека, есть дополнительные методы:

**`size()`** возвращает число объектов в очереди. Вход: нет. Выход: целое число.

**`isEmpty()`** возвращает логическое значение: пуста ли очередь. Вход: нет. Выход: логическое значение.

**`front()`** возвращает первый объект в очереди, не удаляя его; если очередь пуста — ошибка. Вход: нет. Выход: объект.

## Реализация на C через циклический массив

Простейший способ реализации очереди — **массив**. Но наивный подход, при котором `Q[0]` всегда первый элемент, приводит к проблеме: при каждом `dequeue` нужно **сдвигать** все элементы вперёд — `O(n)`. Это неприемлемо.

Решение — **два индекса** `f` (front — начало) и `r` (rear — следующая свободная ячейка). При удалении просто увеличиваем `f`, при добавлении — `r`. Чтобы не выходить за границы массива, используем **операцию деления по модулю** — массив становится «циклическим».

Из-за цикличности возникает новая проблема: при `f == r` очередь может быть как пустой, так и полной. Чтобы различить эти состояния, **одна ячейка остаётся незадействованной**: очередь может содержать не более `N - 1` элементов.

### Интерфейс

```c
#ifndef QUEUE_H
#define QUEUE_H

#include <stdbool.h>
#include <stddef.h>

#define QUEUE_SIZE 1000

typedef struct {
    int data[QUEUE_SIZE];
    size_t front;    // индекс начала очереди
    size_t rear;     // индекс следующей свободной ячейки
    size_t count;    // текущее число элементов
} Queue;

Queue queueInit(void);
bool queueIsEmpty(const Queue *q);
size_t queueSize(const Queue *q);
void queueEnqueue(Queue *q, int value);
int queueDequeue(Queue *q);
int queueFront(const Queue *q);

#endif
```

### Реализация

```c
#include "queue.h"
#include <stdio.h>
#include <stdlib.h>

Queue queueInit(void) {
    Queue q;
    q.front = 0;
    q.rear = 0;
    q.count = 0;
    return q;       
}

bool queueIsEmpty(const Queue *q) {
    return q->count == 0;
}

size_t queueSize(const Queue *q) {
    return q->count;
}

void queueEnqueue(Queue *q, int value) {
    if (q->count == QUEUE_SIZE - 1) {
        fprintf(stderr, "Ошибка: очередь переполнена\n");
        exit(1);
    }

    q->data[q->rear] = value;
    q->rear = (q->rear + 1) % QUEUE_SIZE;
    q->count++;
}

int queueDequeue(Queue *q) {
    if (queueIsEmpty(q)) {
        fprintf(stderr, "Ошибка: очередь пуста\n");
        exit(1);
    }

    int value = q->data[q->front];
    q->front = (q->front + 1) % QUEUE_SIZE;
    q->count--;

    return value;
}

int queueFront(const Queue *q) {
    if (queueIsEmpty(q)) {
        fprintf(stderr, "Ошибка: очередь пуста\n");
        exit(1);
    }
    return q->data[q->front];
}
```

### Пример использования

```c
#include "queue.h"
#include <stdio.h>

int main(void) {
    Queue q = queueInit();

    queueEnqueue(&q, 10);
    queueEnqueue(&q, 20);
    queueEnqueue(&q, 30);

    printf("Размер: %zu\n", queueSize(&q)); // 3
    printf("Начало: %d\n", queueFront(&q)); // 10

    printf("Dequeue: %d\n", queueDequeue(&q)); // 10
    printf("Dequeue: %d\n", queueDequeue(&q)); // 20

    printf("Начало: %d\n", queueFront(&q)); // 30
    printf("Пуста? %s\n", queueIsEmpty(&q) ? "да" : "нет");

    return 0;
}
```

### Сложность

Все методы выполняются за **`O(1)`**. Единственный недостаток — размер `N` нужно задавать заранее. Если число одновременно находящихся в очереди элементов известно заранее, реализация через массив эффективна.

## Реализация на C через связный список

Очередь также можно реализовать на основе **односвязного списка**. Для максимальной эффективности начало очереди (где удаляем) размещают в **начале** списка, а конец (где добавляем) — в **конце**. Нужны две ссылки: на первый и последний узлы. Все операции за `O(1)`, максимальный размер задавать не нужно.

### Интерфейс

```c
#ifndef QUEUE_LIST_H
#define QUEUE_LIST_H

#include <stdbool.h>
#include <stddef.h>

typedef struct QueueNode {
    int value;
    struct QueueNode *next;
} QueueNode;

typedef struct {
    QueueNode *frontNode;   // начало очереди (здесь удаляем)
    QueueNode *rearNode;    // конец очереди (здесь добавляем)
    size_t count;
} QueueList;

void queueListInit(QueueList *q);
bool queueListIsEmpty(const QueueList *q);
size_t queueListSize(const QueueList *q);
void queueListEnqueue(QueueList *q, int value);
int queueListDequeue(QueueList *q);
int queueListFront(const QueueList *q);
void queueListFree(QueueList *q);

#endif
```

### Реализация

```c
#include "queue_list.h"
#include <stdio.h>
#include <stdlib.h>

void queueListInit(QueueList *q) {
    q->frontNode = NULL;
    q->rearNode = NULL;
    q->count = 0;
}

bool queueListIsEmpty(const QueueList *q) {
    return q->frontNode == NULL;
}

size_t queueListSize(const QueueList *q) {
    return q->count;
}

void queueListEnqueue(QueueList *q, int value) {
    QueueNode *newNode = malloc(sizeof(QueueNode));
    if (newNode == NULL) {
        fprintf(stderr, "Ошибка: не удалось выделить память\n");
        exit(1);
    }

    newNode->value = value;
    newNode->next = NULL;

    // Если очередь пуста, новый узел — и начало, и конец
    if (q->rearNode == NULL) {
        q->frontNode = newNode;
        q->rearNode = newNode;
    } else {
        q->rearNode->next = newNode;
        q->rearNode = newNode;
    }

    q->count++;
}

int queueListDequeue(QueueList *q) {
    if (queueListIsEmpty(q)) {
        fprintf(stderr, "Ошибка: очередь пуста\n");
        exit(1);
    }

    QueueNode *oldFront = q->frontNode;
    int value = oldFront->value;

    q->frontNode = oldFront->next;

    // Если удалили последний элемент — rear тоже должен стать NULL
    if (q->frontNode == NULL) {
        q->rearNode = NULL;
    }

    free(oldFront);
    q->count--;

    return value;
}

int queueListFront(const QueueList *q) {
    if (queueListIsEmpty(q)) {
        fprintf(stderr, "Ошибка: очередь пуста\n");
        exit(1);
    }
    return q->frontNode->value;
}

void queueListFree(QueueList *q) {
    while (q->frontNode != NULL) {
        QueueNode *next = q->frontNode->next;
        free(q->frontNode);
        q->frontNode = next;
    }
    q->rearNode = NULL;
    q->count = 0;
}
```

### Пример использования

```c
#include "queue_list.h"
#include <stdio.h>

int main(void) {
    QueueList q;
    queueListInit(&q);

    queueListEnqueue(&q, 1);
    queueListEnqueue(&q, 2);
    queueListEnqueue(&q, 3);

    printf("Размер: %zu\n", queueListSize(&q));    // 3
    printf("Начало: %d\n", queueListFront(&q));    // 1

    while (!queueListIsEmpty(&q)) {
        printf("Dequeue: %d\n", queueListDequeue(&q));
    }

    queueListFree(&q);
    return 0;
}
```

### Особые случаи

При реализации через связный список нужно внимательно следить за двумя случаями.

Первый — **enqueue в пустую очередь**. Если `rearNode == NULL`, то новый узел становится и началом, и концом. Без этой проверки мы бы разыменовали `NULL`.

Второй — **dequeue последнего элемента**. После удаления `frontNode` становится `NULL`, и нужно **обнулить** `rearNode` — иначе он будет указывать на освобождённую память.

### Сложность

| Операция | Сложность |
| :--- | :--- |
| `enqueue` | `O(1)` |
| `dequeue` | `O(1)` |
| `front` | `O(1)` |
| `size` | `O(1)` |
| `isEmpty` | `O(1)` |

Память — `O(n)` по текущему числу элементов. Никакого фиксированного предела нет.

> **Что выбрать?** Массив проще, не требует `malloc`/`free`, работает чуть быстрее. Список гибче: размер не задан заранее, но требует следить за особыми случаями. Если максимальный размер известен — массив. Если нет — список.

## Стандартные реализации в других языках

### C++: `std::queue`

```cpp
#include <iostream>
#include <queue>

int main() {
    std::queue<int> q;

    q.push(10);
    q.push(20);
    q.push(30);

    std::cout << "Начало: " << q.front() << "\n";   // 10
    std::cout << "Размер: " << q.size() << "\n";    // 3

    q.pop();                                         // удаляет 10
    std::cout << "Начало: " << q.front() << "\n";   // 20

    while (!q.empty()) {
        std::cout << q.front() << " ";
        q.pop();
    }
    std::cout << "\n";

    return 0;
}
```

`std::queue` — адаптер контейнера. По умолчанию строится поверх `std::deque`, но можно указать `std::list`.

### Python: `collections.deque`

В Python очередь удобно реализовать через **`collections.deque`**: `append` добавляет в конец, `popleft` удаляет с начала — обе операции `O(1)`.

```python
from collections import deque

q = deque()

q.append(10)
q.append(20)
q.append(30)

print(q[0])          # 10 — начало очереди
print(len(q))        # 3

print(q.popleft())   # 10
print(q.popleft())   # 20

if not q:
    print("Пуста")

# Также есть queue.Queue для потокобезопасной работы
```

Для потокобезопасной очереди в Python есть отдельный модуль `queue` с классом `queue.Queue`.

### Java: `ArrayDeque` или `LinkedList`

```java
import java.util.ArrayDeque;
import java.util.Queue;

public class QueueExample {
    public static void main(String[] args) {
        Queue<Integer> q = new ArrayDeque<>();

        q.offer(10);        // добавить в конец
        q.offer(20);
        q.offer(30);

        System.out.println(q.peek());   // 10 — начало
        System.out.println(q.size());   // 3

        System.out.println(q.poll());   // 10
        System.out.println(q.poll());   // 20

        System.out.println(q.isEmpty()); // false
    }
}
```

Методы `offer`/`poll`/`peek` не бросают исключений. Альтернативы — `add`/`remove`/`element`, которые бросают.

### C#: `Queue<T>`

```csharp
using System;
using System.Collections.Generic;

class Program {
    static void Main() {
        Queue<int> q = new Queue<int>();

        q.Enqueue(10);
        q.Enqueue(20);
        q.Enqueue(30);

        Console.WriteLine(q.Peek());     // 10
        Console.WriteLine(q.Count);      // 3

        Console.WriteLine(q.Dequeue());  // 10
        Console.WriteLine(q.Dequeue());  // 20

        Console.WriteLine(q.Count);      // 1
    }
}
```

`Queue<T>` реализован на циклическом массиве — как раз той стратегией, которую мы разобрали.

## Итог

- **Очередь** работает по принципу **FIFO**: первый пришёл — первым вышел.
- Основные методы: `enqueue` и `dequeue`. Дополнительные: `front`, `size`, `isEmpty`.
- Применяется в планировщиках задач, буферизации, обработке событий, поиске в ширину (BFS).
- **Реализация через циклический массив:** все операции `O(1)`, но размер задан заранее. Индексы `f` и `r` ходят по кругу через деление по модулю.
- **Реализация через связный список:** все операции `O(1)`, размер не ограничен. Важно правильно обрабатывать пустую очередь и удаление последнего элемента.
- В C очередь пишут вручную; в C++ — `std::queue`; в Python — `collections.deque`; в Java — `ArrayDeque`; в C# — `Queue<T>`.
