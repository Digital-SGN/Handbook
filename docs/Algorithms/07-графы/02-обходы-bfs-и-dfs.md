# Обходы графа: BFS и DFS

Представьте, что вы стоите в центре лабиринта, и вам нужно обойти
все комнаты. Есть два способа. Первый: идти по коридору, пока не
упрётесь в тупик, потом возвращаться и пробовать следующую ветку.
Второй: сначала обойти все комнаты на расстоянии одного шага, потом
двух, потом трёх — как круги по воде от брошенного камня.

Первый способ — это **DFS** (depth-first search, поиск в глубину).
Второй — **BFS** (breadth-first search, поиск в ширину). Оба обходят
весь граф за `O(V + E)`, но делают это по-разному и решают разные
задачи.

Это, пожалуй, **самые важные алгоритмы во всём курсе**. Не потому что
они сложные (они простые), а потому что **на них стоит всё остальное**.
Топологическая сортировка — это DFS. Кратчайший путь в невзвешенном
графе — это BFS. Компоненты связности — это DFS. Дейкстра — это BFS
с приоритетной очередью. Понимаете, к чему я?

В этой главе разберёмся: как устроены оба обхода, чем отличаются,
какие задачи решают и как их писать на C.

## Зачем вообще обходить граф

Обход — это систематический способ **посетить каждую вершину ровно
один раз**. Казалось бы, что тут думать? Но именно от **порядка**
посещения зависит, какие задачи решаются «бесплатно».

- Хотите узнать, есть ли путь из A в B? Обойдите граф — если B
  встретилась, путь есть.
- Хотите найти **кратчайший** путь (по числу рёбер)? Нужен именно BFS,
  потому что он идёт «волнами», и первое попадание в B — это
  кратчайшее расстояние.
- Хотите найти **компоненты связности**? DFS — обошли компоненту
  целиком, перешли к следующей.
- Хотите **топологически отсортировать**? DFS с post-order.

Оба обхода работают за `O(V + E)`: каждую вершину посещаем один раз
и перебираем всех её соседей. Это оптимально — быстрее нельзя, потому
что нужно хотя бы прочитать все рёбра.

> **Главная мысль:** BFS и DFS — это не «два алгоритма», а **два
> порядка обхода**. Один и тот же граф, одна и та же сложность, но
> разный порядок даёт разные свойства и разные задачи.

## BFS: волны от камня

**BFS** (breadth-first search) обходит граф **уровень за уровнем**.
Сначала все вершины на расстоянии 1 от старта, потом на расстоянии 2,
потом 3, и так далее.

```
        0          ← уровень 0
       / \
      1   2        ← уровень 1
     /     \
    3       4      ← уровень 2
```

BFS из вершины 0 обойдёт: `0, 1, 2, 3, 4`.

Реализуется через **очередь**:

1. Кладём стартовую вершину в очередь, помечаем посещённой.
2. Пока очередь не пуста:
   - достаём вершину из головы;
   - обрабатываем её;
   - кладём в хвост всех её **непосещённых** соседей и помечаем их.

```text
BFS(g, start):
1  queue ← пустая
2  visited[start] ← true
3  queue.push(start)
4  while not queue.empty():
5      u ← queue.pop()
6      посетить u
7      for каждого соседа v вершины u:
8          if not visited[v]:
9              visited[v] ← true
10             queue.push(v)
```

**Почему это работает.** Очередь — это FIFO: кто первый вошёл, тот
первый выйдет. Значит, все вершины уровня `k` попадут в очередь
раньше, чем вершины уровня `k+1`. Отсюда и «волны».

> **Важно:** помечать посещённой нужно **при добавлении в очередь**,
> а не при извлечении. Иначе одну и ту же вершину могут добавить
> несколько раз (из разных соседей), и очередь распухнет. Классическая
> ошибка.

## BFS и кратчайший путь

Вот главное свойство BFS: **в невзвешенном графе BFS находит
кратчайшее расстояние** (по числу рёбер) от старта до каждой вершины.

Почему? Потому что BFS обрабатывает вершины в порядке возрастания
расстояния. Когда мы впервые попадаем в вершину `v`, это происходит
из вершины `u`, у которой расстояние на 1 меньше. Значит,
`dist[v] = dist[u] + 1` — это минимально возможное расстояние.

Достаточно завести массив расстояний и заполнять его при первом
посещении:

```c
dist[start] = 0;
/* при переходе u → v: */
if (!visited[v]) {
    visited[v] = true;
    dist[v] = dist[u] + 1;
    queuePush(&q, v);
}
```

Всё. Кратчайший путь в невзвешенном графе — это BFS с массивом
расстояний. Никакого Дейкстры не нужно (Дейкстра — это BFS для
**взвешенного** графа).

> **Главная мысль:** «кратчайший путь» — это не всегда Дейкстра.
> Если веса всех рёбер одинаковы (или их нет), BFS быстрее и проще.
> Дейкстра — это обобщение BFS на случай разных весов.

**Восстановление пути.** Если нужен не только расстояние, но и сам
путь, заведите массив `parent[v]` — из какой вершины пришли в `v`.
Потом от целевой вершины идите по `parent` до старта и разверните
путь.

## DFS: вглубь до упора

**DFS** (depth-first search) идёт **вглубь**, пока может, потом
возвращается и пробует следующую ветку. Как в лабиринте: «всегда
идём в первую неисследованную дверь, пока не упрёмся в тупик».

```
        0
       / \
      1   2
     /     \
    3       4
```

DFS из 0 (соседи в порядке возрастания): `0 → 1 → 3 → 2 → 4`.

Реализуется **рекурсией** (или явным стеком):

```text
DFS(g, u):
1  visited[u] ← true
2  посетить u
3  for каждого соседа v вершины u:
4      if not visited[v]:
5          DFS(g, v)
```

Всё. Пять строк. DFS — это самый короткий графовый алгоритм из всех.

**Почему это работает.** Рекурсия использует **стек вызовов**. Когда
мы уходим в соседа, текущая вершина «ждёт» на стеке. Когда сосед
закончил — возвращаемся к текущей и идём в следующего соседа. Это
и есть обход в глубину, только стек неявный.

> **Важно:** DFS рекурсивный может **переполнить стек** на больших
> графах. Глубина рекурсии равна длине самого длинного пути, а в графе
> из миллиона вершин путь может быть длиной в миллион. Стандартный
> стек — 8 МБ, хватает примерно на 100 000 вызовов. Если граф больше —
> нужна итеративная версия.

## DFS итеративный

Рекурсию легко превратить в цикл с явным стеком. Но здесь есть
подвох, на котором спотыкаются все.

**Наивный вариант** (неправильный):

```text
1  stack.push(start)
2  while not stack.empty():
3      u ← stack.pop()
4      if visited[u]: continue
5      visited[u] ← true
6      посетить u
7      for каждого соседа v вершины u:
8          stack.push(v)
```

Это работает, но даёт **не тот порядок**, что рекурсивный DFS. Дело
в том, что стек — это LIFO, и если мы кладём всех соседей сразу,
то обработаем их в **обратном** порядке. А если ещё и не проверять
`visited` при добавлении — получим дубликаты.

**Правильный вариант** — эмулировать рекурсию один в один: хранить
на стеке пару `(вершина, индекс следующего соседа)`.

```text
1  stack.push((start, 0))
2  visited[start] ← true
3  посетить start
4  while not stack.empty():
5      (u, i) ← stack.top()
6      if i < degree(u):
7          v ← neighbor(u, i)
8          stack.top().i ← i + 1
9          if not visited[v]:
10             visited[v] ← true
11             посетить v
12             stack.push((v, 0))
13     else:
14         stack.pop()
```

Это длиннее, но даёт **тот же порядок**, что рекурсия. На практике
часто используют именно этот вариант, если рекурсия не влезает
в стек.

> **Главная мысль:** «итеративный DFS» — это не «заменить рекурсию
> циклом». Это «эмулировать стек вызовов явно». Если вам важен
> порядок обхода (а он часто важен для post-order и топосорта),
> эмулируйте рекурсию точно.

## Что даёт каждый обход

| Задача | BFS | DFS |
|--------|-----|-----|
| Обойти все вершины | ✅ | ✅ |
| Кратчайший путь в невзвешенном графе | ✅ | ❌ |
| Компоненты связности | ✅ | ✅ (проще) |
| Проверка на двудольность | ✅ | ✅ |
| Поиск цикла | ✅ | ✅ (проще) |
| Топологическая сортировка | ❌ | ✅ (post-order) |
| Мосты и точки сочленения | ❌ | ✅ |
| Уровни / расстояния | ✅ | ❌ |

**Правило выбора:**
- Нужны **расстояния** или **кратчайший путь** (по числу рёбер) → BFS.
- Нужна **структура** графа (циклы, компоненты, порядок) → DFS.
- Нужен **post-order** (топосорт, мосты) → DFS.

## Реализация на C

Возьмём список смежности из предыдущей главы. Добавим две функции:
`bfs` и `dfs`.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <limits.h>

/* ... структуры Graph и AdjNode из предыдущей главы ... */

/* ---------- Очередь для BFS ---------- */
/* Простая очередь на массиве фиксированного размера.
 * Для реального кода лучше динамический массив, но для учебных
 * целей хватает и так: размер очереди не превышает n. */
typedef struct {
    int *data;
    int head;
    int tail;
    int cap;
} Queue;

Queue* queueCreate(int cap) {
    Queue *q = malloc(sizeof(Queue));
    q->data = malloc(cap * sizeof(int));
    q->head = q->tail = 0;
    q->cap = cap;
    return q;
}

void queuePush(Queue *q, int v) { q->data[q->tail++] = v; }
int  queuePop(Queue *q) { return q->data[q->head++]; }
bool queueEmpty(Queue *q) { return q->head == q->tail; }
void queueFree(Queue *q) { free(q->data); free(q); }

/* ---------- BFS ---------- */
/* Обходит граф в ширину от start.
 * dist[i] — кратчайшее расстояние (по числу рёбер) от start до i.
 * Если вершина недостижима — dist[i] остаётся INT_MAX. */
void bfs(Graph *g, int start, int *dist) {
    for (int i = 0; i < g->n; i++) dist[i] = INT_MAX;

    bool *visited = calloc(g->n, sizeof(bool));
    Queue *q = queueCreate(g->n);

    visited[start] = true;
    dist[start] = 0;
    queuePush(q, start);

    while (!queueEmpty(q)) {
        int u = queuePop(q);
        for (AdjNode *cur = g->head[u]; cur != NULL; cur = cur->next) {
            int v = cur->to;
            if (!visited[v]) {
                visited[v] = true;
                dist[v] = dist[u] + 1;
                queuePush(q, v);
            }
        }
    }

    queueFree(q);
    free(visited);
}

/* ---------- DFS рекурсивный ---------- */
static void dfsRec(Graph *g, int u, bool *visited) {
    visited[u] = true;
    printf("%d ", u);
    for (AdjNode *cur = g->head[u]; cur != NULL; cur = cur->next) {
        if (!visited[cur->to]) {
            dfsRec(g, cur->to, visited);
        }
    }
}

void dfs(Graph *g, int start) {
    bool *visited = calloc(g->n, sizeof(bool));
    dfsRec(g, start, visited);
    free(visited);
}

/* ---------- DFS итеративный ---------- */
/* Эмулирует рекурсию: на стеке храним (вершина, индекс следующего
 * соседа). Даёт тот же порядок обхода, что и рекурсивный. */
typedef struct {
    int vertex;
    int nextIdx;
} Frame;

void dfsIterative(Graph *g, int start) {
    bool *visited = calloc(g->n, sizeof(bool));
    Frame *stack = malloc(g->n * sizeof(Frame));
    int top = 0;

    visited[start] = true;
    printf("%d ", start);
    stack[top++] = (Frame){start, 0};

    while (top > 0) {
        Frame *f = &stack[top - 1];
        int u = f->vertex;

        /* Найти следующего непосещённого соседа, начиная с f->nextIdx. */
        AdjNode *cur = g->head[u];
        for (int i = 0; i < f->nextIdx && cur != NULL; i++) cur = cur->next;

        if (cur == NULL) {
            /* Соседи закончились — возвращаемся. */
            top--;
        } else {
            f->nextIdx++;
            if (!visited[cur->to]) {
                visited[cur->to] = true;
                printf("%d ", cur->to);
                stack[top++] = (Frame){cur->to, 0};
            }
        }
    }

    free(stack);
    free(visited);
}

/* ---------- Пример ---------- */
int main(void) {
    /* Граф: 0-1, 0-2, 1-3, 2-4. */
    Graph *g = graphCreate(5);
    graphAddEdge(g, 0, 1, 1); graphAddEdge(g, 1, 0, 1);
    graphAddEdge(g, 0, 2, 1); graphAddEdge(g, 2, 0, 1);
    graphAddEdge(g, 1, 3, 1); graphAddEdge(g, 3, 1, 1);
    graphAddEdge(g, 2, 4, 1); graphAddEdge(g, 4, 2, 1);

    int dist[5];
    bfs(g, 0, dist);
    printf("BFS расстояния от 0: ");
    for (int i = 0; i < 5; i++) printf("%d ", dist[i]);
    printf("\n");

    printf("DFS рекурсивный:  ");
    dfs(g, 0);
    printf("\n");

    printf("DFS итеративный:  ");
    dfsIterative(g, 0);
    printf("\n");

    graphFree(g);
    return 0;
}
```

### Что важно в реализации

- **`visited` при добавлении в очередь**, а не при извлечении. Иначе
  очередь распухнет, а вершины будут обрабатываться повторно.
- **`dist` инициализируется `INT_MAX`** — это «бесконечность» для
  недостижимых вершин.
- **Очередь на массиве фиксированного размера** — в BFS каждая
  вершина попадает в очередь не более одного раза, значит,
  `n` элементов хватит с запасом.
- **Итеративный DFS** хранит `nextIdx` — индекс следующего соседа,
  которого надо рассмотреть. Это точная эмуляция рекурсии.
- **`printf` прямо в обходе** — для демонстрации. В реальном коде
  передают callback-функцию или возвращают массив порядка обхода.

> **Важно:** в итеративном DFS мы **не** помечаем соседа посещённым
> при добавлении в стек (как в BFS), а помечаем сразу при заходе в
> него. Это принципиально: если пометить при добавлении, порядок
> обхода изменится и перестанет совпадать с рекурсивным.

## Типичные применения

### Компоненты связности

В неориентированном графе компонента — это множество вершин, между
которыми есть путь. Находится тривиально:

```c
int component[g->n];  /* номер компоненты для каждой вершины */
int compId = 0;

for (int i = 0; i < g->n; i++) {
    if (!visited[i]) {
        /* обходим компоненту от i */
        dfsMark(g, i, visited, component, compId);
        compId++;
    }
}
```

Один проход DFS по всему графу — и все компоненты найдены. `O(V + E)`.

### Проверка на двудольность

Граф **двудольный**, если вершины можно раскрасить в два цвета так,
что каждое ребро соединяет вершины разных цветов. Проверяется BFS:

```c
/* color[v] ∈ {-1, 0, 1}; -1 — не покрашена. */
color[start] = 0;
queuePush(&q, start);
while (!queueEmpty(&q)) {
    int u = queuePop(&q);
    for (соседей v) {
        if (color[v] == -1) {
            color[v] = 1 - color[u];
            queuePush(&q, v);
        } else if (color[v] == color[u]) {
            /* ребро внутри одного цвета — не двудольный */
            return false;
        }
    }
}
return true;
```

Классический пример: граф «кто с кем враждует» — двудольный, если
можно разбить на две группы без врагов внутри группы.

### Поиск цикла

В **неориентированном** графе цикл есть, если при DFS мы наткнулись
на уже посещённого соседа, который **не является родителем** текущей
вершины. В **ориентированном** — сложнее: нужны три цвета (белый,
серый, чёрный) и проверка на «серый» сосед (вершина в текущем стеке
рекурсии). Это тема отдельного разговора, но идея та же.

> **Главная мысль:** все эти задачи — это «BFS или DFS с массивом
> состояния». Никакой магии. Поняли обход — поняли половину графовых
> алгоритмов.

## Итог

- **BFS** обходит «волнами», использует **очередь**, даёт **кратчайшие
  расстояния** в невзвешенном графе.
- **DFS** идёт «вглубь», использует **рекурсию** (или явный стек),
  даёт **структуру** графа (циклы, компоненты, порядок).
- Оба — `O(V + E)`. Быстрее нельзя: нужно прочитать все рёбра.
- **Помечать посещённой** надо при добавлении в очередь (BFS) или
  при заходе в вершину (DFS). Это разные моменты, и путать их —
  классическая ошибка.
- **Итеративный DFS** — это эмуляция рекурсии с явным стеком
  `(вершина, nextIdx)`. Даёт тот же порядок, что рекурсивный.
- **Компоненты связности** — DFS по всему графу в цикле.
- **Двудольность** — BFS с раскраской в два цвета.
- **Цикл** — DFS с проверкой на «не родителя» (для неориентированного).
- BFS и DFS — фундамент всего остального. Топосорт, Дейкстра, Краскал,
  Прим — все они «BFS или DFS с дополнительной структурой».
